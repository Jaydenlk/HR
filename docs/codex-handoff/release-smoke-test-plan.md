### ST-04: Create Diagnosis (创建简历诊断)

- **前置条件**: 已有至少一份简历
- **测试步骤**:
  1. 导航到「诊断」 -> 「新建诊断」
  2. 选择一份简历
  3. 粘贴一段 JD 文本 (>= 50 字，包含职责和要求)
  4. 提交
- **预期结果**:
  - 显示 loading 状态 (AI 处理中，可能 15-30 秒)
  - 完成后跳转到诊断结果页
  - 显示匹配分数、维度分析、关键词命中/缺失、改写建议
  - JD 过短 (<50 字) 应显示错误提示
- **状态**: Plan

## 错误场景测试 (4 项)

### ST-14: Wrong Invite Code (错误邀请码)

- **测试步骤**:
  1. 打开登录页
  2. 输入邮箱和姓名
  3. 输入错误邀请码: `WRONG123`
  4. 点击登录
- **预期结果**:
  - 显示明确的错误消息 (如「邀请码无效」)
  - 不跳转到主页面
  - 不创建用户
- **状态**: Plan

---

### ST-15: Empty Data States (空数据状态)

- **测试步骤**:
  1. 使用新账号登录 (无任何数据)
  2. 依次访问: 简历、诊断、投递、面试、薪资、日报、雷达、职业
- **预期结果**:
  - 每个页面都应显示友好的空状态 (empty state)
  - 不应显示 "undefined"、"null"、空白页面或 JavaScript 错误
  - 应提供引导 (如「上传你的第一份简历」)
- **状态**: Plan

---

### ST-16: AI Key Missing (AI 密钥缺失)

- **前置条件**: 将 `.env` 中 `CLOUDDREAM_API_KEY` 设为空
- **测试步骤**:
  1. 重启后端
  2. 尝试创建诊断或发送对话消息
- **预期结果**:
  - 返回明确的错误信息 (如 401 或「AI 服务不可用」)
  - 前端显示错误提示，不崩溃
  - 非 AI 功能 (投递追踪、面试记录、薪资) 正常工作
- **状态**: Plan

---

### ST-17: External Source Down (外部数据源不可用)

- **前置条件**: XHS/RSS/WeChat 服务均未启动
- **测试步骤**:
  1. 正常启动后端和前端
  2. 访问「日报」和「雷达」页面
  3. 触发 feed 导入 (如果有按钮)
- **预期结果**:
  - 日报和雷达页面正常加载，显示已有数据或空状态
  - 不因外部源不可用而崩溃或 500 错误
  - 导入操作应返回 0 条或友好错误信息
  - 其他所有功能不受影响
- **状态**: Plan
