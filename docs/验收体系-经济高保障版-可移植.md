# 验收体系:经济高保障版(可移植)

> 与《防降智保险方法论》配套。那份讲"怎么让弱模型不跑偏",这份讲"怎么用最少的钱把质量守到最高"。
> 核心公式:**经济 ≠ 少验,而是排序**——便宜且可靠的闸放最前面,贵的火力只砸在真会出错的地方;**保障 ≠ 多验,而是不可妥协项清单**——有几样东西无论多缺预算都不许砍。
> 每条规则带真实事故背书,标注为【实案】。

---

## 一、三条总原则

1. **验收金字塔:从免费到昂贵,逐层拦截。** 一个字段缺失,让免费脚本 0.1 秒抓出来,而不是让人类走查半小时后发现。每一层只负责抓"上一层抓不到、下一层抓太贵"的那类问题。
2. **基线先绿,允许失败数=0。** 存量恒红的测试要么修绿要么显式隔离,不许留"已知失败白名单"。【实案】我们有 4 条 e2e 因种子数据写死了过期季度而恒红,导致之后每次验收都要人肉分辨"是我改坏的还是本来就红"——判据失真,验收等于白做。
3. **证据文化:没有原始输出=没有通过。** 每道闸的结论必须绑定到具体命令的原始统计行;"跑了、看起来没问题"不是证据。【实案】裸测试命令因正则不匹配静默跳过全部 e2e,报"全部通过"而实际 0 条被执行——不核对"执行了多少条",绿灯毫无意义。

## 二、验收金字塔(七层,自下而上,便宜的先跑)

| 层 | 内容 | 成本 | 抓什么 | 通过标准 |
|----|------|------|--------|----------|
| L0 确定性脚本 | 字段完整度/残留扫描/黑名单/引用完整性/数字白名单 | **免费** | 结构性缺陷、漏删漏改、格式违规 | 脚本退出码 0;白名单外零残留 |
| L1 编译+lint | tsc/eslint(或等价) | 秒级 | 类型错误、死引用 | 0 错误(注意:编译过≠测试过,两回事) |
| L2 单元测试 | 纯逻辑用例 | 秒~分钟 | 函数级回归 | 全绿,统计行原样留证 |
| L3 集成/e2e(API 级) | 真数据库+真接口调用 | 分钟级 | 模块协作、鉴权、越权(IDOR)、边界 | **零失败**;必须核对"实际执行条数"防静默跳过 |
| L4 真实用户流(UI E2E) | Playwright 级:点按钮、填表单、断言结果 | 分钟~十分钟 | 前后端断连、假按钮、状态丢失 | 关键路径全过;截图存在≠通过,要断言可见结果(【实案】我们要求断言图片 naturalWidth>0,因为"元素存在"和"图片真的加载出来"是两回事——头像裂图 bug 全链路报 200 成功) |
| L5 独立审计 | 只读代理/人,立场=找茬不背书 | 一次调用 | 范围越界、红线触碰、审出测试测不到的设计偏差 | verdict=PASS 且零 blocking;每条发现必须带 file:line |
| L6 合并后对抗审计 | 单代理,只审合并 diff | 一次调用 | 冲突解
