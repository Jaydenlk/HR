## 0. 北极星与铁律

**一句话定位**:把产品从"又一个会陪跑的简历工具"重定位为 **"用代码护栏硬拦编造的校招求职教练 —— 你说人话,它配好下一步。"**

**两个旧版没讲清、这次必须成主角的点**(正是用户说"体现得不太好/没讲完"的根因):
1. **对话即调度台 Coach**(说一句话 → Coach 配行动卡 → 一键跳模块并预填)。
2. **点数制**(注册送 50 点 / 每次 AI 生成扣 1 点 / 试运行不收费、用完可免费续)。

**五条诚实红线(违反即返工,贯穿落地页与引导全部文案)**:
1. 行业趋势/月刊的联网检索结果 **绝不**称"已核验"。代码事实:URL 为 AI 自产,白名单仅降低误信风险;Bocha 不可用时直说"数据来源暂不可用"。
2. 能力盘点的 AI 评分 **绝不**称"权威评估"。必须区分「用户自评」vs「平台评分」vs「被压分」;自评必须标"用户主观自评,非平台评估结论"。
3. 防编造护栏 **绝不**隐瞒局限。张冠李戴护栏(FG-1)只做"邻近窗口相关性"判断,极复杂的多段经历交叉复用仍可能误判 → FAQ/护栏区要坦诚一句。
4. **绝不**说"试运行完全免费"误导成无限免费。准确口径:**注册送 50 点,每次 AI 生成扣 1 点,试运行期间不收费、点数用完可免费申请充值。**
5. **绝不**回补任何虚构用户数 / 提分数 / 岗位数 / 用户评价 / case。零用户期假证明是信任负分。真实 beta 微证言拿得到才放,拿不到坚决不放。

**结果文案安全区**:不承诺"提分/上岸/拿 offer"等结果,但**确定地陈述我们做了什么动作**(不确定+肯定句式)。也不退缩成"也许有用"这种没底气的对冲软话。

### 2.5 防编造护栏(改造:从"说"到"秀")
- 深色块,标题保留:`别的工具帮你写得更像真的,Coach 把编造<span 蓝>拦下来。</span>` 副:`三道确定性护栏 —— 不靠 AI 自觉,靠代码硬拦。`
- 三道护栏(真实机制,每道配可视示意):
  1. **时间线勾稽**:`「实习早于入学」「项目结束比开始还早」这类 HR 一眼出局的硬伤,由纯代码扫原文抓出,写进报告最显眼处。` 视觉:一行经历旁标红 `时间对不上`。
  2. **可疑数字压分**:`没有基数和口径的「增长 200%」不会被夸「数据扎实」—— 相关评分直接压制,改写只教你补上分母,不帮你圆谎。` 视觉:一个分数 `78 → 61` 的下降标注 `声称提升 40% 但简历无支撑 · 已压分`。
  3. **防编造溯源 + 张冠李戴护栏**:`改写里新增的任何数字、经历,必须能在你原文里找到出处,且要跟这条技能真的相关 —— 对不上就拦下不发。` 视觉:三态标注 `已核实(绿)/ 需你确认(黄)/ 无依据已删(灰)`。
- **坦诚一句**(诚实红线 3):`护栏不是万能 —— 极复杂的多段经历交叉,仍可能判错;拿不准的,我们会标出来让你确认,而不是替你拍板。`

### 2.6 价值观对比(新增 · 紧凑对比框 · 记忆点)
- 标题:`别人帮你过机器,我们帮你过<span 蓝>面试官。</span>`
- 左右对比(各 3 条):
  - 左「通用 AI / 简历工具」:塞关键词过 ATS · 把经历写得更漂亮 · 漂亮到面试官一问就穿帮。
  - 右「Coach」:每句都能在面试里站得住 · 可疑数字反而被压分 · 教你补口径,不帮你圆谎。
- 出处:竞品拆解(ATS 同质化反向切口 / Ajusta 对比表打法)。

## 3. 首次引导(组合拳:导览 + 启动清单 + 空状态 + 移动覆盖)

核心认知:用户说"没讲完、只讲大概"的解药 **不是讲更多**,而是 **讲到点子上 + 把人真正带到第一份诚实诊断(aha)+ 给"完整路径"的进度感 + 覆盖新功能(调度台/点数)+ 移动端也有**。

### 3.1 OnboardingTour 重写(`onboarding-tour.tsx`)
- **载体**:沿用聚光灯 + 居中卡;保留 `localStorage` 键 `coach_tour_done`、保留挂载点。
- **步数**:welcome 卡 + **≤5 个**价值步 + 末尾"启动清单"卡(总览,给"讲完"感)。严守 ≤5 价值步(>5 完成率断崖)。
- **开场改写**(person-before-process,删自我介绍式旁白):
  - welcome:`你来这儿,是想把秋招这场仗打好。我先用一分钟,带你看怎么开始 —— 不急,随时能跳过。`
- **每步从"这是 X 功能"改成"从这里你能做到 Y + 为什么重要"**:
  1. `简历馆`(锚 resumes):`第一步:把简历传进来(PDF / 文本都行)。它会成为你的底稿 —— 之后每次改写都能回溯、能回滚。`
  2. `校招诊断`(锚 campus):`这是重点:按真实校招标准给你逐条体检,每个判断都给原文依据。够不上的,当场告诉你 —— 这是你最该先做的一次。`
  3. `问 Coach 是你的调度台`(锚 chat):`把处境讲给 Coach 听(比如"下周有腾讯产品岗面试"),它会配好下一步、给你一排一键行动卡 —— 你说人话,它配好下一步。`(讲清调度台,诚实红线无关)
  4. `点数怎么用`(无锚或锚头像/点数余额):`注册我们送了你 50 点。每次让 AI 帮你生成用 1 点,余额在左下角随时看得到。试运行期间不收费,用完了找我们免费续 —— 放心用。`(诚实红线 4)
  5. `今天`(锚 today):`每天来这儿看 AI 给你排的待办和复盘节奏,做完今天的就能去过别的生活。`
- **末尾"启动清单"卡**(给"完整/讲完"感,收口指向 aha):
  - 标题:`你的校招启动清单`
  - 4 条(锚定结果):① 传一份简历 ② 跑出你的第一份诚实诊断 ③ 看 Coach 当场拦下一处水分 ④ 问 Coach 一句你最关心的求职问题
  - 主按钮:`传简历,开始第一份诊断` → `/resumes`。
- **语气矩阵**:welcome/各步可有温度;凡涉及"点数/护栏判定"切换冷静克制(尊重+解释),不卖萌不煽情不用感叹号堆砌。
- **移动端**:不再 `!isMobile` 屏蔽(见 3.4)。窄屏聚光灯定位不可靠 → 移动端**降级为居中卡片步**(不挖洞聚光灯,改为每步一张居中说明卡 + 该功能名;或仅 welcome + 启动清单两张卡)。避免 deck-of-cards 轮播观感。保证可滚动、可跳过、tap target ≥44pt。

### 3.2 校招启动清单组件(新增 `components/onboarding/starter-checklist.tsx`)
- **定位**:常驻的"引导脊柱",给"没讲完"的解药 —— 一个看得见的完整路径 + 进度感(蔡格尼克效应)。渲染在 `/today` 顶部。
- **4–5 项**(锚定结果非动作),**预勾第一项**(endowed progress)+ **进度条**:
  - ✓(预勾)`已了解你的求职方向`(注册已收集,直接打勾,让用户一进来就"已完成 1/5")
  - `传一份简历` → 真实判定:`GET /resumes` 非空
  - `跑出第一份诚实诊断` → 真实判定:`GET /diagnoses`(或 campus)非空
  - `问 Coach 一句` → 真实判定:`GET /conversations` 非空
  - `(可选第 5,按路由)做一次模拟面试 / 盘点能力差距`

## 7. 决策记录(chosen / rejected / why)

- **落地页结构**:选"叙事弧线(Hero→痛点→调度台→护栏→对比→能力→点数→质量→FAQ→收尾)+ 合并两面功能墙";排除"在旧结构上加段"(信息密度过高、稀释主线,违背做减法)。依据:落地页最佳实践"一屏一信念"+ 用户"不要盲目堆数据"。
- **护栏区从'说'到'秀'**:选"三态标注 + 78→61 压分可视";排除"只改文案"。依据:竞品(CVAIMate/Ajusta)已把"绝不编造"口号喊烂,必须用可视证据差异化。
- **引导**:选"重写导览(≤5 价值步 + 启动清单卡 + 移动覆盖)+ 常驻启动清单(/today)+ /resumes 空状态";排除"做满 checklist+intent路由+对话内开场的全活化系统"(scope creep + 触后端 + 回归风险)。依据:用户只问"引导介绍",范围纪律,回归零容忍。
- **不动后端/DB**:本轮纯前端 → 满足"不误删数据"红线,零 migration。
- **构建载体**:选"feature 分支在主工作树(node_modules 已装)+ 并行 Opus 子代理改不相交文件 + 主代理过门 + 合 dev";排除"每 agent 独立 worktree"(无 node_modules 需重装 + 合并冲突历史痛点)。dev 分支在合并前不受影响,满足隔离意图。
- **credit 文案口径**:选"注册送50点/每次扣1点/试运行不收费、用完免费续";排除"试运行完全免费"(诚实红线 4,会误导无限免费)。
- **移动端门禁豁免(门禁阶段发现并加做)**:Playwright 移动验证时发现全站 `MobileGate`(波1 deliberate 决策,带显式注释"产品决定:移动端体验未达标就不放行")会把已做好移动响应式的落地页也挡在"移动端暂未适配"后。选"仅豁免 /landing、/terms,App+登录保持拦截";排除"全站放开"(App 页确实未适配移动,会给坏体验)、排除"不动门禁"(营销页是校招生主力入口,挡在 mobile 是转化灾难)。依据:门禁自身 rationale 是"挡未就绪体验",落地页现已就绪;funnel 仍诚实(mobile 看完介绍→点 CTA→/login 门禁=自然的"用电脑开始")。**此项改了一个 deliberate 决策,已在交付报告显著标注,用户验收可一行回退**。
- **质量证据卡软化(诚实红线 P0,门禁发现)**:旧落地页(及 README)的"33份盲评/5陷阱卷/3被拒卷/四条硬杠全部通过"在仓库 docs/.claude/memory 中找不到可溯源留痕(真实记录是 7样本×4视角 / 14·8 persona survival audit / FG-1~7,框架与数字均不同)。选"软化为可验证的对抗盲审表述(survival audit + 防编造对抗已真实验证)";排除"保留具体数字"(违诚实红线 5、品牌即诚实)。README 的同款表述本轮未改(范围纪律),已在报告标注供用户决定。
