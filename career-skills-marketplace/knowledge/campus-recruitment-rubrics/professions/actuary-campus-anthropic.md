# 精算（精算 · 校招(压力版 · 高标准)）

> 校招职业标尺 · 难度档：`pressure` · 预设ID：`actuary-campus-anthropic`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 精算考试进度（门数硬门槛×体系聚焦）（满分 30）
- **好的样子**：头部再保/咨询/直保总部真实卡分线:SOA 已通过 5 门及以上(P/FM/IFM/STAM/LTAM 或对应新体系科目)向 ASA 冲刺,或 CAA 准精算师已取得;科目逐一列出英文代号且体系单一聚焦(纯 SOA 或纯 CAA 主线,不与 CFA/FRM/CPA 混列暴露方向不定)。门数全部写「已通过」并标注最近一次考期,展现持续高通过率而非零散试水。
- **应届证据**：证书栏明确「已通过 SOA 5 门」并逐一列出科目代号+体系,或「CAA 准精算师已取得」;考试进度置于简历首屏(精算三件套之一);通过节奏密集且无长期卡壳,体现学习强度可承受总部工作量。
- **常见缺失 / 反模式**：【反模式·备考中先生】满简历「在考」「计划考 SOA」却已过门数寥寥甚至为零,头部筛选器看到低门数直接划走;【反模式·体系骑墙派】SOA 过两门又转 CAA、再并排堆 CFA/FRM,体系不聚焦暴露方向摇摆;门数刚够及格线却投再保/咨询(其真实门槛远高于直保分公司)。

### 2. 精算岗实习的机构层级与任务实质（满分 28）
- **好的样子**：真实精算岗(非营销/柜台)实习,机构层级达头部:再保险公司精算部(慕再/瑞再/汉诺威)、头部精算咨询(WTW/美世/韬睿惠悦)最佳,平安/太保/国寿总部精算部次之。任务写得出精算硬内容并能说清本人独立做了什么:参与产品定价费率厘定(用了什么定价假设、跑了什么利润测试)、准备金评估(用了什么方法、覆盖哪类产品)、经验分析、模型维护(Prophet/自建现金流模型),每段绑定可量化产出与本人独立承担的环节。
- **应届证据**：实习栏写明机构全称+精算部门+精算硬任务,bullet 含具体方法与量级(评估 X 个产品准备金、维护 X 套定价模型、跑 X 万条保单现金流);慕再/瑞再/头部咨询实习是顶级背景;有 return offer 或转正考察通过。
- **常见缺失 / 反模式**：【反模式·沾边就算仔】拿银行柜台、保险销售、券商实习往精算岗上靠,觉得行业沾边就够,录用官第一刀就砍;【反模式·杂活美化师】在分公司做的是与精算无关的杂活却美化成「参与精算工作」,背调即穿帮;实习描述只有「参与精算相关工作」无任何方法、产品、量级。

### 3. 编程与精算建模实操深度（满分 16）
- **好的样子**：Excel/VBA 作为门槛默认具备;Python 或 R 有真实精算项目佐证并能讲清方法(用 Python 跑 GLM 产险定价、做现金流测算、复现准备金评估),数据系/科技险企岗另需 SQL 取数;寿险评估岗有 Prophet 真实建模实操是专项强加分。每项工具绑定「用它解决了什么精算问题、算了什么、数据量级多大」,且经得起「具体怎么实现」的追问。
- **应届证据**：实习/项目描述写「用 Python 实现 GLM 定价并校验拟合」「用 Prophet 搭建寿险准备金评估模型」「用 VBA 搭建现金流测算表」,工具与精算产出绑定;数模国奖佐证建模能力。
- **常见缺失 / 反模式**：【反模式·精通牌吹牛皮】技能栏全「精通/熟练 Python/Prophet」,正文零项目佐证,Prophet 写上去却连界面都没打开过,面试问具体实现即露馅;把跑过教程当「会建模」;Python 只用来做过课程作业,从未碰真实精算数据。

### 4. 精算业务理解（监管框架×定价准备金实务）（满分 14）
- **好的样子**：能用业务语言体现对核心框架的实务级认知:偿二代(C-ROSS II)偿付能力监管、IFRS 17 新保险合同准则(头部精算部均在改造准备金模型)、产品定价框架(费率厘定/利润测试/GLM 在产险定价应用)、内含价值等,并说清自己在课设/论文/实习中具体做了什么、理解了什么因果(而非名词罗列)。能讲出「为什么 IFRS 17 改了准备金计量、对利润释放节奏有何影响」这类实务追问。
- **应届证据**：课设/毕业论文/实习项目出现偿二代/IFRS 17/准备金/利润测试/内含价值并说明参与内容(如「参与 IFRS 17 准备金模型改造测试」);能就某框架讲清因果链而非背名词。
- **常见缺失 / 反模式**：【反模式·考试机器人】满脑子过了几门,对偿二代、IFRS 17、准备金一个字说不出,录用官一眼看穿「只会考不懂业务」;把监管框架当名词背诵讲不出因果与影响;简历从头到尾只有门数+编程,零业务术语。

### 5. 学历背景与专业匹配硬门槛（满分 12）
- **好的样子**：本/硕为精算或统计、数学方向,院校匹配精算名校光环(人大/复旦/南开/央财/上财或清北数学系)更佳;专业匹配度 精算>统计>数学≈金融工程>金融/保险(后者须证书+实习双补);全日制双证可按时取得(央企/国企硬门槛)。GPA 必附(精算圈对成绩敏感)并列出精算核心课成绩(概率论/随机过程/精算数学/寿险非寿险精算)。
- **应届证据**：教育栏写明院校+精算/统计/数学方向+全日制+预计毕业年月+GPA 及排名+精算核心课成绩;海外精算名校+海外精算实习是强信号;院校精算协会负责人展示行业认同感。
- **常见缺失 / 反模式**：【反模式·绩点孤勇者】以为 GPA 拉满就能进精算总部,简历除成绩单空空如也,录用官看的是实习不是分数;专业是金融/保险却既无证书也无实习补匹配;非全日制学历投央企/国企(硬门槛直接出局);毕业时间模糊不写月份。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实,分数与 why 严格一致:① 命中/缺失事实写进 evidenceFound/gap——exam_progress 写出已过几门+哪个体系+列了哪些科目(如「已过 SOA 5 门:P/FM/IFM/STAM/LTAM」)或「零已过门数仅见备考中」;actuarial_internship 写出机构层级+精算硬任务+本人独立环节,或「仅银行/营销实习无精算岗经历」;programming 写工具+绑定的精算计算场景,或「技能栏列 Python/Prophet 但正文零佐证」;business_acumen 写命中框架及参与内容,或「全文无偿二代/IFRS 17 等术语」;education 写院校+专业方向+GPA,或「专业不对口且无证书无实习补足」。严禁「有一定了解」「基础好」等笼统话。② 说明压力版精算语境下为何重要——门数是头部再保/咨询/总部的非弹性硬门槛(低门数直接过滤)、精算岗实习是录用官首位筛选且不可被跨行业实习替代、编程近年权重急升且互联网系险企必问、业务理解是面试核心、院校专业是隐形筛选线。③ 命中反模式直接点名(「备考中先生」「体系骑墙派」「沾边就算仔」「杂活美化师」「精通牌吹牛皮」「考试机器人」「绩点孤勇者」),不得空泛说「有待提升」。④ 给高分但 why 全是缺口属自相矛盾,应拒绝输出。严禁泄漏「满分X%/扣X分」等内部计算口径。

## 改写指引（禁编造铁律）
严格遵循「禁编造」铁律,只精修简历已有的精算实习/项目句,绝不替候选人添加原句没有的能力、技术名词、机构层级或门数:① 把已有精算实习句讲精准——明确写出用了什么方法(GLM/利润测试/现金流测算/经验分析)、解决什么精算问题(定价费率厘定/准备金评估/模型维护)、量级多大(评估 X 个产品、维护 X 套模型、处理 X 万条保单),机构/产品/方法均须取自原文,缺则留占位或走 gap_advice;② 用精准动词但不越级——原文写「协助/参与」就保留,严禁夸大为「独立完成/主导」,原文确有独立产出才可用「独立完成」;③ 只在缺数字处用 [具体数字] 占位并在 reason 注明建议补充真实数据,绝不代填;④ 严禁编造——简历没写过 Python/Prophet/SQL/某监管框架一律不得添加,没体现过的门数、机构层级、业务认知不得凭空生成;⑤ 缺失关键能力一律走 gap_advice——「建议补充已通过的精算考试门数及具体科目」「建议补充一段精算岗实习并写明具体任务与方法」「建议在项目中补充编程工具的实际使用场景」「建议补充对偿二代或 IFRS 17 的认知体现」;⑥ original 字段必须是简历原文一字不差。

## 本土惯例与硬规则
出局级硬规则:无任何精算考试通过记录(一门未过)再保/咨询/直保总部直接过滤;非全日制学历或无法按时拿到毕业证+学位证双证,央企/国企硬性出局;简历虚假信息经学信网+背调核验,造假列入行业黑名单;无精算岗实习在再保/咨询/总部层级几乎只能靠内部推荐。证书优先级:1.SOA(性价比最高,头部与外资均认)2.CAA 准精(央企/国企监管体系优先认)3.SOA+CAA 双证有加分但投入产出要算清 4.IFoA 仅合资/欧资加分、CAS 为产险专项 5.明确反信号:CFA/FRM/CPA 对精算岗不加分,与精算证并列暴露方向不定。格式偏好:头部走网申系统,本科 1 页、研究生最多 2 页;考试门数、院校、实习机构层级三项必须首屏可见;央企投递邮件主题严格按「应聘岗位+姓名」。加分项:慕再杯获奖可直接关联慕再实习是顶级背景、数模国奖、SOA 奖学金、Prophet 实操(寿险评估专项)、IFRS 17 相关项目、海外精算名校+海外精算实习。反信号:过多非精算证书暴露方向不定、只有营销/业务类实习、描述实习只用「协助/参与」无任何量化产出。
