# 精算（精算 · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`actuary-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 精算考试进度（门数×体系）（满分 28）
- **好的样子**：已通过 SOA 3-5 门或 CAA 准精 4 门以上，并具体列出科目名（如 SOA 的 P/FM/IFM、CAA 的精算数学/精算模型）。证书体系聚焦：以 SOA 或 CAA 为主线，不与 CFA/FRM/CPA 混列。目标央企/国企者优先 CAA（偿付能力监管体系本土认可），冲再保/外资/咨询者 SOA 性价比最高。门数写「已通过」而非「备考中」。
- **应届证据**：证书/考试栏明确写「已通过 X 门」+ 逐一列出科目英文代号或中文名，标注体系（SOA/CAA）。考试进度安排在简历开头（精算圈三件套之一，与院校、实习并列首屏可见）。
- **常见缺失 / 反模式**：只写「正在备考精算考试」「计划报考 SOA」却零已过门数；或把 CFA 一级、FRM 与精算证并排堆砌显得方向不聚焦。【反模式·备考中先生：一门没过却满简历都是「在考」「计划考」，顶部机构筛选器看到零门数直接划走】

### 2. 精算岗实习经历（机构层级×任务实质）（满分 30）
- **好的样子**：有真实的精算岗（非营销/柜台）实习，机构层级清晰：再保险公司精算部（慕再/瑞再）、头部精算咨询（WTW/韬睿/美世）最佳，平安/太保/人寿总部精算部次之。任务写得出具体内容：参与产品定价费率厘定、准备金评估、模型维护、经验分析等，且能说清自己独立做了什么（用了什么方法、算了什么、给出什么结论）。
- **应届证据**：实习经历栏写明机构全称+精算部门+起止时间，每段用 2-3 条 bullet 描述具体精算任务与可量化产出（如评估了 X 个产品的准备金、维护了 X 套定价模型），而非一句「参与精算相关工作」。
- **常见缺失 / 反模式**：用保险营销、银行柜台、券商实习冒充精算经验，以为「保险/金融相关」就够；或在分公司做了与精算无关的杂活却美化成「参与精算工作」，背调即穿帮。【反模式·沾边就算仔：拿银行柜台、保险销售实习往精算岗上靠，觉得行业沾边就能补上精算实习的空缺，录用官第一刀就砍这个】

### 3. 编程与精算工具实操能力（满分 18）
- **好的样子**：Excel/VBA 作为门槛能力默认具备；Python 或 R 有真实项目/实习佐证（如用 Python 跑 GLM 定价、用 VBA 做现金流测算）；数据系/科技险企岗位另需 SQL 取数能力。寿险评估岗有 Prophet 实操接触是专项加分。每项工具都绑定一个「用它做了什么计算/建模」的具体场景。
- **应届证据**：在实习/课程项目描述里写「用 Python 完成了××计算/建模」「用 VBA 搭建了××测算表」，工具与产出绑定出现，而非单独一栏列「熟练 Python/R/SQL」。
- **常见缺失 / 反模式**：技能栏写「精通 Python」「熟练 Prophet」却全简历找不到一个用到它的项目，面试一问具体怎么用就露馅。【反模式·精通牌吹牛皮：技能栏全是「精通/熟练」，正文零项目佐证，Prophet 写上去了却连界面都没打开过】

### 4. 学历背景与专业匹配度（满分 14）
- **好的样子**：本/硕为精算或统计、数学方向，院校匹配精算名校光环（人大、复旦、南开、央财、上财，或清北数学系）更佳。专业匹配度：精算>统计>数学≈金融工程>金融/保险（后者需用证书补足）。全日制双证可按时拿到（央企/国企硬门槛）。附 GPA（精算圈对成绩敏感）并列出精算相关核心课成绩。
- **应届证据**：教育背景栏写明院校+专业（标注精算/统计方向）+全日制+预计毕业时间，附 GPA 及排名，列出概率论、随机过程、精算数学、寿险/非寿险精算等核心课程成绩。
- **常见缺失 / 反模式**：把全部精力堆在刷 GPA 和课程分数上，零精算实习，对再保/咨询/总部而言仍是零竞争力；或专业是金融/保险却既无证书也无实习来补匹配度。【反模式·绩点孤勇者：以为 GPA 拉满就能进精算总部，简历里除了成绩单空空如也，录用官看的是实习不是分数】

### 5. 精算业务理解（监管框架×定价准备金认知）（满分 10）
- **好的样子**：能用业务语言体现对核心框架的认知：偿二代（C-ROSS II）偿付能力监管、IFRS 17 新保险合同准则（2023 年起执行，头部精算部均在改造准备金模型）、产品定价框架（费率厘定、利润测试、GLM 在产险定价中的应用）、内含价值等。哪怕是「参与 IFRS 17 建模测试」「课程设计中做过准备金评估」也胜过完全无认知。
- **应届证据**：在课程设计、毕业论文、实习项目描述中出现偿二代/IFRS 17/准备金/利润测试/内含价值等关键词，并说明自己在其中做了什么、理解了什么，而非纯名词罗列。
- **常见缺失 / 反模式**：简历从头到尾只有考试门数和编程技能，完全不出现任何监管框架或业务术语，显示只会刷题考试不懂实务。【反模式·考试机器人：满脑子都是过了几门，对偿二代、IFRS 17、准备金一个字都说不出，录用官一眼看穿「只会考不懂业务」】

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实，按以下结构展开，分数与 why 严格一致：

① 命中/缺失事实（写进 evidenceFound / gap）：
- exam_progress：evidenceFound 写出具体过了几门、哪个体系、列了哪些科目（如「已过 SOA 3 门：P/FM/IFM」）；gap 写「全文仅见『备考中』无任何已过门数」或「CFA+FRM+精算证混列，方向不聚焦」。
- actuarial_internship：evidenceFound 写出机构层级与具体任务（如「慕再精算部，参与产品准备金评估」）；gap 写「仅有银行/营销实习无精算岗经历」或「实习描述只有『参与精算工作』无任何任务实质」。
- programming_tools：evidenceFound 写出工具+绑定的计算场景（如「用 Python 实现 GLM 定价」）；gap 写「技能栏列 Python/Prophet 但正文零项目佐证」。
- education_major：evidenceFound 写院校+专业方向+GPA；gap 写「专业为金融/保险且无证书无实习补足」或「仅有 GPA 零实习」。
- business_understanding：evidenceFound 写命中的框架关键词及参与内容（如「课设涉及 IFRS 17 准备金建模」）；gap 写「全文无偿二代/IFRS 17/准备金等任何业务术语」。

② 校招语境下为何重要：必须说明该维度在精算校招的实际筛选作用——考试门数是顶部机构的非弹性硬门槛（零门数直接过滤）；精算岗实习是录用官实际筛选第一位且不可被跨行业实习替代；编程工具近 3 年权重急升且互联网系险企必问；院校专业是隐形筛选线；业务理解是简历铺垫、面试核心。

③ 命中反模式直接点名：若命中则直呼「备考中先生」「沾边就算仔」「精通牌吹牛皮」「绩点孤勇者」「考试机器人」等，不得空泛说「有待提升」。

分数对齐：exam_progress 零已过门数封顶不及格（顶部机构硬出局）；actuarial_internship 仅有跨岗实习不得给中等以上分；programming_tools 工具无佐证只能算缺失；business_understanding 零业务术语给低分但不一票否决（属铺垫维度）。

## 改写指引（禁编造铁律）
严格遵循「禁编造」干净句式，绝不替候选人添加原句没有体现的能力、技术名词或机构层级：

1. 把简历「已有」的精算实习/项目句讲精准：明确写出用了什么方法（GLM/利润测试/现金流测算/经验分析）、解决什么精算问题（定价费率厘定/准备金评估/模型维护）、量级多大（评估了 X 个产品、维护 X 套模型、处理 X 万条保单数据）。
   - 例：原句「参与精算相关工作」→ 改「在 [机构] 精算部参与 [产品类型] 的准备金评估，使用 [原文已提及的方法] 完成 [具体环节]」（机构、产品、方法均须取自原文，缺则留占位或走 gap_advice）。

2. 用精准动词替换模糊词，但不得越级：原文写「协助/参与」就保留「参与」，严禁夸大为「独立完成/主导」；原文确写了独立产出才可用「独立完成」。

3. 只在缺数字处用 [具体数字] 占位：如「评估了 [具体数字] 个产品的准备金」「跑了 [具体数字] 条保单的定价模型」，让候选人自行填真实数字，绝不代填。

4. 严禁编造能力：简历没写过 Python/Prophet/SQL/某监管框架，一律不得在改写中添加；没体现过的考试门数、机构层级、业务认知不得凭空生成。

5. 凡简历缺失的关键能力（如无已过门数、无精算岗实习、无编程佐证、无业务术语），一律走 gap_advice 给「建议补充」而非在 rewrite 里编造：
   - gap_advice 示例：「建议补充已通过的精算考试门数及具体科目（如 SOA P/FM）」「建议补充一段精算岗实习并写明具体任务」「建议在项目中补充编程工具的实际使用场景」「建议补充对偿二代或 IFRS 17 的认知体现」。

## 本土惯例与硬规则
出局级硬规则：
- 无任何精算考试通过记录（一门未过）：再保/咨询/直保总部等顶部机构直接过滤，无商量余地。
- 非全日制学历 / 无法按时拿到毕业证+学位证双证：央企、国企硬性出局。
- 简历虚假信息：国企通过学信网+背景调查核验，一旦发现造假列入行业黑名单。
- 无精算岗实习：在再保/咨询/直保总部层级，几乎只能靠内部推荐（业内原话「只能靠关系」）。

证书优先级（国内就业明确共识）：
1. SOA（北美）— 性价比最高，4-5 门即达门槛，国内头部与外资均认。
2. CAA 准精（中国精算师协会 2023 年改革后新体系）— 央企/国企监管体系优先认，本土合规优势。
3. 双证（SOA+CAA）有加分但投入产出要算清楚，非学霸不建议双修。
4. IFoA（英国）仅合资/欧资场景加分，国内通用性约为 CAA/SOA 的 1/5；CAS 为产险定价专项，主流机构不独立要求。
5. 明确反信号：CFA、FRM、CPA 对精算岗不加分，与精算证并列反而暴露方向不坚定。

格式偏好：
- 头部机构走网申系统，简历本科 1 页、研究生最多 2 页。
- 考试门数、院校、实习机构层级三项必须在简历开头/首屏可见（精算圈最看重的三件套）。
- 央企走正式报名渠道，投递邮件主题须严格按「应聘岗位+姓名」格式。

加分项（精算特有）：
- 慕再杯（慕尼黑再保险精算数学竞赛）获奖，可直接关联慕再实习，是精算圈顶级背景；全国数学建模国奖、SOA 奖学金项目亦认可。
- Prophet 软件有实操经验（寿险评估岗专项加分）。
- IFRS 17 相关项目/课程（2023 年后权重极高）。
- 海外精算名校+海外精算实习（实习比海归学历本身更重要）。
- 院校精算协会/社团负责人（展示行业认同感）。

反信号（精算特有）：
- 过多非精算证书（CFA/CPA 与精算并列暗示方向不坚定）。
- 只有营销/业务类实习，无精算岗经历。
- 描述实习时只用「协助」「参与」而无任何量化产出。
