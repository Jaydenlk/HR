# 门店管培/储备店长（门店管培/储备店长 · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`store-manager-trainee-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 门店一线实操经验(人货场实务×任务实质)（满分 28）
- **好的样子**：有真实门店一线经历(连锁零售/餐饮/酒旅/便利店/3C体验店等),且做的是实务而非边角:理过货(陈列/补货/盘点)、管过人(带过班次/排过班/带新人)、对过账(收银/日结/损耗盘点)、处理过现场(客诉/高峰应对/调改陈列)。能说清自己在「人(员工/顾客)、货(库存/陈列/损耗)、场(动线/卫生/氛围)」三件事上具体做了什么、用了什么 SOP、带来什么改善。机构层级清晰:优衣库 UMC/经营管培、百胜(肯德基/必胜客)餐厅管理培训生、星巴克储备经理、名创/盒马/山姆/沃尔玛门店管培、海底捞储备干部等知名连锁的门店实习含金量最高。
- **应届证据**：实习经历栏写明品牌全称+门店/岗位(店员/见习/管培实习)+起止,用 2-3 条 bullet 写清在人货场上的具体动作与量化产出:如「负责 [品类] 区陈列与补货,周转盘点损耗率从 X% 降到 Y%」「高峰时段带 N 人班次,把出餐/排队时长压到 X 分钟」。把门店实习放在简历首屏(该岗第一看点),而非埋在「其他经历」。
- **常见缺失 / 反模式**：把发传单、做活动兼职、纯收银、商场临时促销当成「门店运营经验」,以为「在店里待过」就算;或门店实习只写「负责日常工作/协助店长」却说不出任何人货场动作。【反模式·收银台路过仔:只在前台扫了俩月码、连库存和排班长什么样都没碰过,却把简历写成「门店运营管培预备役」,录用官一问『损耗怎么盘的、班怎么排的』当场哑火】

### 2. 经营数据与坪效人效意识(数据驱动复盘)（满分 24）
- **好的样子**：懂门店是个生意:认识并能正确使用核心经营指标——坪效(每平米销售额)、人效(人均产出)、客单价、连带率/客带率、转化率、损耗率、毛利率、人力成本占比(行业普遍 15-25%)、库销比/周转天数。不止认识名词,而是能在经历里体现『看了数据→发现问题→做了动作→指标变好』的闭环:如根据时段客流调排班降人力成本、根据动线/陈列数据提连带率、根据损耗盘点找漏洞。Excel 做日报/周报、看懂门店经营报表是门槛能力;接触过 BI/数字化排班/收银后台数据是加分。
- **应届证据**：在门店实习或商业分析/数据类课程项目里写出指标闭环:如「用 Excel 做时段销售透视,发现 [时段] 人效偏低,调整排班后人力成本占比下降 X 个百分点」「分析 [品类] 连带率,调整关联陈列后客单价提升 X 元」。指标要具体到名字(坪效/人效/连带率),数字带 [量级]。
- **常见缺失 / 反模式**：通篇是『提升了业绩』『优化了运营』『提高了顾客满意度』这类没有指标、没有数字的空话,看不出懂不懂这门生意;或堆一串指标名词却没有一个绑定到自己做过的动作。【反模式·业绩提升靠感觉:满屏『大幅提升销售/极大优化运营』,坪效人效连带率一个数都报不出,录用官看完只记得四个字『查无实据』】

### 3. 带团队与领导潜质(排班/激励/冲突处理)（满分 20）
- **好的样子**：储备店长本质是『提前预定的店长』,带人是核心。有过真实带团队/带班次/带项目的经历:门店里带过班、排过表、带过新人、协调过员工冲突;校园里当过学生组织/社团/部门负责人、活动总负责、班长/团支书,且写得出『带了几个人、怎么分工、怎么推动、遇到分歧怎么处理、最终拿到什么结果』。能体现责任心、服务他人意识、把一群人组织起来达成目标的能力,而非单打独斗的个人成绩。
- **应届证据**：在门店实习/学生工作里写出带人闭环:如「带 N 人迎新组,3 周内完成 X 场活动,处理了 [具体分歧] 」「门店高峰带 N 名小时工排班分工,把翻台/动线理顺」。突出『我组织/我协调/我拍板』,而非『我参加了』。
- **常见缺失 / 反模式**：把『参加过社团』『是社团成员』当领导力,从头到尾只有参与没有带人;或只罗列头衔(部长/会长)却说不出带了几个人、解决过什么具体冲突。【反模式·光杆司令挂名党:简历挂着『××部部长/××社社长』,一问『你带几个人、有没有处理过队员撂挑子』全是空白,头衔再大也是光杆一个】

### 4. 一线韧性与下沉意愿(倒班/轮岗/抗压)（满分 16）
- **好的样子**：清楚且认同这是个『从店里干起』的岗:接受先下门店一线轮岗(普遍 6-18 个月三阶段:店员→领班/见习→副店→储备店长)、接受倒班/排班/周末与节假日在岗、接受跨城/跨店外派。心态务实,把『下店、站柜、值早晚班、扛大促』当作成长路径而非委屈。能用经历佐证抗压与持续性:做过强度大、周期长、要直面顾客的一线工作并坚持下来(连续做满一个完整周期、扛过一次大促/旺季)。
- **应届证据**：在实习/兼职描述里体现坚持与强度:如「连续 X 个月门店实习,经历完整 [节日/大促] 周期,日均接待 X 名顾客」;在求职意向/自我评价里明确写『接受门店一线轮岗与倒班、可服从跨城外派』,把企业最担心的『干两天嫌累跑路』提前打消。
- **常见缺失 / 反模式**：简历透出『只想坐办公室做管理/做品牌策划/做数据分析』,对下店站柜倒班只字不提甚至流露抵触,与岗位本质(先当一线兵)错位;或全是短平快的轻松兼职,看不出能扛一线强度。【反模式·空降总监预备役:还没下过一天店,就把自己定位成『门店运营管理/品牌战略方向』,字里行间不愿站柜倒班,录用官最怕这种『管培没做就想当店总』入职即闪退】

### 5. 服务意识与现场合规(客诉处理/食安·安全)（满分 12）
- **好的样子**：门店是直面顾客的生意:有发自内心的服务意识与同理心,能讲出真实处理顾客投诉/突发的案例(怎么安抚、怎么补救、怎么避免再犯)。餐饮线需有食品安全与卫生合规意识(明厨亮灶、效期管理、5S/6T、消防安全);零售线需有防损、商品效期、现场安全(消防/客流管控)意识。能体现对『标准化执行(SOP)』的尊重——门店运营靠流程跑通,理解照章办事不是死板而是底线。普通话标准、表达清晰、形象得体(直面顾客岗的隐性门槛)。
- **应届证据**：用一个具体客诉/突发案例展现处理能力:如「处理 [具体投诉],先 [安抚动作] 再 [补救动作],并推动 [流程改进] 避免复发」;餐饮岗补充食安/卫生相关经历或证书(健康证、食安管理员培训)。在自我评价里点出服务意识与抗挫心态,而非空喊『热爱服务业』。
- **常见缺失 / 反模式**：把『热爱服务行业、性格开朗、有亲和力』当服务能力,全是形容词没有一个真实顾客场景;或对食安/防损/SOP 这些门店底线毫无概念,显得没在真门店待过。【反模式·亲和力复读机:自我评价里『热情开朗、亲和力强、热爱与人打交道』复读三遍,却举不出一个真实搞定难缠顾客的例子,亲和力成了简历最廉价的填充词】

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实,按以下结构展开,分数与 why 严格一致:

① 命中/缺失事实(写进 evidenceFound / gap):
- store_operations_practice:evidenceFound 写出品牌层级+人货场具体动作(如「优衣库门店实习,负责陈列补货并参与盘点损耗」);gap 写「仅有发传单/纯收银/促销兼职,无人货场实务」或「门店实习只写『协助店长』无任何具体动作」。
- operating_metrics_literacy:evidenceFound 写出命中的指标名+绑定动作+量级(如「用 Excel 分析时段人效,调排班降人力成本」);gap 写「全文只有『提升业绩/优化运营』无任何经营指标与数字」。
- team_leadership:evidenceFound 写出带人规模+组织动作+冲突处理(如「带 8 人迎新组完成 3 场活动」);gap 写「仅写社团成员/挂部长头衔,无带人规模与冲突处理实例」。
- frontline_resilience:evidenceFound 写出一线强度/周期+下沉意愿表态(如「连续 4 个月门店实习经历完整大促,明确接受轮岗倒班」);gap 写「全文流露只想做管理/办公室岗,对下店倒班只字不提或抵触」。
- service_compliance_mindset:evidenceFound 写出真实客诉案例与食安/防损意识(如「处理顾客退换投诉并推动流程改进,持健康证」);gap 写「服务意识全是形容词无真实顾客场景」或「餐饮岗无任何食安/卫生意识体现」。

② 校招语境下为何重要:必须说明该维度在门店管培校招的实际筛选作用——门店一线实操是该岗第一看点(储备店长是从店里长出来的,无真门店实务=零起点);经营数据意识区分『会干活的店员』与『能当店长的管培』(店长本质是经营者,看的是坪效人效这门生意);带团队是储备店长的核心职责(提前预定的店长,不会带人=不能晋升);一线韧性与下沉意愿决定留存(企业最大成本是管培干两天跑路,不愿倒班下店直接淘汰);服务与合规是直面顾客岗的底线(无服务案例=空谈,餐饮无食安意识=高危)。

③ 命中反模式直接点名:若命中则直呼「收银台路过仔」「业绩提升靠感觉」「光杆司令挂名党」「空降总监预备役」「亲和力复读机」等,不得空泛说「有待提升」。

④ 分数对齐:store_operations_practice 无真门店人货场实务(只有传单/促销/纯收银)封顶不及格(该岗零起点);frontline_resilience 流露抵触下店倒班或明确只想坐办公室视为重大减分(留存高危,不得给中等以上);operating_metrics_literacy 通篇空话无任何指标数字只能算缺失;team_leadership 仅挂头衔无带人实例不得按领导力给分;service_compliance_mindset 给低分但不单独一票否决(属配合维度,餐饮线无食安意识可下调)。

禁止在 why 中出现「满分的X%」「给分不超过」「故给满分」「扣X分」等内部计算比例话术;why 只陈述简历事实、该岗筛选逻辑与反模式点名,不暴露打分公式。

## 改写指引（禁编造铁律）
严格遵循「禁编造」干净句式,绝不替候选人添加原句没有体现的能力、指标、品牌层级或带人规模:

1. 把简历「已有」的门店/学生工作经历讲精准:明确写出在人货场上做了什么(陈列/补货/盘点/排班/带新人/处理客诉)、用了什么标准或方法(原文提到的 SOP/盘点流程/排班逻辑)、影响了什么指标(原文出现过的坪效/人效/损耗率/连带率/客单价)。
   - 例:原句「协助门店日常运营」→ 改「在 [品牌门店] 参与 [原文提到的具体动作,如陈列与补货],并配合完成 [原文提到的环节,如周度盘点]」(品牌、动作、环节均须取自原文,缺则留占位或走 gap_advice)。

2. 用精准动词替换模糊词,但不得越级:原文写『协助/参与/配合』就保留,严禁夸大为『独立负责/主导/管理整店』;原文确写了自己带人/拍板才可用『带 N 人/牵头』。

3. 只在缺数字处用 [具体数字] 占位:如「将损耗率从 [具体数字]% 降到 [具体数字]%」「高峰带 [具体数字] 名员工排班」「连带率提升 [具体数字]」,让候选人自行填真实数字,绝不代填,也不凭空塞一个『提升 30%』。

4. 严禁编造能力与指标:简历没体现过的经营指标(坪效/人效/连带率/损耗率)、没碰过的工具(Excel 数据透视/BI/排班系统)、没带过的团队规模、没处理过的客诉案例,一律不得在改写中添加;不得把『纯收银/发传单』美化成『门店运营管理』;不得替候选人写出『接受倒班外派』的表态(这是意愿,须本人确认)。

5. 凡简历缺失的关键能力,一律走 gap_advice 给「建议补充」而非在 rewrite 里编造:
   - gap_advice 示例:「建议补充一段真实门店一线实习,并写明在人货场上的具体动作(陈列/盘点/排班/带新人)」「建议把『提升业绩』改为可量化的经营指标(如连带率/坪效/损耗率变化)并补充具体数字」「建议补充一段带团队/带班次的经历,写清带人规模与冲突处理」「建议在求职意向中明确表态接受门店一线轮岗与倒班(若属实)」「建议补充一个真实处理顾客投诉的案例;餐饮岗补充食安/卫生相关意识或健康证」。

## 本土惯例与硬规则
出局级硬规则:
- 不接受门店一线轮岗/倒班/周末节假日在岗/跨城外派:储备店长本质是从店里干起,明确不愿下店或流露『只想做管理/办公室岗』者,绝大多数连锁直接淘汰(企业最怕管培入职即闪退)。
- 无任何真实门店/服务业一线经历(只有发传单、纯促销、纯收银兼职):对该岗等于零起点,头部连锁管培(优衣库 UMC/百胜/星巴克/海底捞等)基本过滤。
- 学历/全日制不达岗位最低门槛(本科或大专按企业要求,部分头部连锁卡 211/985 或一本线):硬性出局。
- 餐饮线缺健康证/无任何食安卫生意识、或体检不合格(传染病等):上岗硬门槛,不可回避。
- 简历造假(虚构门店实习/编造指标):连锁企业背调+试用期一线轮岗当场暴露,直接淘汰并可能列入用工黑名单。

经营能力优先级(门店管培明确共识):
1. 真实门店一线人货场实操 > 一切——储备店长是从店里长出来的,这是第一硬通货。
2. 经营数据/坪效人效意识——区分『会干活的店员』和『能当店长的管培』,第二位。
3. 带团队/学生组织负责人经历——储备店长核心职责,第三位。
4. 一线韧性与下沉意愿(可倒班/可外派)——决定留存,企业反复确认。
5. 服务意识+食安/防损/SOP 合规——直面顾客岗底线,配合性硬要求。

格式偏好:
- 门店一线实习经历放简历首屏第一看点,品牌全称+门店/岗位+起止+人货场动作量化产出,而非埋在『其他经历』。
- 经营指标(坪效/人效/连带率/损耗率/客单价)与数字绑定动作出现,不单列名词。
- 应届生简历 1 页为宜,求职意向写明接受门店一线轮岗与可外派城市。
- 普通话标准、表达清晰、形象得体是直面顾客岗的隐性门槛,可在自我评价点到。

加分项(门店管培特有):
- 知名连锁门店管培/储备岗实习(优衣库 UMC、百胜餐厅管理培训生、星巴克储备经理、名创/盒马/山姆/沃尔玛门店管培、海底捞储备干部)——背景直接对口。
- 用 Excel/BI 做过门店经营数据分析(时段人效、品类连带、损耗盘点),或接触过数字化排班/收银后台。
- 学生组织/社团/活动总负责人,带过 5 人以上团队并处理过真实分歧。
- 餐饮线:健康证、食品安全管理员培训;零售线:防损/陈列相关培训或竞赛。
- 真实可讲的客诉/突发处理案例,体现服务意识与应变。
- 接受跨城外派、可倒班、能扛大促旺季的明确表态(企业最在意的留存信号)。
