# 风险咨询(内控/合规)（风险咨询(内控/合规) · 校招(压力版 · 高标准)）

> 校招职业标尺 · 难度档：`pressure` · 预设ID：`risk-advisory-campus-anthropic`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 乙方内控/合规项目全闭环×个人实质承担（满分 30）
- **好的样子**：对标四大 Risk Advisory 真实门槛:有乙方风险咨询 / 内控 / 合规实习,机构层级清晰(德勤风险咨询 / 普华永道 Risk Assurance / 安永 Consulting-Risk / 毕马威风险咨询最佳,内资八大风险线、头部券商合规风控次之),且能讲清一个完整闭环——流程梳理(narrative/flowchart)→ 穿行测试(walkthrough)→ 控制测试(test of controls)→ 内控缺陷识别与分级 → 整改建议。能说清自己在项目里独立做了什么(测了哪几个控制点、访谈了哪个流程、出了什么底稿与发现),并讲明乙方视角:按项目服务多家客户、对外出具发现与建议,而非常驻一家公司做日常内审。
- **应届证据**：实习经历栏写明机构全称 + 风险咨询 / 内控 / 合规部门 + 起止时间,每段 2–3 条 bullet 描述具体乙方动作与可量化产出(对 X 个业务循环做穿行测试、梳理 X 条风险控制矩阵、识别 X 项内控缺陷并提整改建议),并点明客户行业(如某制造业上市公司 SOX 项目),体现项目制服务多客户的乙方属性,且能复述一个项目从穿行测试到整改建议的完整逻辑。
- **常见缺失 / 反模式**：【反模式·装订底稿小王子】实习通篇打印、装订、扫描底稿,一个穿行测试 / 控制点 / 缺陷都说不出,录用官一眼看出是来打杂的,第一刀就砍这种「0 产出实习」;【反模式·甲乙方混淆】在一家公司做日常内审 / 合规台账却当成乙方咨询经验写,分不清按项目服务多客户与常驻一家做内审的区别;【反模式·测试名词空转】会说穿行测试 / 控制测试这些词,却讲不清自己测了哪个控制点、样本怎么抽、发现了什么缺陷。

### 2. 内控方法论与风险语言(COSO/SOX 闭环级)（满分 26）
- **好的样子**：能用风险咨询的专业语言而非纯会计语言表达对核心框架与方法的认知,并讲清「风险 — 控制 — 测试 — 缺陷 — 整改」的完整闭环逻辑:COSO 内部控制整合框架(五要素)、SOX 404 内控有效性、财政部《企业内部控制基本规范》及配套指引(国企 / 央企内控主线)、风险控制矩阵(RCM)、穿行测试与控制测试的区别、内控缺陷分级(重大 / 重要 / 一般缺陷)、业务循环(采购付款 / 销售收款 / 存货 / 财务报告)。合规方向另需反洗钱(AML/KYC / 可疑交易报告)、数据合规(个保法 / 数据安全法 / 最小必要原则)、内控与合规体系搭建逻辑。哪怕是「课设里对销售循环做过 RCM 梳理并识别职责分离缺陷」也胜过只会背会计分录。
- **应届证据**：在实习项目、课程设计、毕业论文中出现 COSO/SOX 404 / 企业内控基本规范 / RCM / 穿行测试 / 内控缺陷 / 业务循环 / 反洗钱 / 个保法等关键词,并说明自己在其中做了什么、理解了什么(如「在销售收款循环识别职责分离缺陷并建议增设复核控制」),而非纯名词罗列。
- **常见缺失 / 反模式**：【反模式·会计搬运工】满简历是「做账、出报表、对账」,COSO / 控制点 / 缺陷一个字说不出,录用官看穿「只会算账不懂控制」,而内控咨询恰恰不是做账;【反模式·框架名词堆】框架名词列一排却讲不出穿行测试与控制测试的区别、缺陷怎么分级;【反模式·闭环断链】只会说「梳理了风险」却接不上控制设计、测试、缺陷分级与整改建议的下半段。

### 3. 证书体系聚焦度×子方向匹配(已过科目级)（满分 16）
- **好的样子**：证书体系聚焦在内控 / 审计 / 风险主线且与目标子方向匹配:Business Risk(内控 / 财务流程)优先 CPA、ACCA、CIA;IT Risk(IT 审计 / 数据合规)优先 CISA、CISP;Compliance(反洗钱 / 合规)优先法律背景 + CAMS、法考。应届不要求过证,但压力版只认「已通过 CPA X 科 / CIA Part 1 已过」这类有进度的硬信号,「在考 CISA」可写但需与目标方向呼应。证书与实习 / 课程方向一致,体现「认准内控 / 合规这条路」的聚焦感。
- **应届证据**：证书栏写明体系与进度(如「CPA 已过会计、审计 2 科」「CIA 已通过 Part 1」「CISA 备考中」),并与目标子方向呼应(应聘 IT Risk 就突出 CISA / 计算机背景);证书与实习 / 课程方向一致。
- **常见缺失 / 反模式**：【反模式·考证集邮册】证书栏像集邮,CPA/CFA/FRM/CMA/ 教资全列却没一个过、没一个对口,录用官看到的不是上进是「方向都没想清楚」;【反模式·零进度备考】只写「正在备考会计相关证书」零已过科目;【反模式·错配证书当主打】拿与岗位无关的证(如 CFA 之于纯内控)当主打,暴露对子方向认知不清。

### 4. 学历专业匹配与英语能力(四大网申英语门槛)（满分 14）
- **好的样子**：本 / 硕为会计、审计、财务管理、法律(合规方向)、统计 / 数学(风险建模方向)、信息系统 / 计算机(IT Risk 方向)等匹配专业,院校达四大网申门槛(双一流 / 财经强校 / 海外名校优先,但四大对院校相对包容,实习与素质可补)。英语是硬门槛:四大网申 OT 在线测评、底稿、客户沟通多为英文,六级 / 雅思托福成绩或英文实习经历应体现;CET-6 高分、ACCA(英文)是加分信号。全日制双证可按时取得。
- **应届证据**：教育背景栏写明院校 + 专业(标注与内控 / 合规 / IT / 风险的相关方向)+ 全日制 + 预计毕业时间 + GPA(四大看重但非唯一);英语能力单列或在证书栏体现(六级分数 / 雅思 / 托福 / ACCA),有英文项目或全英课程经历可点明。
- **常见缺失 / 反模式**：【反模式·荣誉墙搬运工】简历半页都是「优秀学生干部」「校歌比赛三等奖」「献血证书」与内控合规零关联,把无关荣誉当卖点,四大 HR 明说罗列无关荣誉只会减分;【反模式·专业空挂】专业完全不沾财会 / 法律 / 统计 / 计算机,又无证书无对口实习补匹配度;【反模式·英语真空】英语只字未提,而四大网申 OT 与底稿都是英文,卡在 OT 环节硬出局。

### 5. 工具与底稿文档能力(Excel/流程图×结构化表达)（满分 14）
- **好的样子**：Excel 作为门槛默认熟练(数据透视、VLOOKUP、基础函数用于测试样本与控制台账);能用 Visio / 流程图工具画业务流程图;PPT/Word 用于出具内控报告、整改建议、底稿;IT Risk 方向另需 SQL 取数与基础数据分析,数据合规岗对 Python / 数据治理工具有接触是加分;具备结构化、规范的底稿与文档表达能力(乙方对客户出具物的专业性要求高)。每项工具都绑定「用它做了什么测试 / 梳理 / 出具」的具体场景。
- **应届证据**：在实习 / 课程项目里写「用 Excel 完成 X 项控制点的测试抽样与台账」「用 Visio 绘制采购付款循环流程图」「用 SQL 取数支持某合规分析」,工具与产出绑定出现;条理化的底稿 / 报告排版能力可通过项目报告、竞赛作品体现,而非单独一栏列「精通 Office」。
- **常见缺失 / 反模式**：【反模式·精通牌复读机】技能栏一排「精通 Excel / 熟练 SQL / 了解 Python」正文零项目佐证,连一次穿行测试的样本怎么抽都说不清,录用官当场识破「技能栏是抄的」;【反模式·会记账不会测试】只会用 Excel 记账,不会做控制测试样本与台账;【反模式·底稿无章法】产出的文档 / 底稿排版散乱、无结构化表达,不符合乙方对客户出具物的专业性要求。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实,按以下结构展开,分数与 why 严格一致:① 命中 / 缺失事实(写进 evidenceFound / gap)——control_project_full_loop 写机构层级 + 乙方项目制的具体动作与完整闭环(如「德勤风险咨询,参与某制造业上市公司 SOX 404 内控测试,做了采购循环穿行测试并识别 X 项缺陷」),gap 写「仅有出纳 / 记账 / 行政实习无内控合规岗经历」或「实习只有『协助装订底稿』无任何项目实质」或「把单家公司日常内审当乙方咨询经验」;coso_sox_methodology 写命中的框架与参与内容及闭环逻辑,gap 写「全文只有会计术语无 COSO/SOX / 控制点 / 缺陷等风险语言」或「只会说梳理风险接不上测试与整改」;certification_focus 写体系 + 已过科目 + 方向匹配,gap 写「CPA+CFA+FRM+ 教资混堆方向不聚焦」或「仅写备考无任何已过科目」;education_major_english 写院校 + 专业方向 + 英语,gap 写「专业与内控合规零关联且无证书无实习补足」或「英语只字未提」;tools_workpaper 写工具 + 绑定的测试 / 梳理场景,gap 写「技能栏列 Excel/SQL 但正文零项目佐证」。② 校招语境下为何重要:乙方内控 / 合规项目全闭环是录用官筛选第一位且不可被纯财务 / 单家公司内审实习替代(乙方看的是项目制服务多客户的能力);方法论与框架认知决定你是「内控顾问」还是「高级会计」;证书体现方向聚焦度(集邮式堆证反而减分);学历专业是隐形筛选线、英语是四大网申硬门槛;工具与底稿文档能力是乙方对客户出具物专业性的基本盘。③ 命中反模式直接点名(装订底稿小王子 / 甲乙方混淆 / 测试名词空转 / 会计搬运工 / 框架名词堆 / 闭环断链 / 考证集邮册 / 零进度备考 / 错配证书当主打 / 荣誉墙搬运工 / 专业空挂 / 英语真空 / 精通牌复读机 / 会记账不会测试 / 底稿无章法),不得空泛说「有待提升」。分数对齐:control_project_full_loop 仅有出纳 / 记账 / 行政等无关实习不得给中等以上分,把单家公司内审当乙方咨询经验需在 gap 点破并扣分;coso_sox_methodology 全文零风险 / 控制语言给低分;certification_focus 集邮式混堆多证且零对口已过科目按方向不聚焦扣分;education_major_english 英语只字未提需点破;tools_workpaper 工具无项目佐证只能算缺失。严禁在 why 中出现「满分的 X% / 给分不超过 / 故给满分 / 扣 X 分」等内部计算比例话术,只陈述简历事实、反模式诨名与缺口。

## 改写指引（禁编造铁律）
严格遵循「禁编造」干净句式,绝不替候选人添加原句没有体现的能力、框架名词、客户层级或项目动作:1. 把简历「已有」的内控 / 合规实习与项目句讲精准:明确写出做了什么乙方动作(穿行测试 / 控制测试 / 流程梳理 / RCM 梳理 / 缺陷识别与整改建议 / 合规尽调)、针对哪个业务循环或客户、量级多大(测了 X 个控制点、梳理 X 条风险控制矩阵、覆盖 X 个业务循环);例:「参与风险咨询相关工作」→「在 [机构] 风险咨询部参与 [客户行业] 的 [原文已提及的项目类型,如 SOX 内控测试],对 [原文已提及的业务循环] 完成 [具体环节]」(机构、客户、循环、动作均须取自原文,缺则留占位或走 gap_advice)。2. 用精准动词替换模糊词但不得越级:原文「协助 / 参与」就保留「参与」,严禁夸大为「独立负责 / 主导项目」;绝不把「装订底稿」美化成「参与内控测试」——那是编造。3. 只在缺数字处用 [具体数字] 占位(如「对 [具体数字] 个控制点完成控制测试」「梳理 [具体数字] 条风险控制矩阵」),让候选人自填真实数字绝不代填。4. 严禁编造能力:简历没写过 COSO/SOX / 穿行测试 /RCM / 某证书 / 某工具一律不得添加;没体现过的客户层级、项目类型、合规框架、英语能力不得凭空生成;不得把甲方单家公司内审改写成乙方多客户咨询。5. 凡简历缺失的关键能力一律走 gap_advice:如「建议补充一段四大或内资所风险咨询 / 内控岗实习,并写明参与的具体项目动作(如穿行测试、控制测试、RCM 梳理)」「建议在项目描述中补充对 COSO/SOX 或企业内控基本规范的认知体现」「建议补充已通过的对口证书科目(如 CPA 审计、CIA Part 1)」「建议补充英语能力(四大网申 OT 与底稿为英文)」「建议补充用 Excel/Visio 完成内控测试或流程梳理的具体场景」。

## 本土惯例与硬规则
出局级硬规则(压力版从严):
- 全程零内控 / 合规 / 风险相关实习与项目,简历只有出纳 / 记账 / 行政 / 纯销售类经历:四大 Risk Advisory 等乙方机构基本直接过滤,履历看不到「项目制做控制」的影子。
- 英语完全无法满足:四大网申 OT 为全英、底稿与部分客户沟通需英文,英语过弱者卡在网申 /OT 环节硬出局。
- 非全日制学历 / 无法按时拿到毕业证 + 学位证双证:四大及国企客户驻场项目硬性出局。
- 简历虚假信息:四大背景调查严格,把装订底稿写成内控测试、把单家公司内审包装成乙方咨询项目,一经背调 / 面试追问穿帮即出局。
证书优先级(按子方向):1. CPA(财会 / 审计主线)、ACCA——Business Risk 首选,含金量与对口度最高;2. CIA——内审 / 内控认可度高,与风险咨询直接对口;3. CISA——IT Risk / IT 审计 / 数据合规方向首选,计算机 / 信息系统背景配 CISA 是稀缺组合;4. CAMS + 法考 / 法律背景——Compliance(反洗钱 / 合规)方向加分;5. 明确反信号:CFA、FRM 之于纯内控 / 合规岗不加分,与 CPA/CIA 并排堆砌反而暴露方向不聚焦;教资、与岗位无关证书一律删。
格式偏好:
- 四大走网申系统,简历本科 1 页、研究生最多 2 页,中英文版本常需各备一份(底稿英文环境)。
- 实习经历(机构层级×项目动作)、专业匹配、证书方向三项应在首屏可见。
- 实习与项目描述用「动作—对象—产出」结构(如「对采购循环做穿行测试 → 识别 X 项缺陷 → 提整改建议」),避免只写「参与 / 协助」无产出。
- 区分甲乙方:乙方咨询要点明「服务的客户行业 / 项目」,不要写成像在一家公司当员工。
加分项:四大 Risk Advisory 或内资八大风险 / 内控线实习,能讲清一个完整项目(穿行测试→控制测试→缺陷→整改);已过对口证书科目(CPA 审计 / 会计、CIA Part 1、CISA 单科)+ 方向一致;IT Risk 方向:计算机 / 信息系统背景 + SQL / 数据分析 + CISA 稀缺组合;合规方向:法律背景 + 个保法 / 数据安全法 / 反洗钱认知 + CAMS;英语突出(六级高分 / 雅思托福 / ACCA 英文 / 全英项目);财会 / 审计类竞赛、内控案例大赛、参与过企业内控制度梳理的课程设计。
反信号:实习通篇「装订底稿、打印、扫描、整理文件」无任何项目实质;简历只有会计 / 做账语言零 COSO/SOX / 控制点 / 缺陷术语;证书集邮式堆砌却零对口已过科目;罗列大量与岗位无关的校园荣誉、社团头衔稀释专业信号;把甲方单家公司日常内审 / 合规台账包装成乙方咨询项目混淆甲乙方视角。
