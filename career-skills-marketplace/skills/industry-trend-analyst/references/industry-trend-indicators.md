# 行业趋势指标体系

## 增长信号类别

| 类别 | 具体指标 | 可信来源 |
|------|----------|----------|
| 政策信号 | 工信部/发改委政策文件、专项支持计划 | A 级（政府官网） |
| 资本信号 | 一级市场融资金额/轮次、投资机构关注度 | A/B 级（36氪/IT桔子） |
| 就业信号 | 招聘平台岗位增长量 | B 级（via market-radar） |
| 收入信号 | 行业龙头营收增长率 | A/B 级（财报） |

## 风险信号类别

| 类别 | 具体指标 | 严重度 |
|------|----------|--------|
| 政策收紧 | 专项整治/监管趋严 | high |
| 市场饱和 | 用户增长停滞、价格战加剧 | medium |
| 资本撤退 | 融资金额/轮次下降趋势 | medium |
| 人才外流 | 行业人才净流出 | medium |
| 龙头裁员 | 头部公司大规模裁员 | high |

## 招聘前景评级

| 等级 | 定义 |
|------|------|
| strong | 招聘量增长 30%+，供不应求 |
| growing | 招聘量增长 10-30% |
| stable | 招聘量平稳，±10% |
| declining | 招聘量下降 10-30% |
| contracting | 招聘量下降 30%+，大规模裁员 |
| unknown | 无实时数据 |

## 中国行业特有考量

- **政策导向**：中国行业发展与政府政策高度相关（新能源/AI/半导体）
- **赛季性**：春节后（3-4月）和秋招季（8-11月）数据有季节性偏差
- **城市集中度**：部分行业（金融科技/AI）高度集中在一线城市，全国数据可能掩盖区域差异
