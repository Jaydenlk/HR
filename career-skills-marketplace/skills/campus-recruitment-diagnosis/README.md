# 校招简历诊断 · campus-recruitment-diagnosis

你的简历摆到目标岗位招聘官桌上,到底值几分?这个 skill 就回答这一件事。

它不灌鸡汤、不替你吹牛、更不帮你编。它更像一个看过几千份应届简历、嘴有点毒但绝对实诚的学长:按你想投那个职业**真实的校招标尺**,一项一项给你打分,告诉你差在哪、面试官会拿哪句话怼你、哪里该怎么改才不露馅。

> 只管校招、只管应届。社招 / 转行 / 中高级岗别用这个,去找 `match-diagnosis`。

## 它帮你做四件事

**① 按职业标尺打分** —— 不是泛泛地评"简历好不好",而是拿你目标职业(后端?投行?HRBP?)那套专属的五个维度逐条量。每维多少分、为什么扣、扣在你哪句话上,都摊开说。覆盖 11 大类、**90 个校招职业**。

**② 照中国校招的潜规则过一遍** —— 技术栈写"精通"还是"熟悉"有讲究,项目没 GitHub、没像样实习会被怎么看,竞赛谁含金量高……这些招聘官心里有数、你却未必知道的事,逐条标:稳 / 悬 / 危。

**③ 提前把面试官的刀亮给你看** —— 简历里虚的、容易被追问穿帮的地方,先替面试官把问题问出来,再告诉你怎么**真**准备。是帮你补真本事,不是教你圆谎。

**④ 帮你改,但一个字都不替你编**(这步得你点头才动)—— 只打磨你**已经写了**的句子,让它更准、更有劲。简历里没有的数字、没干过的活、没碰过的技术?它不会替你写上去,只会说"这块你要真做过,可以这么写;没做过先别写,面试一问就穿"。

## 用之前,给它两样东西

就两样是必须的:**简历正文** + **目标职业**。

- 简历把经历、项目、技能、**竞赛荣誉**都贴全 —— 尤其六级 552 分、ACM 银牌这种,**原文的分数名次照搬上来**,它会老老实实读进去算分;你嫌麻烦不写,亏的是自己的分。
- 职业写中文就行("后端开发""投行(IBD)")。你要是自己也没想好投哪,把简历丢给它,它从你经历里挑一两个让你二选一。
- 想被往狠里批(冲大厂练心态),说一句"开压力档";默认是对应届友好的 standard。
- 有目标 JD 也能贴,但只当背景参考,不会动评分的标尺。

没简历它不瞎评,会先让你贴;职业没填它不硬猜,先跟你对一下。

## 它会还你什么

一份能直接用的诊断:总分 + 每维的分数 / 理由 / 你简历里的原话 / 差距,加本土惯例核查、面试追问清单、(你确认后的)改写建议,最后压一段**诚实边界** —— 把"这次做了啥、没做啥、哪些建议得你真具备了再往上写"说在明面上。

字段长啥样看 `output_schema.json`;实际跑起来什么效果,`examples/` 里有五个场景:强简历、弱背景、自相矛盾、乱填、以及"想让它帮我吹个牛"——最后这个它会当场拒绝。

## 一条死规矩:不帮你编

这是它的底线,也是它跟满大街"AI 简历优化器"最不一样的地方:

- **数字**:改写句里每个数,你简历原文得能逐字找到;找不到就写 `[具体数字]` 占位,你自己填真的。
- **能力**:你没有的实习 / 技术 / 方法,只进"建议补充"并标**面试穿帮风险**,绝不混进"优化句"里假装你有。
- **兜底**:交付前还有个脚本 (`scripts/check_fabrication.mjs`) 机械地再查一遍,把漏网的编造揪出来。
- **读取**:你写明的名次 / 分数 / Star 数照抄计入,不会自作主张判"没写分=分不高"。

标尺按截至模型知识更新时的中国校招行情定;具体公司当季要求会变,最终以官方 JD 为准。
