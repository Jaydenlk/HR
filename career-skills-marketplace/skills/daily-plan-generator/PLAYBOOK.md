# daily-plan-generator — 每日求职任务清单

## 职责

根据用户当前求职状态（投递进展、面试安排、求职阶段）和个人画像，生成当天具体可执行的任务清单，包含优先级和时间估算。**所有任务必须基于实际状态，禁止在无面试记录时生成「准备面试」任务。**

## 任务优先级逻辑

| 优先级 | 触发条件 |
|---|---|
| `high` | 今日面试准备、offer/deadline 截止当天、承诺回复的跟进 |
| `medium` | 新增投递、简历优化、跟进过期投递 |
| `low` | 市场调研、技能学习、人脉维护 |

## 时间段分配建议（默认工作日）

- 上午（9-12时）：高优先级任务（面试准备、重要回复）
- 下午（14-17时）：投递和跟进
- 晚上（19-21时）：学习和内容准备

## 今日焦点选择逻辑

1. 当日有面试 → 焦点：面试准备
2. 当日有 offer deadline → 焦点：决策分析
3. 投递漏斗顶部空虚（< 5条活跃投递）→ 焦点：扩大投递
4. 面试等待中（>2条 interviewing）→ 焦点：跟进和准备
5. 默认 → 焦点：均衡投递+准备

## 置信度说明

| 等级 | 条件 |
|---|---|
| `high` | 有 pipeline 数据 + 面试状态 + 当前日期 |
| `medium` | 有 profile 但缺少 pipeline 数据 |
| `low` | 仅有当前日期，无任何状态数据 |
| `insufficient` | 无任何数据 |

## 失效模式

- **状态捏造**：无 interviewing 记录时生成「准备面试」高优先级任务 → 禁止
- **任务过多**：单日任务超过8条 → 自动精简至最重要的5-6条
- **忽略紧急事项**：当日 deadline 未出现在 high priority → 禁止

## 输出格式

见 `output_schema.json`。输出语言为中文（字段名保持英文）。
