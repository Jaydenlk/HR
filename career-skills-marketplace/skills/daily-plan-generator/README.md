# daily-plan-generator — 每日求职任务清单

## 概述

根据当前求职状态（面试安排、投递进展、待办事项）和用户画像，生成当天具体可执行的任务清单。每条任务含优先级和时间估算，总任务数不超过6条，聚焦而非全面。

## 适用场景

- 每天早上规划求职任务
- 有面试当天，需要安排其余时间
- 求职进展停滞，需要具体的下一步行动
- 待办事项积压，需要优先级排序

## 输入数据

| 字段 | 必须 | 说明 |
|---|---|---|
| `current_date` | 必须 | 当前日期，用于判断面试和deadline |
| `user_profile` | 推荐 | profile-builder 输出 |
| `pipeline_state` | 推荐 | application-tracker 漏斗状态 |
| `today_interviews` | 可选 | 今日面试列表 |
| `pending_actions` | 可选 | 紧急待办事项 |

## 优先级逻辑

| 优先级 | 触发条件 |
|---|---|
| high | 今日面试、offer deadline、承诺的跟进 |
| medium | 新增投递、过期跟进、简历优化 |
| low | 技能学习、市场调研、人脉维护 |

## 今日焦点

系统根据当前状态自动确定今日焦点：
- 有面试 → 面试准备
- 漏斗顶部空虚 → 扩大投递量
- 有过期跟进 → 跟进现有投递
- 有offer deadline → offer决策

## 重要限制

- 任务总数不超过6条：聚焦比全面更重要
- 无面试数据时不生成高优先级「面试准备」任务
- deadline 任务强制为高优先级

## 依赖

- `profile-builder` — 用户画像（可选）
- `application-tracker` — 漏斗状态（可选）
