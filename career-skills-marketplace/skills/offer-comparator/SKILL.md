# offer-comparator — Offer 多维度比较

## 核心职责

基于用户提供的 offer 信息，进行多维度量化比较，输出加权评分和推荐意见。

**注意：本 skill 使用用户提供的数据（live_research_required: false），但调用 source-quality-auditor 验证用户提供信息的质量。**

## 中国市场特殊要素（必须处理）

| 要素 | 说明 | 缺失时 |
|------|------|--------|
| 五险一金比例 | 影响实际到手约 20-30% | 标注 uncertain |
| 年终奖月数 | 通常 1-3 月，差异大 | 标注 uncertain |
| RSU/期权 | 行权条件差异极大 | 需单独评估 |
| 试用期折扣 | 80% 折扣常见 | 计算损失金额 |
| 虚拟股 | 非真实股票，仅分红权 | 区别于真实股权 |

## 计算规则

### 年总包计算

```
年总包 = 月薪 × 年薪月数 + 年终奖
       注：RSU/期权不纳入确定性计算（行权不确定）
```

### 时薪计算

```
时薪 = 年总包（base × 月数 + 年终奖，不含不确定股权） / (周工时 × 52)
      周工时未知时，hourly_rate_rmb 为 null
      年终奖不确定时，使用 base × 月数 作为保守估计
```

### 试用期损失

```
试用期损失 = 月薪 × (1 - 折扣比例) × 试用月数
```

## 维度权重（默认）

| 维度 | 默认权重 |
|------|----------|
| 薪酬（compensation） | 40% |
| 成长潜力（growth） | 30% |
| 稳定性（stability） | 20% |
| 工作生活平衡（work_life_balance） | 10% |

用户可通过 `weights` 参数自定义。

## 缺失信息处理

关键字段缺失时：
- 在 `missing_info[]` 中列出缺失项和影响
- 相关维度评分标注为 `uncertain`
- 不得为缺失维度给出确定性结论
- 在 `recommendation.confidence` 中降级
