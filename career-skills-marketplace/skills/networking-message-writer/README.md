# networking-message-writer — 人脉消息生成

## 概述

根据候选人画像、目标岗位、联系人关系类型和沟通平台，生成真诚得体的人脉联系/内推申请消息。支持微信、脉脉、LinkedIn、邮件四种渠道。

## 适用场景

- 在脉脉/微信向弱关系联系人申请内推
- 在LinkedIn向陌生人请教职位情况
- 激活沉默多年的校友/前同事关系
- 通过共同朋友介绍后的第一次联系

## 平台差异

| 平台 | 字数 | 语气 | 特点 |
|---|---|---|---|
| 微信 | 50-100字 | 随和自然 | 熟人场景，直接说意图 |
| 脉脉 | 100-150字 | 职业友好 | 说明来意+展示共同点 |
| LinkedIn | 100-200字 | 专业简洁 | 可用中英双语，附个人链接 |
| 邮件 | 200-400字 | 正式完整 | 主题明确，附简历 |

## 必须输入

- `target_company`：目标公司
- `target_position`：目标职位
- `platform`：发送平台

## 生成原则

1. 真诚：不虚构关系或共同背景
2. 得体：给对方退路，不施压
3. 简洁：对方时间宝贵，不啰嗦
4. 具体：说明自己是谁、想要什么、有什么回报价值

## 重要限制

- 不生成虚假关系声明
- 不虚构共同经历
- 不使用「尊敬的XXX」等过时措辞
- 单条消息只提一个请求

## 依赖

- `profile-builder` — 用户画像（可选，缺少时生成通用版本）
