## 输入

```json
{
  "target_company": "字节跳动",
  "target_position": "后端工程师",
  "platform": "maimai",
  "user_profile": {
    "years_of_experience": 3,
    "skills": ["Java", "Spring Boot", "高并发系统"],
    "education": "某985大学，计算机科学，2021届",
    "highlights": ["主导过日活500万的交易系统重构", "有分布式系统实战经验"]
  },
  "contact_info": {
    "name": "李明",
    "title": "高级工程师",
    "relationship": "alumni"
  }
}
```
