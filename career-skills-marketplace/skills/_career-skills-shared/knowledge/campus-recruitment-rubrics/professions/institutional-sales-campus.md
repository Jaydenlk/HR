# 机构销售/交易(FICC)（机构销售/交易(FICC) · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`institutional-sales-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 前台对客实习经历（机构层级×台子相关性）（满分 28）
- **好的样子**：有真实的前台对客实习,且台子相关性强:券商固收/FICC销售交易部、机构业务部(机构客户覆盖)、衍生品/场外交易台为最强;头部公募/保险/银行金融市场部的交易/投资台、卖方固收研究次之。机构层级清晰(中信/中金/华泰/银河/中信建投总部最佳,头部公募固收次之)。任务写得出实质:跟过哪类机构客户(银行/保险/公募/私募/理财子)、协助过什么产品的询价报价、整理过哪些债券/利率/衍生品的盘面与持仓、做过什么客户需求对接或路演材料。能说清自己独立产出了什么(整理了什么数据、对接了哪类客户、跟了哪些成交)。
- **应届证据**：实习经历栏写明机构全称+具体部门(固收销售交易部/机构业务部/金融市场部)+起止时间,每段用 2-3 条 bullet 写清对接的客户类型、参与的产品(国债/信用债/利率互换/收益凭证等)与可量化产出(如协助覆盖 X 类机构客户、整理 X 只债券盘面、跟踪 X 笔询价),而非一句「参与销售交易相关工作」。
- **常见缺失 / 反模式**：用银行柜台、营业部经纪、零售理财、保险个险销售冒充机构销售/交易经验,以为「金融/销售沾边」就够,实则面向个人客户与机构对客是两套打法;或在分公司/营业部做了与FICC无关的开户拉新却美化成「机构客户开发」,一问对接过哪类机构、什么产品就露馅。【反模式·零售冒机构哥:拿营业部拉客户、卖理财产品的零售经历往机构销售上贴,觉得都是销售就能算,录用官第一刀就砍这种「客户根本不是同一拨人」的硬伤】

### 2. FICC 产品与市场认知（品种×交易语言）（满分 26）
- **好的样子**：能用业务语言体现对 FICC 核心品种的认知:固定收益(国债/政金债/信用债/同业存单、久期/凸性/收益率曲线/利差)、利率与外汇(利率互换IRS/国债期货/远期/掉期)、商品及衍生品(场外期权/收益凭证/雪球结构)、银行间与交易所两个市场的基本规则与参与机构。理解一级承销分销与二级做市/撮合的差别,知道机构客户(银行自营/保险/公募/理财子/私募)各自的配置诉求。哪怕是「课程/实习中跟踪过收益率曲线变动」「研究过某类信用债利差」也胜过零产品认知。区分得清销售(客户覆盖/产品营销)与交易(报价/做市/头寸管理)各自做什么。
- **应届证据**：在实习项目、课程设计、毕业论文、模拟交易或行研中出现久期/收益率曲线/利差/IRS/国债期货/雪球/银行间市场等关键词,并说明自己在其中分析了什么、得出什么结论;或在自述中清晰写出对某类机构客户配置需求的理解,而非纯名词罗列。
- **常见缺失 / 反模式**：全简历找不到一个 FICC 品种或市场术语,只有泛泛的「对金融市场感兴趣」「熟悉资本市场」;或把权益选股、价值投资那一套搬过来,显示其实不懂固收交易语言。【反模式·宏观大词侠:满嘴「看好债市」「利率下行」却说不出久期、利差、做市、银行间这些干活用的词,录用官一问「这只债你会怎么报价」就哑了】

### 3. 对客软实力与销售思维（沟通×抗压×客户导向）（满分 18）
- **好的样子**：机构销售/交易是前台对客岗,软实力是硬通货而非点缀:有可佐证的对客沟通/资源整合/抗压经历(如带队拉过赞助/做过 BD/路演主讲/大型活动对接外部机构),能体现「服务客户、做生意」的卖方思维而非「我要自己投资赚钱」的买方思维。语言能力(英语流利,外资/跨境台子另需)。能讲出一个把复杂信息讲清楚、推动对方决策、在压力下交付的具体故事。交易岗另需体现快速反应、对数字与盘面的敏感、情绪稳定。
- **应届证据**：在社团/学生工作/商赛/实习里写出对客或销售性质的具体事件:对接了多少家外部机构/赞助商、组织了多大规模的活动、在多紧的时间内完成了什么交付,并落到可量化结果(拉到 X 元赞助、覆盖 X 家单位、转化率/达成率多少),而非空写「沟通能力强、抗压能力强」。
- **常见缺失 / 反模式**：通篇只在技能栏自评「沟通能力强/抗压能力强/有团队精神」,正文零事件支撑;或全程表现出的是买方投资思维(只谈自己怎么选股选债赚了多少),与卖方服务客户的岗位本质错位。【反模式·形容词战士:把「沟通强、抗压强、执行力强」当成果写一排,却拿不出一件对客或销售的真事,面试官追问「举个例子」就空白】【反模式·买方上身癌:简历满屏「模拟盘收益率」「我的投资逻辑」,却忘了这岗是替机构客户做生意不是自己炒,卖方思维缺位直接被判错位】

### 4. 院校学历与专业匹配度（满分 16）
- **好的样子**：头部券商FICC/机构口径越来越以重点院校全日制硕士为基本门槛,本科为强校亦有机会;专业以金融、经济、金融工程、数学、统计为主,计算机/理工背景在交易/衍生品台子受欢迎。全日制双证可按时拿到。GPA 与核心课(固定收益、金融衍生品、随机过程、计量、概率统计)成绩可佐证基本功。海外名校金融硕士在外资/跨境台子有优势。专业匹配度:金融/金融工程≈数学统计>经济>其他理工(需用实习与产品认知补足)。
- **应届证据**：教育背景栏写明院校+专业+全日制+预计毕业时间,附 GPA 及排名,列出固定收益、金融衍生品、计量经济、随机过程等相关核心课程成绩;海外/交换经历与语言成绩(托福/雅思/GRE)如有则列出。
- **常见缺失 / 反模式**：院校专业达标但把全部精力堆在刷 GPA 上,零前台实习也零产品认知,对头部FICC岗仍是低竞争力;或专业完全无关又无证书、无实习、无产品认知来补匹配度。【反模式·绩点孤勇者:以为名校加满绩点就能进交易台,简历除了成绩单空空如也,机构销售/交易看的是对客实习与盘感不是分数】

### 5. 金融工具实操与证书（满分 12）
- **好的样子**：终端类工具(Wind/iFinD/Bloomberg/Choice)是默认门槛,有真实取数/盯盘/做数据的场景佐证;Excel/VBA 默认具备;Python 在数据分析、债券/衍生品定价或量价分析上有真实项目/实习佐证(交易/衍生品台子权重更高,近年招聘明确写「熟练 Python」优先)。证书层面 CFA(已过一级/二级在进行中)对固收销售交易是加分而非门槛,证券/基金从业资格是入职合规要求需尽早考。每项工具都绑定一个「用它做了什么」的具体场景。
- **应届证据**：在实习/项目描述里写「用 Wind 提取并整理了 X 类债券的发行与成交数据」「用 Python 跑了××定价/量价分析」「用 Excel/VBA 搭建了××盯盘/测算表」,工具与产出绑定出现;证书栏写明已通过的从业资格、CFA 进度(如「CFA 一级已通过」)。
- **常见缺失 / 反模式**：技能栏写「精通 Python/Bloomberg/Wind」却全简历找不到一个用到它的项目,面试一问具体怎么取的数、跑的什么模型就露馅;或把 CFA「备考中」当成硬通货写在最显眼处却零已过级别。【反模式·精通牌吹牛皮:技能栏一排「精通/熟练」,正文零项目佐证,Bloomberg 写上去了却连终端长什么样都没见过,一问就穿】

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实,按以下结构展开,分数与 why 严格一致:

① 命中/缺失事实(写进 evidenceFound / gap):
- front_office_internship:evidenceFound 写出机构层级+台子+具体对客任务(如「中信证券固收销售交易部,协助覆盖银行/保险客户的信用债询价」);gap 写「仅有营业部零售/银行柜台/个险销售实习,无机构对客经历」或「实习描述只有『参与销售交易工作』无对接客户类型与产品实质」。
- ficc_product_knowledge:evidenceFound 写命中的品种与市场术语及参与内容(如「实习中跟踪国债收益率曲线、分析信用利差」);gap 写「全文无久期/利差/IRS/银行间等任何 FICC 术语,仅泛称『熟悉金融市场』」或「通篇权益选股语言,缺固收交易认知」。
- client_soft_skills:evidenceFound 写出可佐证的对客/销售/抗压事件与量化结果(如「带队对接 X 家赞助商拉到 X 元」);gap 写「软实力仅靠技能栏自评,正文零对客事件」或「全程买方投资视角,卖方服务思维缺位」。
- school_major_match:evidenceFound 写院校+专业+学历层次+GPA+相关核心课;gap 写「专业无关且无产品认知与前台实习补足」或「仅有 GPA 零前台实习」。
- tools_and_certs:evidenceFound 写工具+绑定的使用场景与证书进度(如「用 Wind 取债券成交数据,CFA 一级已通过」);gap 写「技能栏列 Python/Bloomberg 但正文零项目佐证」或「CFA 仅『备考中』无已过级别」。

② 校招语境下为何重要:必须说明该维度在 FICC 机构销售/交易校招的实际筛选作用——前台对客实习是录用官实际筛选第一位且不可被零售/柜台实习替代(客户群体根本不同);FICC 产品与市场认知是区分「真懂这行」与「只是想进金融」的分水岭,也是面试必考;对客软实力在本岗是硬通货(前台靠人做生意),买方思维错位会被直接判为方向不对;院校专业是头部机构的隐形筛选线(硕士渐成门槛);工具证书是加分与合规门槛,CFA 对本岗是加分非硬门槛。

③ 命中反模式直接点名:若命中则直呼「零售冒机构哥」「宏观大词侠」「形容词战士」「买方上身癌」「绩点孤勇者」「精通牌吹牛皮」,不得空泛说「有待提升」。

分数对齐:front_office_internship 仅有零售/柜台跨岗实习不得给中等以上分;ficc_product_knowledge 零品种术语给低分(显示不懂这行);client_soft_skills 软实力纯自评无事件按缺失处理,买方思维错位明确扣减;tools_and_certs 工具无佐证只能算缺失。why 中严禁出现「满分的X%」「给分不超过」「故给满分」「扣X分」等内部比例话术,只描述事实与缺口。

## 改写指引（禁编造铁律）
严格遵循「禁编造」干净句式,绝不替候选人添加原句没有体现的能力、产品名词、机构层级或客户类型:

1. 把简历「已有」的前台实习/项目句讲精准:明确写出对接了哪类机构客户、参与了什么产品(取自原文,如国债/信用债/利率互换/收益凭证)、做了什么环节(整理盘面/协助询价报价/对接客户需求/准备路演材料)、量级多大(覆盖 X 类客户、整理 X 只债券、跟踪 X 笔成交)。
   - 例:原句「参与销售交易相关工作」→ 改「在 [机构] 固收销售交易部协助覆盖 [原文已提及的客户类型] 的 [原文已提及的产品] 询价与盘面整理」(机构、客户类型、产品均须取自原文,缺则留占位或走 gap_advice)。

2. 用精准动词替换模糊词,但不得越级:原文写「协助/参与」就保留「协助」,严禁夸大为「独立负责/主导覆盖」;原文确写了独立产出才可用「独立完成」。

3. 只在缺数字处用 [具体数字] 占位:如「协助覆盖 [具体数字] 类机构客户」「整理 [具体数字] 只债券的成交盘面」,让候选人自行填真实数字,绝不代填。

4. 严禁编造能力:简历没写过的 FICC 品种、未提过的 Python/Wind/Bloomberg、未体现的客户类型或对客事件、未声明的 CFA 级别,一律不得在改写中添加;不得把零售/柜台经历的客户偷换成「机构客户」。

5. 凡简历缺失的关键能力(如无前台对客实习、无 FICC 产品术语、无对客软实力事件、无工具佐证、无已过 CFA 级别),一律走 gap_advice 给「建议补充」而非在 rewrite 里编造:
   - gap_advice 示例:「建议补充一段券商固收/机构业务前台实习并写明对接的客户类型与产品」「建议在项目或课程中补充对久期、收益率曲线或利率衍生品的具体认知」「建议补充一件能体现对客沟通与抗压的具体事件(如对接外部机构/路演主讲)并量化结果」「建议补充 Wind/Python 的实际使用场景」「建议补充已通过的从业资格或 CFA 级别」。

## 本土惯例与硬规则
出局级硬规则:
- 把零售/营业部/柜台/个险销售经历直接当作「机构销售/交易」经验包装:面向个人客户与面向机构对客是两套体系,录用官一眼识破,视为方向错位甚至包装造假。
- 非全日制学历 / 无法按时拿到毕业证+学位证双证:头部券商与国企硬性出局。
- 简历虚假信息(伪造实习、夸大客户层级/产品):券商通过背景调查与从业资格核验,一旦发现造假列入行业黑名单。
- 通篇买方投资思维(只谈自己模拟盘收益、个人投资逻辑)而无任何服务客户/做生意视角:与前台对客岗本质错位,头部机构销售/交易直接判不匹配。
- 头部券商FICC/机构口径渐以重点院校全日制硕士为基本门槛,本科需强校+硬核前台实习+产品认知方有竞争力。

证书与技能优先级:
1. 证券从业资格 / 基金从业资格 — 入职合规要求,应尽早通过,是基础门槛而非加分。
2. CFA(一级已过更佳,进度中亦可写)— 对固收销售交易是加分项而非硬门槛,体现固收/投资知识体系。
3. 终端工具(Wind/iFinD/Bloomberg/Choice)+ Excel/VBA — 默认门槛,须有使用场景佐证。
4. Python — 交易/衍生品台子权重更高,近年招聘明确写优先;须有定价/量价/数据分析的真实场景。
5. 明确反信号:CPA、教师资格、与本岗无关的一堆证书堆砌,暴露方向不聚焦;CFA 仅写「备考中」且零已过级别,加分有限。

格式偏好:
- 头部机构走网申系统,简历本科 1 页、研究生最多 2 页,中文为主(外资/跨境台子需中英双版)。
- 院校、前台对客实习机构层级、FICC 产品认知三项应在简历首屏可见(本岗最看重)。
- 实习描述须写清「对接的客户类型 + 参与的产品 + 量化产出」,而非泛泛「参与相关工作」。
- 投递邮件主题严格按「应聘岗位+姓名+院校」格式。

加分项(本岗特有):
- 券商固收/FICC销售交易部、机构业务部、头部公募固收交易台的真实前台实习(比学历本身更有说服力)。
- 模拟交易大赛/债市/衍生品相关竞赛获奖,或全国数学建模、CFA Research Challenge 等。
- 能体现对客与抗压的高质量学生工作(大型活动外联主讲、商赛、BD 拉赞助)并有量化结果。
- 英语流利(外资/跨境台子),或小语种对应特定区域客户。
- Python 用于债券/衍生品定价或量价分析的真实项目(交易台专项加分)。

反信号(本岗特有):
- 零售/柜台/个险销售经历冒充机构对客经验。
- 通篇买方投资视角(模拟盘收益、个人选股),缺卖方服务客户思维。
- 软实力只在技能栏自评,正文无任何对客或销售的真实事件。
- 满屏宏观大词(「看好债市」)却无久期/利差/做市等干活用的交易语言。
- 与本岗无关的证书与技能大量堆砌,显方向不聚焦。
