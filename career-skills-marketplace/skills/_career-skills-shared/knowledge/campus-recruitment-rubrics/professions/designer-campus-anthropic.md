# 设计师(UI/UX)（设计师(UI/UX)· 校招(压力版 · 高标准)）

> 校招职业标尺 · 难度档：`pressure` · 预设ID：`designer-campus-anthropic`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 作品集——设计决策链与可证伪性（满分 30）
- **好的样子**：对标头部大厂(字节/腾讯/阿里 UED、网易)用作品集前两个项目就要判定下限:每个核心项目能完整还原"问题来源→用户洞察→方案推导→交付→上线验证",且每一个视觉/交互决策都讲得出依据(为什么这个布局、为什么砍掉那个方案、和竞品差异在哪);作品集首屏 2 秒内能看出方向与最强项目,信息层级本身即一件作品;结论(最终稿)只占少数,推导链才是主体。
- **应届证据**：在线作品集(Figma Community / Behance / 站酷)+ PDF 主体,前两个项目详写决策推导而非堆页面;实习/竞赛项目写清"我做了哪个判断、为什么、被数据或评审证伪过没有";能就任一界面回答"如果这里改成X会牺牲什么"。
- **常见缺失 / 反模式**：【Anthropic 反模式·结论先行(solutioning before framing)】直接端出漂亮终稿,跳过问题定义与方案权衡,面试官追问"为什么这么设计"当场失语;【Anthropic 反模式·"还行就过"的模糊评审】对自己作品只会说"我觉得这样比较好看/比较清晰",给不出 design-critique 式的具体诊断(谁和谁竞争注意力、读序是否正确);堆 40+ 页静态图以量充质,最弱作品压在结尾拉低下限。

### 2. 用研到设计的转化严谨度（满分 22）
- **好的样子**：用研不是装饰章节,而是能形成"研究→洞察→方案"的可追溯闭环:每条设计响应都能回指到某条研究结论;清楚区分"用户说的"与"用户做的",不把一句访谈金句当全部依据;方法选得对(深访 5-8 人做动机、可用性测试 5-8 人评方案、问卷 100+ 量化态度),并用亲和图/影响-成本矩阵做过取舍而非全做。
- **应届证据**：作品集用研页呈现"关键洞察 → 对应功能/交互"的逐条对照;实习/课程中真实做过访谈或可用性测试,写清场景、样本量与结论;能说明"这个洞察来自行为观察还是用户自述",并据此调整了方案。
- **常见缺失 / 反模式**：【Anthropic 反模式·调研搬运(research as decoration)】把课程用研报告整段塞进作品集,方法堆满却提炼不出洞察、更推不出设计响应;【Anthropic 反模式·听其言不观其行(say vs do)】只引用用户原话当依据,从不看真实行为数据;Persona/旅程图三件套齐全,后续设计稿却找不到任何对应。

### 3. 设计系统与工程化交付（满分 20）
- **好的样子**：具备 design tokens 思维(色彩/字体/间距/圆角/阴影成体系而非逐处硬编码),Figma 能产出组件库(Variants / Auto Layout / 多人协作);"一致性优先于创意"——同类元素行为一致;状态覆盖完整(default/hover/active/disabled/loading/error/空态),而非只画 Happy Path;交付文件命名规范、切图标注齐备、与研发协作成本低,做到"没文档=不存在"。
- **应届证据**：作品集有组件库/Design System 截图与 token 说明;技能栏 Figma 写到"组件化/Variants/Auto Layout"应用程度而非只列软件名;有可交互原型链接;实习中参与过规范沉淀或还原走查(design QA)。
- **常见缺失 / 反模式**：【Anthropic 反模式·硬编码代替系统(hardcoded over tokens)】每个页面颜色间距各写各的,无 token 体系,导致风格漂移、改一处崩一片;【Anthropic 反模式·只做正常路径(Happy Path only)】缺 loading/error/空态/禁用态,交互逻辑残缺;只会 Photoshop 不会 Figma(2025 年多数互联网 JD 已明确排除);交稿命名混乱、标注缺失,研发返工。

### 4. 可访问性与包容性设计意识（满分 13）
- **好的样子**：懂并能落地 WCAG 2.1 AA 基线:正文对比度 ≥4.5:1、大字 ≥3:1,触控目标 ≥44×44,可见焦点与合理 Tab 顺序,表单有清晰 label 与可理解的错误提示;设计时主动考虑色盲、低视力、键盘用户与暗色模式,而非交付后补;能在评审中指出某配色对比不达标并给出修正。
- **应届证据**：作品集有对比度/触控尺寸/焦点态的标注或说明;修过 HCI / 无障碍 / 认知心理学相关课程;实习项目里做过 a11y 走查或暗色模式适配;能说出"这个浅灰提示文字对比度不够"这类具体判断。
- **常见缺失 / 反模式**：【Anthropic 反模式·可访问性事后补(accessibility as afterthought)】通篇只追求视觉好看,从不提对比度/触控尺寸/键盘可达,把 a11y 当上线后再说的边角料;低对比度的浅色占位文字、按钮触控区过小、无焦点指示却毫无察觉;不知 WCAG 为何物。

### 5. 业务数据闭环与界面文案（满分 15）
- **好的样子**：能把设计方案接到业务指标(转化率/任务完成率/留存),作品集有"上线后指标变化"的数据闭环,并理解 A/B 测试在迭代中的位置;UX 文案遵循"清晰/简洁/一致/有用/像人话":CTA 用动词且具体(用"创建账户"而非"提交"),错误提示给"发生了什么+为什么+怎么办",空状态给"这是什么+为何空+如何开始"。
- **应届证据**：实习经历有设计-数据闭环(改版后转化/完成率变化);作品集末页有数据结论或 A/B 结果;界面里的按钮/报错/空态文案写得具体可执行,而非"出错了""请稍后再试"。
- **常见缺失 / 反模式**：【Anthropic 反模式·美学自嗨拒绝证伪(aesthetics over outcome)】认为设计价值只是"好看",说不出与转化/留存的关系,把审美主权凌驾业务目标之上;【Anthropic 反模式·占位符文案(lorem-ipsum / generic copy)】界面塞"按钮""请输入"等无意义文案,报错只写"出错了",空态一片空白,可见候选人从未认真对待微文案;实习描述无任何上线效果数据。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度必须给出 why,且分数与 why 严格一致:① 指出简历/作品集中具体命中或缺失的事实——前两个项目是否还原了"问题→洞察→推导→验证"决策链、能否就单个决策讲出权衡、用研洞察是否逐条对应到设计、是否有 design tokens/组件库与完整状态覆盖、是否提及对比度/触控/焦点等 a11y 基线、是否有上线数据闭环、界面文案是否具体可执行——写进 evidenceFound / gap;② 说明在校招 UI/UX 岗(对标头部大厂)语境下为何重要(作品集是筛选前置且 2 秒定方向、决策链是面试追问的命门、用研要闭环不是装饰、设计系统决定研发协作效率、a11y 是大厂合规基线、数据闭环证明设计价值);③ 命中反模式时直接点名(结论先行 / 调研搬运 / 听其言不观其行 / 硬编码代替系统 / 只做正常路径 / 可访问性事后补 / 美学自嗨拒绝证伪 / 占位符文案),不得空泛("还不错"无效)。压力版从严:无可访问的作品集链接则"作品集决策链"维度不得超过 10 分;给高分却 why 全是缺口属于评分自相矛盾,应拒绝输出。

## 改写指引（禁编造铁律）
设计师(压力版)改写铁律——只精修简历/作品集"已有"的句子,严禁编造:把已有的项目/用研/交互句讲精准(为谁解决什么问题、做了哪些设计决策与权衡、上线后可用性/业务指标如何),用设计精准动词(调研/定义/推导/原型/迭代/验证/走查)替换"做了/参与了";只在简历已暗示规模但缺具体数字处用 [具体数字] 占位(如任务完成率提升[具体数字]%、访谈[具体数字]名用户、可用性测试[具体数字]轮),占位只补数字、绝不补能力。严禁替候选人添加原句没有体现的用研过程、design token 体系、a11y 结论或数据;严禁把"协助/参与"夸大为"独立/主导";凡简历没有的能力一律走"建议补充(gap_advice)"(如缺用研→建议补一条关键洞察的来源、缺验证→建议补可用性测试或上线数据、缺 a11y→建议在作品集标注对比度与触控尺寸),而非编造。original 必须是简历原文一字不差。

## 本土惯例与硬规则
中国校招 UI/UX 设计惯例核查:① 出局级硬规则(任一触发直接淘汰)——无在线作品集链接或链接 404/需申请权限/加载极慢;作品集与简历揉成一个超大文件;留学英文作品集投国内校招却无中文版。② 作品集格式——PDF 主体 ≤20MB、3-5 个项目、每项目 4-8 页、全集 ≤30 页;链接版(Figma Community/Behance/站酷)作补充;简历首屏或顶部即放作品集入口。③ 简历本身——一页 A4、纯中文、信息密度优先于花哨排版(排版即作品,视觉混乱直接出局);求职意向写清单一方向(UI / UX / 交互 / 产品设计)而非"设计类均可"。④ 加分项——知名互联网公司实习且有完整上线项目、HCI/认知心理学交叉背景、可交互原型与 AIGC 工具实操、行业认可赛事获奖。⑤ 反信号——课程作业冒充商业项目、用技能进度条/雷达图自证工具力、实习只写"参与了设计"无个人贡献。⑥ 无需照片/性别/婚姻等无关字段。
