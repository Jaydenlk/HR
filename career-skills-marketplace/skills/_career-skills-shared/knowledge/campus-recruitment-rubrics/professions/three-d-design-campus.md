# 三维设计师(3D)（三维设计师(3D) · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`three-d-design-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 作品集硬实力（商业三维项目×完整度×成品质量）（满分 36）
- **好的样子**：作品集是三维设计师校招的命根子，权重压倒一切。3-5 个完整的商业三维项目（电商主图/产品KV/品牌视觉/包装/三维场景动画），每个项目能拉通全流程：建模 → 材质贴图 → 灯光 → 渲染 → AE/PS 后期合成，而非只甩一张孤零零的渲染图。成品质量是商业级而非练习级：构图干净、材质质感真实（金属/玻璃/液体/塑料分得清）、灯光有逻辑（主光/补光/轮廓光层次清楚）、渲染无噪点无穿模。方向必须对口——电商/品牌侧的产品级三维（3C数码、美妆、食品饮料、家电、IP衍生），而不是游戏角色、室内效果图、建筑表现混进来充数。至少有 1 个项目带「设计思路/难点拆解」说明（拿到了什么 brief、为什么这么打光、怎么解决材质/渲染问题），证明不是只会照教程点按钮。
- **应届证据**：简历首屏顶部就放作品集链接（站酷ZCOOL / Behance / 个人作品集PDF）并确保可点开、不挂；每个代表作标注：项目类型（电商主图/品牌KV/产品动画）、独立完成的环节、使用的软件与渲染器、是否真实投放/课程/实习产出。实习或项目 bullet 里写清「独立完成 [产品] 的建模-材质-渲染全流程，产出 X 张商业主图/X 秒产品动画」。
- **常见缺失 / 反模式**：作品集链接失效/需密码/要等审核打不开，等于没交作品集，HR 不会催你；或通篇是网上教程的临摹复刻（同一个香水瓶、同一组电商场景，全网都是这一套），看不出个人能力。【反模式·教程复刻侠：作品集全是B站/站酷爆款教程同款工程文件，香水瓶布光、Octane材质球一模一样，面试官一眼认出『这不是XX老师的课吗』，独立能力清零】另一类是【反模式·孤图甩锅怪：只甩最终渲染大图,不给建模布线/材质节点/灯光过程,面试官无从判断到底是你做的还是套的预设,默认按最低能力估】。

### 2. 软件与渲染器栈（建模软件×渲染器×后期）（满分 24）
- **好的样子**：工具栈对口商业三维硬通货：建模主力 C4D（电商/品牌侧绝对主流，2024 年起已是岗位基本技能而非加分项）；产品精度造型需 Rhino（NURBS 曲面，3C/工业产品级建模公司常用）；角色/复杂动画侧需 Maya。渲染器是分水岭——Octane(OC) / Redshift / Corona 至少精通一款并能说清用它做了什么（OC 实时GPU出图、Redshift 大场景效率）。后期 AE（产品动画合成/动态）+ PS（精修出图）默认门槛。每个工具都绑定「用它做出过什么商业成品」的场景，而非裸列软件名。区分清楚 C4D（多边形+渲染+动画一体）与 Rhino（NURBS高精度曲面）的适用边界是专业度的体现。
- **应届证据**：技能栏不写孤立的软件名清单，而在作品/实习描述里嵌入「用 C4D 建模 + Octane 渲染完成 [产品] 商业主图」「用 Rhino 完成 [产品] 曲面精模再导入 C4D 渲染」；渲染器写明版本/精通度并对应到具体作品；AE/PS 作为后期能力绑定到动画或精修成品。
- **常见缺失 / 反模式**：技能栏堆「精通 C4D / Maya / 3ds Max / Blender / Rhino / ZBrush」六七个软件全精通，作品集里却只有一种风格的练习图，面试一问 Rhino 怎么倒角、OC 怎么调焦散就卡壳。【反模式·全家桶通才：软件技能栏列满全行业工具号称样样精通，作品集证据只够撑起一个软件，面试官按『列得越多越虚』反向打分】；或只会一个渲染器的默认材质球，没有任何灯光/材质自定义能力。

### 3. 三维制作功底（建模布线×材质灯光×渲染干净度）（满分 20）
- **好的样子**：看的是肉眼可验证的硬功底，不是嘴上说的『有美感』。建模：布线/拓扑合理（产品要倒角顺滑无破面，需动画的模型布线规整不卡变形）；材质：质感真实可辨（金属反射、玻璃折射、次表面散射、磨砂质感分得开），会用节点/材质编辑器而非套预设；灯光：有打光逻辑（三点布光、HDRI 环境光、产品轮廓光），能营造商业氛围；渲染：成品干净——无噪点、无漏光、无穿模、白平衡正常，会用多通道（AOV）输出方便后期。能在项目里说清自己解决过的具体技术难点（如『玻璃材质渲染发灰，通过调整折射率+背光解决』）。
- **应届证据**：作品集对至少 1 个代表作展示制作过程：建模布线截图/材质节点/灯光布置/渲染设置，证明全流程是自己跑通的；项目 bullet 写出解决过的具体技术问题（材质/灯光/渲染层面），用『发现-原因-解决』结构而非『负责渲染』一句带过。
- **常见缺失 / 反模式**：渲染图一眼脏：满屏噪点、漏光、模型穿插、材质塑料感，却当成代表作放首位；或建模布线乱成一团、产品有破面卡线还自称『精通建模』。【反模式·噪点糊弄侠：渲染采样不够就草草交图,满图噪点和漏光当成『胶片颗粒感』,商业出图标准里这是直接退稿级别的硬伤】；只会无脑套 HDRI 默认光,讲不出任何打光意图。

### 4. 商业视觉理解（电商/品牌场景×需求落地）（满分 12）
- **好的样子**：懂三维是为商业服务的，不是自嗨炫技。理解电商/品牌侧三维的真实用途：电商主图要突出卖点、产品KV要契合品牌调性、618/双11 大促视觉要有节奏、产品动画要讲清功能。能从『接到 brief 到交付投放』讲一个项目：目标人群是谁、要传达什么卖点、为什么这样构图打光、最终用在哪个渠道（详情页/主图/信息流广告/官网）。哪怕是实习里跟过真实投放项目、或课程作业模拟过电商场景，也胜过纯个人风格练习。对设计趋势（如近年的 3D 微缩场景、blind box IP 风、UV 弥散光风）有感知。
- **应届证据**：在实习/项目描述里写明『为 [品牌/产品] 制作 [渠道] 三维视觉，围绕 [卖点] 设计，最终投放于 [详情页/主图/广告]』；作品旁附一句业务背景说明（brief 是什么、解决了什么营销诉求），而非纯艺术化标题。
- **常见缺失 / 反模式**：作品集全是个人审美的炫技场景（赛博朋克、超现实），零商业落地场景，与电商/品牌岗的实际需求两张皮；或讲不出任何一张图『是给谁、为什么、用在哪』。【反模式·自嗨艺术家：满屏个人风格炫技大片却没有一张能落地电商详情页,面试官要的是能卖货的商业视觉,不是参展作品,这一刀砍掉一片】。

### 5. 学历背景与专业匹配度（满分 8）
- **好的样子**：本/硕为视觉传达、数字媒体艺术、工业设计、动画、影视后期等设计相关方向，院校有设计强校光环（央美、清华美院、国美、江南大学、广美、同济设计等）更佳。但三维设计是『作品说话』的硬技能岗——专业匹配只是隐形加分，作品集才是决定性的。跨专业（如计算机、普通文理）若作品集过硬同样能进。全日制双证可按时拿到（大厂网申硬门槛）。相关核心课（三维建模、数字媒体、视觉设计）或自学经历能与作品集呼应。
- **应届证据**：教育背景栏写明院校+专业（标注设计/数媒/工设方向）+全日制+预计毕业时间；若院校/专业不占优，则把作品集和实习提到更前面，用作品弥补背景；相关核心课或获奖与作品集形成呼应。
- **常见缺失 / 反模式**：把精力全压在 GPA 和课程分数上，作品集空空，对设计岗而言仍是零竞争力；或专业对口但作品集是课堂练习级、无任何商业项目。【反模式·绩点换皮匠：以为设计专业+高GPA就能进大厂三维岗,简历里除了成绩单没有一个像样的商业作品,设计岗录用官只认作品集不认分数】。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实，按以下结构展开，分数与 why 严格一致：

① 命中/缺失事实（写进 evidenceFound / gap）：
- portfolio_strength：evidenceFound 写出作品集是否可访问、有几个完整商业项目、方向是否对口、是否带过程/思路（如『站酷链接有效,4个电商产品完整项目,含建模到后期全流程,1个带难点拆解』）；gap 写『作品集链接失效/无作品集』或『全为教程临摹/纯个人炫技无商业项目』。
- software_renderer_stack：evidenceFound 写出对口工具+绑定的成品场景（如『C4D建模+Octane渲染完成3组电商主图,Rhino用于产品曲面精模』）；gap 写『技能栏堆6+软件全精通但作品仅撑起一种,渲染器仅会默认材质球』。
- pipeline_craft：evidenceFound 写出展示了哪些过程证据与解决的技术难点（如『提供材质节点与灯光布置截图,讲清玻璃发灰的调试过程』）；gap 写『代表作满屏噪点/漏光/穿模』或『只甩成品图无任何过程,布线/材质功底无从验证』。
- commercial_sense：evidenceFound 写命中的商业落地证据（如『为某美妆品牌做详情页三维视觉,围绕成分卖点构图』）；gap 写『全为个人炫技场景,零商业落地说明』。
- education_major：evidenceFound 写院校+专业方向；gap 写『仅有GPA/课程分零商业作品』或『专业对口但作品全为课堂练习级』。

② 校招语境下为何重要：必须说明该维度在三维设计校招的实际筛选作用——作品集是录用官筛选第一位且不可被任何其他维度替代(设计岗『作品说话』),链接打不开等于零;软件渲染器栈是岗位硬通货(C4D 2024年起已是基本技能非加分项),渲染器精通度是分水岭;制作功底(布线/材质/灯光/渲染干净度)是肉眼可验证的真功夫,脏图是退稿级硬伤;商业视觉理解决定能否落地电商/品牌真实需求;学历专业是隐形加分但作品集可完全覆盖(跨专业作品硬照样进)。

③ 命中反模式直接点名：若命中则直呼『教程复刻侠』『孤图甩锅怪』『全家桶通才』『噪点糊弄侠』『自嗨艺术家』『绩点换皮匠』等，不得空泛说『有待提升』。

分数对齐：portfolio_strength 无作品集/链接失效/全教程临摹封顶不及格(设计岗硬出局);software_renderer_stack 软件堆砌但作品仅撑一种工具不得给中上分;pipeline_craft 代表作脏图(噪点漏光穿模)不得给中等以上;commercial_sense 零商业落地给低分但不一票否决(属铺垫维度);education_major 专业对口但作品全课堂练习级给低分,跨专业但作品硬可给高分。严禁在 why 中出现『满分的X%』『给分不超过』『故给满分』『扣X分』等内部比例话术。

## 改写指引（禁编造铁律）
严格遵循「禁编造」干净句式，绝不替候选人添加原句没有体现的能力、软件、渲染器或商业项目：

1. 把简历「已有」的三维项目/实习句讲精准：明确写出独立完成的环节（建模/材质/灯光/渲染/后期哪几步）、用了什么软件与渲染器（仅限原文提及）、产出量级（X 张商业主图 / X 秒产品动画 / X 个产品模型）。
   - 例：原句「负责产品渲染」→ 改「独立完成 [产品类型] 的建模-材质-渲染全流程,使用 [原文已提及的软件/渲染器],产出 [具体数字] 张商业主图」（产品、软件、渲染器均须取自原文,缺则留占位或走 gap_advice）。

2. 用精准动词替换模糊词，但不得越级：原文写「协助/参与」就保留「参与」，严禁夸大为「独立完成/主导」；原文确写了独立产出才可用「独立完成」。原文没写后期就不要加 AE/PS,没写 Rhino 就不要加曲面建模。

3. 只在缺数字处用 [具体数字] 占位：如「产出 [具体数字] 张电商主图」「完成 [具体数字] 个产品模型」「制作 [具体数字] 秒产品动画」，让候选人自行填真实数字，绝不代填。

4. 严禁编造能力：简历没写过的软件/渲染器（C4D/Maya/Rhino/Octane/Redshift/AE/PS）一律不得在改写中添加；没体现过的制作环节（布线优化/材质节点/多通道渲染）、商业落地场景、作品集链接不得凭空生成。

5. 凡简历缺失的关键能力（如无作品集链接、无渲染器、无完整项目、无商业落地说明），一律走 gap_advice 给「建议补充」而非在 rewrite 里编造：
   - gap_advice 示例：「建议在简历首屏补充可访问的作品集链接(站酷/Behance/PDF),并确保不挂不需密码」「建议为代表作补充建模布线/材质/灯光过程截图,证明全流程独立完成」「建议补充使用的渲染器(如 Octane/Redshift)及对应作品」「建议为作品补充商业背景说明:为谁做、传达什么卖点、用在哪个渠道」「建议补充一段对口电商/品牌侧的三维项目或实习」。

## 本土惯例与硬规则
出局级硬规则：
- 无作品集 / 作品集链接失效 / 需密码或等审核打不开：设计岗直接出局,HR 不会催你补,作品集是三维设计师的命根子,链接必须当场可点开。
- 作品集方向严重跑偏（投电商/品牌产品三维岗,作品全是游戏角色/室内效果图/建筑表现/2D概念原画）：视为不对口,基本出局——此岗是商业三维(产品/品牌)非游戏原画。
- 非全日制学历 / 无法按时拿到毕业证+学位证双证：大厂网申硬性出局。
- 作品集为网上教程临摹复刻 / 套用现成工程文件冒充原创：面试技术追问当场穿帮,造假级减分。

软件与渲染器优先级（电商/品牌侧三维共识）：
1. C4D — 电商/品牌侧绝对主流,2024 年起已是岗位基本技能而非加分项,不会几乎无法投递。
2. 渲染器（Octane/OC > Redshift > Corona）— 至少精通一款是分水岭,只会默认材质球不算会渲染。
3. Rhino（NURBS 曲面）— 3C/工业产品级精度建模需要,产品方向加分项。
4. AE + PS — 产品动画合成与精修出图的后期门槛,默认要求。
5. Maya — 角色/复杂动画侧需要,纯电商产品岗非必需。
6. 弱相关:Blender 作为替代可,但商业岗仍以 C4D 为通用语言;ZBrush 偏雕刻/角色,产品电商岗非核心。

格式偏好：
- 作品集链接放简历首屏顶部,与姓名/联系方式并列,确保可点开、不挂、不需密码。
- 大厂走网申系统,简历控制在 1 页(本科)/最多 2 页(研究生),作品集另附链接或 PDF。
- 技能不裸列软件名清单,而用『软件+渲染器+做出过什么成品』的绑定句式呈现。
- 每个代表作标注:项目类型、独立完成环节、软件与渲染器、是否真实投放。

加分项（三维设计特有）：
- 真实投放的商业项目(电商主图/品牌KV真正上过详情页或广告投放)。
- 站酷ZCOOL 推荐/首页、Behance 项目获 Appreciation、设计赛事获奖(站酷奖、One Show、靳埭强设计奖等)。
- 作品带完整制作过程(建模布线/材质节点/灯光/渲染设置),证明全流程独立跑通。
- Rhino 高精度曲面建模能力(3C/工业产品方向稀缺)。
- 对设计趋势有感知并体现在作品(3D微缩、IP潮玩风、UV弥散光等)。

反信号（三维设计特有）：
- 软件技能栏堆 6+ 工具号称全精通,作品却只撑起一种(列得越多越虚)。
- 代表作满屏噪点/漏光/穿模/塑料感(商业出图退稿级硬伤)。
- 全是个人炫技场景零商业落地,与电商/品牌岗两张皮。
- 描述项目只用『负责/参与/协助』而无任何独立产出与量化。
- 作品集与岗位方向不符(游戏/室内/建筑混投产品电商岗)。
