# 游戏策划（游戏策划 · 校招(压力版 · 高标准)）

> 校招职业标尺 · 难度档：`pressure` · 预设ID：`game-design-campus-anthropic`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 游戏拆解与设计思维（满分 30）
- **好的样子**：头部(腾讯/网易/米哈游)卡分线:玩游戏时用"设计者视角"而非"玩家视角"。针对1-2款现象级游戏写出反策划文档,不是描述"系统有什么功能",而是讲清"为什么这样设计、解决了玩家什么问题(玩家想达成的 job)、对整个生态的影响"。系统方向能拆系统结构,数值方向能反推经济/战斗数值并讲清北极星留存指标怎么受其影响,关卡方向能讲清地图节奏与白盒逻辑,文案方向能拆叙事结构与世界观自洽。每条分析都能扛住"为什么不那样做"的深度追问,且会明确"这次拆解不展开什么"(Non-Goals 意识)以聚焦。
- **应届证据**：简历附带或链接到针对2-3款游戏的反策划/拆解文档(飞书/腾讯文档链接),按报考方向区分:系统拆解报告、数值经济反推、关卡白盒Demo、世界观+任务文案。游戏经历区每款标注品类、平台、累计时长和"拆解角度",而非堆时长。
- **常见缺失 / 反模式**：【反模式·玩家视角投毒】写了三百字游戏体验,却没有一句话说得清设计者当初为什么要这么做;【Anthropic 反模式·solutioning before framing】上来就讲"我会怎么改这个系统",从不先讲清原设计要解决玩家什么问题;游戏分析停在"好玩/不好玩"层面,随手一问立刻露馅。

### 2. 策划案撰写与逻辑表达（满分 25）
- **好的样子**：策划案是策划岗第一生产力,直接决定能否进面。好的应届策划案有完整骨架:设计目的、目标玩家画像、流程图/脑图、界面UE示意、逻辑规则详解,图文并茂、零错别字,逻辑链比创意重要——讲得清"解决什么玩家问题、谁来玩、如何平衡"。压力版借规格文档视角抬高:写得出可被程序"接住"的验收标准(在什么前置条件下、玩家做什么操作、应得到什么结果,含异常与边界),并用 MoSCoW 区分必做/可做/不做。数值方向额外体现 Excel(VLOOKUP/INDEX-MATCH/数据透视表)实操和数值框架建模,而非套模板。
- **应届证据**：投递时附完整策划案(链接或附件),作品集分区清晰;项目/实习经历用"目标→设计决策→上线结果"结构写,每条经历都能支撑面试深度追问。数值方向在简历点明会用 Excel 函数搭数值框架、有概率论/数理统计/数学建模基础。
- **常见缺失 / 反模式**：【反模式·脑洞派】策划案像一篇科幻小说,程序看完不知道第一行代码该写什么:"为什么这样设计、谁来玩、如何平衡"三连问全缺,通篇脑洞堆砌而非可落地推演;【Anthropic 反模式·no acceptance criteria】只写"做一个XX系统"却没有任何可验收的输入-操作-预期结果定义,程序无法据此实现;数值方向只会 SUM 却写"熟练 Excel"。

### 3. 数据指标与平衡感知（满分 18）
- **好的样子**：压力版新增并抬高:理解游戏不是只看"好玩",还要看数据健康——分得清北极星指标(如留存/时长/付费深度)与诊断指标,看得懂留存曲线初始陡降(新手引导问题)vs 持续下滑(中期内容问题)。数值/系统方向能用数据反推平衡:某英雄/卡牌胜率偏离区间说明什么、经济产出与消耗是否失衡、付费点是否健康(而非杀鸡取卵)。能区分"反映健康的指标"与"只涨不健康的虚荣指标(如累计下载)"。
- **应届证据**：反策划文档里有基于公开数据/自测数据的平衡或留存分析(如从战斗节奏倒推数值区间、对某经济系统的产出消耗拆解);数值方向竞赛/课程作业用真实或自建数据做过平衡建模;自制 Demo 里跑过留存/时长的简单埋点观察。
- **常见缺失 / 反模式**：【反模式·唯手感无数据】通篇"这样设计更好玩",从不用任何留存/胜率/经济数据支撑判断;【Anthropic 反模式·vanity metrics】拿"累计下载/总注册"当游戏成功证据,不看留存与付费健康;数值方向讲不出某数值偏离会引发什么连锁失衡。

### 4. 对口实习与作品集产出（满分 17）
- **好的样子**："对口实习"和"完整作品集"至少占其一,头部公司两者都要。实习哪怕2个月游戏公司测试岗也强过零经验;作品集体现真实生产环节:参加 GGJ/CiGA Game Jam 并完成"能玩"的完整原型、独立游戏(可上架 itch.io)、学校游戏社团的完整项目。压力版借用户研究视角抬高:产出里若做过玩家测试,能讲清观察到玩家"实际怎么玩"(行为)而非只听玩家"嘴上说想要什么"(陈述),并据此迭代。关键是有实际能跑起来的产出,而非只参加了多少场活动。
- **应届证据**：简历列出游戏公司实习(注明方向与具体产出)、Jam作品的可玩链接(itch.io/视频Demo)、上架独立游戏链接;Jam经历写明"完成了什么、负责哪块",能深度解析其中的设计决策与玩家测试发现。
- **常见缺失 / 反模式**：【反模式·作品集真空】说自己热爱做游戏,可整份简历找不到一个能点开来玩的链接;只有"参加了某Game Jam"一行字,点进去要么弃坑要么无可玩产出;【Anthropic 反模式·stated-not-behavioral】做过测试却只引用玩家嘴上说的偏好,没观察玩家实际怎么玩、卡在哪。

### 5. 跨部门协作与落地取舍（满分 10）
- **好的样子**：理解策划核心工作是把设计意图翻译给程序、美术、运营,策划案要"能被程序接住、能被美术实现"。应届体现在实习/项目中与程序、美术的真实协作,策划案里标注需求优先级和实现约束,设计方案考虑落地成本。压力版借路线图取舍视角抬高:面对有限工期/资源能讲清"先做什么、砍了什么、依赖什么"(而非什么都 P0),按可控容量排期留缓冲,不抛"程序根本实现不了"的天马行空。诚实区分自己"主导"还是"参与"的部分。
- **应届证据**：实习/项目写明与程序、美术、运营的协作分工和自己承担的具体环节;策划案中体现对实现约束、需求优先级和取舍依据的考量;团队项目如实标注个人贡献边界,经得起面试追问。
- **常见缺失 / 反模式**：【反模式·我主导了一切】三个人的 Game Jam 作品,简历写得像一个人通宵做完,追问协作分工就支撑不住;【Anthropic 反模式·everything-is-P0】需求全是"必须做",没有任何取舍与 Non-Goals,排期拍到满档无缓冲;只写"独立负责/主导设计"却讲不出技术细节与协作边界。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
对每个维度的打分都必须给出 why,严格三段式,分数与 why 必须一致:① 命中/缺失的事实(写进 evidenceFound / gap):必须引用简历原文。例如 evidenceFound:"附了《原神》元素反应系统反策划文档链接,从战斗节奏倒推数值区间";gap:"全篇游戏经历只写『资深玩家,累计3000小时』,无任何拆解角度"。严禁写"设计思维不足"这类空话,要指到具体哪一句。② 在游戏策划压力档语境下为何重要:结合本职业现实——"策划案是策划岗第一生产力,无作品集=简历直接进废纸桶""面试标配现场出一道开放设计题,逻辑结构化表达直接决定成败""数值岗笔试系统题占40%以上,且要看得懂留存与经济数据""文案大厂近年实际仅录清北复交"。③ 命中反模式直接点名:用本预设自创或 Anthropic 改编的反模式名,如"这是典型的『玩家视角投毒』""上来就改方案=『solutioning before framing』""策划案是『脑洞派』且无验收标准=『no acceptance criteria』""唯手感无数据/拿累计下载当成功=『vanity metrics』""游戏列表是『游戏收藏家』,被问即穿""『作品集真空』,无一可玩产出""做测试只听嘴不看行为=『stated-not-behavioral』""团队项目写成『我主导了一切』""需求全 P0=『everything-is-P0』"。不得用"可以再优化"这类和稀泥说法。打分锚点:维度内既有可链接的高质量产出(反策划文档/可玩Demo/完整策划案/数据分析)又能扛深度追问→高分;有产出但逻辑断层、无数据或浮于表面→中分;无任何产出、纯靠热情和时长堆砌、或命中出局级反模式→低分。分数必须能由 evidenceFound 与 gap 反推出来,不允许"印象分"。

## 改写指引（禁编造铁律）
严格遵守「禁编造」原则:只把简历已有的经历讲精准,绝不替候选人添加原句没有体现的能力、技术名词或产出。可以做(把已有的讲精准):- 把模糊的游戏分析句改写得有'设计者视角'——但只能基于候选人原句已提到的游戏和观点。例:原句'分析过《王者荣耀》的英雄设计'→'拆解《王者荣耀》英雄技能组的[具体机制],从[原句已提到的角度]倒推其平衡设计意图',其中[具体机制]为占位等候选人补。- 把项目/实习经历改成'目标→设计决策→结果'结构:原句'参与了一个塔防游戏的关卡设计'→'负责塔防项目[N]个关卡的白盒搭建,围绕[难度曲线/资源节奏]做关卡设计'——只在缺数字处用 [具体数字]/[关卡数] 占位。- 用精准动词替换空泛动词:把'做了''弄了'换成'拆解/反推/搭建白盒/编排难度曲线/建数值框架',但前提是简历确有对应动作。绝对禁止:- 不得把'协助/参与/跟着做'夸大为'独立完成/主导设计/一手负责'——团队项目如实保留协作措辞。- 不得添加简历没提的引擎(Unity/UE)、工具(Excel函数/VBA)、品类拆解或Jam作品。- 不得无中生有'上架作品''现象级游戏拆解文档''留存/平衡数据'。缺失能力一律走 gap_advice(建议补充)而非编造,例如:'简历无作品集链接→建议补充:整理1-2份反策划文档或一个可玩Demo并附飞书/腾讯文档链接,这是策划岗进面的硬门槛''数值方向未体现Excel建模→建议补充:用一个具体数值案例展示VLOOKUP/数据透视表搭框架的能力''未体现数据感知→建议补充:若拆解过某游戏可补一句基于公开留存/胜率数据的平衡判断,如实标注数据来源'。所有占位符用 [中括号] 标注,提示候选人填真实数据。

## 本土惯例与硬规则
出局级硬规则(命中即废纸桶):1. 无作品集即出局——不提交策划案/拆解文档/可玩Demo,任何方向(系统/数值/关卡/文案)的简历都直接被刷,自我介绍和游戏热情撑不起场面。2. 学历隐形门槛——头部(腾讯/网易/米哈游)后台实际按985/211筛,友塔等二线明确要211及以上;双非候选人机会主要在中小游戏公司(北京休闲游戏赛道相对开放)。3. 文案策划尤其严苛——大厂近年文案校招应届实际仅录清北复交,门槛显著高于其他策划方向;只会写作不够,要有叙事结构设计、世界观自洽和完整长篇/剧本作品。4. 策划案有错别字——直接扣印象分,部分公司当一票否决项。证书/竞赛优先级(应届加分排序):GGJ(1月)/CiGA Game Jam(6-7月)国内认可度最高,有完整可玩作品且能深度解析设计决策,是应届最强加分项之一;Ludum Dare 国际知名、大厂认可,优于无经历但低于国内Jam;985游戏社团×公司定点内测赛事(信息不对等是现实,在头部社团有优势);数值方向:数学建模竞赛(MCM/CUMCM)是专属加分项,CFA/精算等量化背景略加分;引擎证书(UE/Unity)对关卡策划有一定加分;策划岗整体几乎没有公认行业证书,别指望靠证书取胜。格式偏好:PDF提交,一页为主(经历丰富可两页,绝不超两页);游戏经历必须单独分区,写明品类/平台/累计时长/拆解角度;必须有作品集链接(飞书文档/腾讯文档即可,不要求独立网站);不附照片(除非JD明确要求)。反信号(踩中减分):游戏分析只写'好玩/不好玩'无设计者视角;简历堆十几款游戏却每款浅尝辄止;策划案创意堆砌、逻辑断层、无验收标准;数值方向写'熟练Excel'实则只会SUM;拿'累计下载/注册'当游戏成功证据而不看留存;应聘某公司却从没玩过其代表作;学生项目写'独立负责/主导'追问即穿;只参加Jam但弃坑无可玩产出;跨专业转型无解释、无作品、无游戏经历。
