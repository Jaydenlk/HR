# 工艺工程师(制造/半导体)（工艺工程师(制造/半导体) · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`process-engineer-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 工艺模块与良率工程能力(工艺段×缺陷/良率分析)（满分 30）
- **好的样子**：认知落到具体工艺段而非泛谈「半导体」:半导体方向能指明自己接触/感兴趣的模块——光刻(Litho)、刻蚀(Etch,含干法/湿法)、薄膜(Thin Film,CVD/PVD/ALD)、扩散/氧化、离子注入(Implant)、CMP(化学机械抛光)、金属化中的一到两段,并知道它属于前道(FEOL)还是后道(BEOL);制造/新能源方向能指明所在工序段(SMT/注塑/焊接/电芯涂布/卷绕/电池片镀膜等)。围绕「良率(Yield)」展开:做过缺陷(Defect)分析、异常(Excursion)排查、用 WAT/CP 测试数据或在线 SPC 数据定位失效模式,并能说出良率从 X% 提升到 Y% 或不良率从 X 降到 Y(哪怕是项目/实习里参与的一段)。能区分 PE(模块专精,依赖机台)与 PIE(工艺整合,跨模块沟通),知道自己想走哪条线。
- **应届证据**：在实习/项目/毕业设计描述里点名具体工艺段(如「负责刻蚀段 CD 均匀性改善」「参与电芯涂布工序面密度波动分析」),写明针对什么缺陷/失效模式、用什么数据(WAT/CP/SPC/SEM 图)定位、做了什么调整、良率或不良率变化多少(带数字)。实验室/课程项目即使无产线,也写「围绕 [某工艺参数] 设计实验,分析其对 [膜厚/CD/良率] 的影响」。
- **常见缺失 / 反模式**：全篇只写「熟悉半导体工艺」「了解芯片制造流程」却说不出任何一个具体工艺段,更没有良率/缺陷的任何数字。【反模式·流程背诵机:把『光刻-刻蚀-薄膜-扩散-离子注入-CMP-金属化』整条流程像课本一样默写一遍,却没有一段是自己真正动手做过的,录用官一眼看穿这是百度来的流程图不是经验】;或把良率说成结果却给不出基线与改善幅度。【反模式·良率口号党:简历写满『提升良率、优化工艺、降低不良』的口号,全程零基线零数字零方法,HR 一句『良率从多少到多少、你用什么定位的』就问垮】

### 2. 统计方法与工艺改善方法论(SPC/CPK/DOE/8D)（满分 22）
- **好的样子**：掌握工艺工程师的「质量语言」并能落到使用场景:SPC(统计过程控制,看控制图判异常)、CPK/CP(过程能力指数,知道半导体/汽车 IATF 体系 CPK≥1.33 为合格线、1.67 优秀、2.0 世界级)、DOE(实验设计,能说出全因子/部分因子/响应曲面 RSM/田口方法中用过哪种)、8D(八步法解决问题报告)、FMEA(失效模式分析)、MSA/GRR(量测系统分析)、5M1E/鱼骨图等改善工具。每个工具都绑定一个「用它解决了什么工艺问题」的场景,而非孤零零列在技能栏。知道相关标准体系:半导体看 JEDEC,汽车/储能看 IATF 16949,通用 ISO 9001。
- **应届证据**：在项目/实习 bullet 里写「用 DOE(部分因子)筛选出影响 [膜厚] 的 3 个关键因子」「用 SPC 控制图监控 [参数] 并将 CPK 从 1.0 提升到 1.33」「按 8D 流程完成一份 [某不良] 的改善报告」。课程层面写学过/做过的实验设计、质量管理课程项目。
- **常见缺失 / 反模式**：技能栏堆「精通 SPC/DOE/Minitab/六西格玛」,正文找不到任何一次实际使用,面试一问「你的 DOE 是几因子几水平、CPK 怎么算的」立刻卡壳。【反模式·六西格玛吊牌侠:把 SPC、DOE、8D、六西格玛绿带像吊牌一样挂满技能栏,真问一个控制图怎么判异常、CPK 公式是什么就答不上来,这是工艺岗面试第一道送命题】;或只会念工具名词,完全不懂 CPK 的合格门槛(连 1.33 都说不出),暴露纯背术语没实操。

### 3. 工艺岗实习/产线经历(机构层级×任务实质)（满分 22）
- **好的样子**：有真实的工艺/制程岗(PE/PIE/工艺/质量改善)实习或产线项目,而非纯实验室或行政打杂。机构层级清晰:半导体晶圆厂(中芯国际/华虹/长江存储/长鑫存储)、设备/材料商(屹唐/盛美/中微)、新能源龙头(宁德/比亚迪/隆基/通威)、汽车与精密制造大厂最佳。任务写得出实质:跟过哪条产线/哪个机台、处理过什么异常、参与过什么工艺改善或新产品导入(NPI),并说清自己独立做了什么(测了什么、分析了什么、给出什么结论)。进过洁净室(Cleanroom)、了解机台基本操作与安全规范是半导体方向的实打实加分。
- **应届证据**：实习经历栏写明企业全称+部门(工艺部/制程部/良率部)+起止时间,每段 2-3 条 bullet 写具体任务与可量化产出(如「跟进 [机台] 的 [参数] 漂移,完成 X 次工艺调整,良率回升 X%」),而非一句「参与工艺相关工作」。无产线实习者用扎实的工艺实验项目替代:完整的实验设计-数据-结论闭环,比空泛 GPA 更有说服力。
- **常见缺失 / 反模式**：用与工艺无关的行政、市场、纯理论实验室经历冒充工艺经验,以为「进过制造业公司」就够;或在产线只是参观/记录却美化成「参与工艺优化」,背调即穿帮。【反模式·进厂参观团:把一次工厂参观、暑期实践、产线打卡写成『深度参与工艺改善』,既说不清跟的哪个机台也给不出任何数据,录用官当场识别为『来过工厂』而非『做过工艺』】;或实习全程只写「协助」「参与」无任何独立产出与数据。

### 4. 学历背景与专业匹配度(理工科硬门槛)（满分 14）
- **好的样子**：本/硕为微电子、集成电路、材料、物理(凝聚态/半导体物理)、化学/化工、机械、自动化、电气/电子等对口理工科;半导体方向硕士为主力(不少 Fab 工艺岗硕士起),制造/新能源本科亦有机会。专业匹配度:微电子/集成电路 > 材料/物理/化学化工 ≈ 机械/自动化 > 其他工科。全日制双证可按时拿到(大厂硬门槛)。附 GPA 与排名(工艺岗对动手与扎实程度敏感,成绩可作佐证但非决定项),列出半导体器件、固体物理、材料科学、半导体工艺、概率统计/质量工程等对口核心课。
- **应届证据**：教育背景栏写明院校+专业(标注微电子/材料/物理等对口方向)+学历层次+全日制+预计毕业时间,附 GPA 及排名,列出半导体物理、固体器件、材料、半导体工艺原理、统计/质量等核心课程及成绩。
- **常见缺失 / 反模式**：专业与制造/半导体完全不沾边(纯文科/商科)又无任何工艺实习与项目来补匹配度;或把全部精力堆在刷 GPA,零工艺实习零动手项目,对 Fab 工艺岗而言仍是零竞争力。【反模式·绩点空壳人:简历除了一个漂亮 GPA 和成绩单空空如也,既没碰过机台也没做过工艺实验,工艺岗看的是动手与良率不是排名,4.0 也救不了零经验】

### 5. 数据分析与工艺工具实操能力（满分 12）
- **好的样子**：统计与数据工具有真实佐证:JMP 或 Minitab(做 SPC/DOE/能力分析的行业标配)、Excel(数据处理门槛能力);进阶有 Python/SQL 做产线大数据取数与良率分析(数据驱动型 Fab 越来越看重);制造段需 AutoCAD/SolidWorks/UG 等绘图与工艺文件(PFMEA/控制计划/作业指导书)制作能力。半导体方向了解 SEM/TEM/AFM 等量测表征手段、能看懂失效分析(FA)图是专项加分。每项工具都绑定「用它做了什么分析/产出」的具体场景。
- **应届证据**：在项目/实习描述里写「用 JMP 完成 DOE 因子筛选与方差分析」「用 Python 拉取 [X] 万条 WAT 数据做良率趋势分析」「用 SolidWorks 绘制 [夹具/工艺图] 并编制控制计划」,工具与产出绑定出现,而非单独一栏列「熟练 JMP/Minitab/Python」。
- **常见缺失 / 反模式**：技能栏写「精通 Minitab/JMP/Python」却全简历找不到一个用到它的项目,面试一问「你用 JMP 做过哪种 DOE、输出怎么看」就露馅。【反模式·软件罗列党:技能栏一口气列 JMP、Minitab、Python、SQL、AutoCAD、SolidWorks 七八个软件全标『精通』,正文零项目佐证,录用官默认这是『装机列表』不是能力清单,直接打折】;或只会 Excel 拉表却谎称掌握统计软件。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的 why 必须落到简历事实,按以下结构展开,分数与 why 严格一致:

① 命中/缺失事实(写进 evidenceFound / gap):
- process_module_yield:evidenceFound 写出点名的具体工艺段+良率/缺陷数据(如「负责刻蚀段 CD 改善,良率 92%→97%」);gap 写「全文只写『熟悉半导体工艺』无任何具体工艺段」或「良率只有口号无基线无数字」。
- stat_methodology:evidenceFound 写出工具+绑定场景(如「用部分因子 DOE 筛 3 个关键因子」「SPC 监控将 CPK 提至 1.33」);gap 写「技能栏列 SPC/DOE 但正文零使用」或「念得出工具名说不出 CPK 合格门槛」。
- process_internship:evidenceFound 写机构层级+具体任务(如「中芯国际工艺部,跟进机台参数漂移」);gap 写「仅有行政/纯理论实验室经历无工艺岗」或「产线只参观无独立产出」。
- education_major:evidenceFound 写院校+对口专业方向+学历+GPA;gap 写「专业不沾边且无工艺实习补足」或「仅有 GPA 零工艺实践」。
- data_tools:evidenceFound 写工具+绑定分析场景(如「用 JMP 做 DOE 方差分析」);gap 写「技能栏堆多款软件全标精通但正文零项目佐证」。

② 校招语境下为何重要:必须说明该维度在工艺岗校招的实际筛选作用——工艺段+良率是工艺工程师的本职(说不出工艺段=不懂这行);统计方法论是面试第一道送命题(CPK/DOE 必问);工艺岗实习不可被无关实习替代且产线/洁净室经历是 Fab 硬通货;学历专业是隐形筛选线(半导体硕士为主力);数据工具近年权重急升(数据驱动 Fab 必问 JMP/Minitab 实操)。

③ 命中反模式直接点名:若命中则直呼「流程背诵机」「良率口号党」「六西格玛吊牌侠」「进厂参观团」「绩点空壳人」「软件罗列党」等诨名,不得空泛说「有待提升」。

分数对齐:process_module_yield 说不出任何具体工艺段且无良率数字封顶不及格(本职缺失);stat_methodology 工具零使用佐证只能算缺失,连 CPK 门槛都说不出给低分;process_internship 仅有无关/参观式经历不得给中等以上分;education_major 专业不沾边且无实习补足给低分(隐形筛选);data_tools 软件无佐证只能算缺失。

禁止在 why 中出现「满分的 X%」「给分不超过」「故给满分」「扣 X 分」等内部计算比例话术,why 只陈述简历事实与校招筛选逻辑。

## 改写指引（禁编造铁律）
严格遵循「禁编造」干净句式,绝不替候选人添加原句没有体现的工艺段、工具、机构层级或良率数字:

1. 把简历「已有」的工艺实习/项目句讲精准:明确写出针对哪个工艺段/工序、什么缺陷或失效模式、用什么数据(WAT/CP/SPC/SEM)定位、用什么方法(DOE/8D/SPC)改善、量级多大(良率 X%→Y%、CPK X→Y、不良率降 X)。
   - 例:原句「参与工艺优化工作」→ 改「在 [机构] 工艺部参与 [原文已提及的工艺段] 的 [原文已提及的缺陷] 改善,使用 [原文已提及的方法] 完成 [具体环节]」(工艺段、缺陷、方法均须取自原文,缺则留 [具体数字] 占位或走 gap_advice)。

2. 用精准动词替换模糊词,但不得越级:原文写「协助/参与」就保留「参与」,严禁夸大为「独立完成/主导」;原文确写了独立产出才可用「独立完成」。

3. 只在缺数字处用 [具体数字] 占位:如「良率从 [具体数字]% 提升到 [具体数字]%」「将 CPK 从 [具体数字] 提升到 [具体数字]」「分析了 [具体数字] 片晶圆的缺陷分布」,让候选人自行填真实数字,绝不代填。

4. 严禁编造能力:简历没写过的工艺段(光刻/刻蚀/CMP 等)、没写过的工具(JMP/Minitab/Python/SolidWorks)、没写过的方法(DOE/SPC/8D/FMEA)、没写过的良率数字与机构层级,一律不得在改写中添加;不得把课本流程默写当成本人经验注入。

5. 凡简历缺失的关键能力,一律走 gap_advice 给「建议补充」而非在 rewrite 里编造:
   - gap_advice 示例:「建议点明你接触的具体工艺段(如刻蚀/薄膜/CMP)而非泛写半导体工艺」「建议为良率描述补充基线与改善后数字(如 92%→97%)」「建议补充一段工艺/制程岗实习并写明跟进的机台与任务」「建议在项目中补充 DOE/SPC 的实际使用场景与 CPK 数值」「建议补充 JMP/Minitab 的具体分析产出」。

## 本土惯例与硬规则
出局级硬规则:
- 专业完全不对口(非微电子/材料/物理/化学化工/机械/自动化等理工科)且无任何工艺实习与动手项目:半导体 Fab 与制造大厂工艺岗直接过滤。
- 半导体头部 Fab 多数工艺岗以硕士为主力门槛;非全日制 / 无法按时拿到毕业证+学位证双证:大厂硬性出局。
- 简历虚假信息:大厂通过学信网+背景调查核验,实习产线与任务一问即穿,造假直接出局。
- 说不出任何一个具体工艺段、零良率/缺陷数据:工艺工程师本职缺失,基本无竞争力。

能力优先级(工艺岗就业共识):
1. 具体工艺段经验 + 良率/缺陷分析的真实数据(良率从 X% 到 Y%)— 本职硬通货,最高优先。
2. 统计与质量方法论实操(SPC/CPK/DOE/8D/FMEA)+ 知道 CPK≥1.33 合格门槛 — 面试必问。
3. 工艺/制程岗实习 + 洁净室/机台经验(半导体)— 不可被无关实习替代。
4. 对口理工科学历(微电子/材料/物理为佳)+ 数据工具实操(JMP/Minitab/Python)。
5. 明确反信号:纯背工艺流程图、纯念质量工具名词、软件全标『精通』无佐证,对工艺岗均为负面信号。

格式偏好:
- 大厂走网申系统,本科 1 页、研究生最多 2 页;工艺段、机构层级、良率数据应在首屏可见。
- 每段实习/项目用『工艺段 + 缺陷/问题 + 方法 + 数据结果』四件套描述,而非一句『参与工艺工作』。
- 半导体方向建议在简历中体现对前道(FEOL)/后道(BEOL)的基本认知与目标模块。

加分项(工艺岗特有):
- 真实产线/Fab 实习 + 洁净室作业经验 + 跟过具体机台。
- 良率/不良率有清晰基线与改善幅度的真实数据。
- DOE/SPC/8D 有完整案例(从问题到结论闭环)、六西格玛绿带且有项目支撑。
- JMP/Minitab 实操、Python/SQL 做良率大数据分析(数据驱动 Fab 加分)。
- 全国大学生节能减排/材料/化工设计竞赛、挑战杯等与工艺相关获奖;发表过工艺相关论文/专利。
- 了解 SEM/TEM/AFM 表征与失效分析(FA),熟悉 JEDEC / IATF 16949 / ISO 9001 体系。

反信号(工艺岗特有):
- 把整条工艺流程当课本默写,无一段是本人动手。
- 良率/优化全是口号无基线无数字。
- 质量工具与软件全标『精通/熟练』正文零佐证。
- 实习只是工厂参观/打卡却写成『深度参与工艺改善』。
- 描述经历只用『协助』『参与』而无任何量化产出。
