# 管理咨询（管理咨询 · 校招(压力版 · 高标准)）

> 校招职业标尺 · 难度档：`pressure` · 预设ID：`consulting-campus-anthropic`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 假设驱动与定制化结构(MBB 终面级)（满分 30）
- **好的样子**：对标 MBB 终面与贝恩杯全国决赛级别:不是会画 MECE,而是能在信息不全时先抛出一条可证伪的核心假设(day-1 hypothesis),用 issue tree 自上而下拆到可取数的叶子节点,再用数据逐条证伪或证实,最后用金字塔结构把判断收敛成一句 CEO 能直接拍板的 recommendation。框架必须是为这道题现搭的(driver tree / 利润桥 / 客户决策旅程),并能讲清每一支的 so-what 与对最终结论的边际贡献。case 经历里担任的是定义问题、设假设、定优先级的 lead,而非被分配去跑某一格数据。
- **应届证据**：贝恩杯全国决赛 / 麦肯锡 Young Leaders / 奥纬 Impact / Peak Time 等 S 级实绩,且能复述自己负责的那条假设链从 day-1 到 final recommendation 的完整证伪过程;MBB / Tier2 实习里独立 own 过一个 work stream 的 issue tree 拆解;能现场把一个模糊增长课题(为何 GMV 增速跌半)在三层内拆到可验证的根因。
- **常见缺失 / 反模式**：【反模式·框架贴皮匠】把 SWOT / 4P / 波特五力当万能贴纸往每段经历上贴,套了框架却答不出每一格对这道题的 so-what,MBB 终面第一刀就砍这种「会背框架、不会拆问题」;【反模式·先有答案后补框架】结论是拍脑袋定的,框架只是事后包装,假设不可证伪、拆解互相重叠又有遗漏,一追问哪条假设被数据推翻就答不上;【反模式·跑数工具人】全篇「负责数据整理/做调研」,看不出谁定的问题、谁设的假设、谁下的判断。

### 2. 顶级实习含金量与咨询语言转译（满分 24）
- **好的样子**：实习层级直达 S 级即强信号:MBB 暑期 / PTA、顶级投行战略部、PE 投后或尽调;A 级(四大战略 Monitor/Strategy&、罗兰贝格、奥纬)须写清项目类型与个人独立 own 的子模块及可量化产出(搭了几个模型、跑了几轮高管访谈、识别出几条被采纳的建议)。无对口实习者用贝恩杯决赛级竞赛或主导的重量级定量研究实打实顶上。关键是每段都被诚实重构成「问题结构化 → 定量分析 → 落地建议 → 客户影响」的咨询叙事,而非靠 logo 撑场或沿用通用运营话术。
- **应届证据**：MBB / Tier2 实习写明项目方向(消费品增长战略 / 制造业精益降本 / 出海市场进入)+ 个人 own 的分析模块 + 可量化产出 + 建议是否被客户采纳;PE / 投行尽调中独立承担的行业或财务子课题;无对口实习时以贝恩杯全国决赛或主导的产业级定量课题替代。
- **常见缺失 / 反模式**：【反模式·镀金叙事】实际做的是 cold call、整理纪要、订会议室,简历写成「主导战略方案 / 牵头转型规划」,背调与细节追问当场归零;【反模式·大厂光环依赖】仗着腾讯 / 阿里运营实习的牌子直接套通用运营描述,却没把经历转译成咨询语言(问题怎么拆、影响多大量级),品牌替代不了内容重构;【反模式·头衔通胀】两个月跟项目某一环,却把从问题定义到落地的全周期都写成自己「主导」。

### 3. 白名单院校与硬学术门槛（满分 16）
- **好的样子**：院校落在 MBB 大陆白名单约 18 所或海外 Target,GPA 显著高于 3.5+(4.0 制)非正式门槛、以 Top 5%(8/235)的排名百分位呈现而非裸分,专业 GPA 高于总 GPA 时单列;教育背景置顶,GPA + 排名 + 奖学金三连第一行。加分信号(国家奖学金=专业 Top 1%、理工+经管双学位)显著前置。非白名单院校坦诚以内推路径 + 顶级竞赛 / 顶尖实习这类黑船级经历对冲降权,而不是用水课刷出的高总绩点充数。
- **应届证据**：院校全称 + 专业 + GPA / 排名百分位 + 奖学金;国家奖学金、校级一等奖学金等可量化荣誉;清华计算机+经双等匹配数字化方向的复合背景;LSE / MIT / 港大港科等海外顶校交换或联合学位;高级计量 / 公司金融 / 机器学习等核心难课具体高分。
- **常见缺失 / 反模式**：【反模式·藏分自残】GPA 已达 3.5+ 却不写或只写「成绩优秀、专业前列」无任何数字,机器与筛选官按刻意隐瞒处理,等于主动撕掉入场券;【反模式·水课刷绩】非白名单院校冷申却无内推,版面浪费在通识水课拉高的总绩点上,而不用专业 GPA、核心难课高分与顶级竞赛补院校短板;【反模式·裸分罗列】只写 3.7 不写排名百分位,无法体现在本专业的相对位置。

### 4. 量化严谨度与建模深度（满分 16）
- **好的样子**：数字敏感贯穿全篇且经得起连追三层:目标 70%+ bullet 含金额 / 比例 / 规模 / 时间的可验证量化结果。Excel 自下而上(bottom-up)市场空间测算与敏感性分析是底盘,能讲清每个假设的来源与口径;Python / R / SQL 处理真实数据并落到商业结论是加分;熟练使用 MECE、scenario analysis、EBITDA、利润桥等咨询语汇并真的用在经历里。能列出高级计量 / 随机过程 / 公司金融等有信号的核心课而非通识水课。
- **应届证据**：实习 / 竞赛中用 Excel 自下而上测算市场空间 + 敏感性分析的具体项目(说清测算口径与关键假设);Python / R / SQL 清洗或分析数据的产出(数据量级 + 解决的商业问题);CFA / ACCA 进度;Relevant Coursework 的高难度定量课程成绩;每段经历嵌入的可验证数字(增收 % / 降本额 / 覆盖规模)。
- **常见缺失 / 反模式**：【反模式·形容词冲量】通篇「有效提升 / 显著改善 / 圆满完成」零个数据,筛选官无法判断真实 impact;【反模式·假数字】写「提升 30%」但答不出这 30% 怎么算、口径是什么、基线多少,终面连追三层当场穿帮;【反模式·办公软件凑数】技能栏堆 Office / 沟通 / 团队合作占满一行,咨询默认人人会、写了是噪音,真正稀缺的 CFA / 建模 / 数据工具反而没突出。

### 5. PEI 故事深度与非职权影响力（满分 14）
- **好的样子**：用 1-2 段最能体现领导力 / 影响力 / 进取心的经历,撑起麦肯锡 PEI 所需的 3-4 个独立故事库,每个都经得起一位面试官深挖 15 分钟、连续 5-6 轮追问「你当时怎么想、为什么这么做、如果重来会怎样」。看的是规模(全国性 > 院系级)、角色(负责人 > 执委 > 成员)与可量化成果,以及在没有正式权力时如何说服关键人、推动跨团队拿到结果(非职权影响力)。「学生会主席」四个字毫无信号,「主导 2000 人校庆、赞助额提升 40% 且说服 3 个赞助商」才算。
- **应届证据**：全国性 / 大型学生组织或咨询俱乐部的核心角色 + 量化成果(赞助额 / 活动规模 / 招募人数);担任 case 辅导导师、发起校园大使招募等主动型经历;靠说服而非职权推动落地的跨团队故事;能围绕同一段经历讲清「背景—我的动作—说服 / 推动过程—结果—复盘」的完整 PEI 素材。
- **常见缺失 / 反模式**：【反模式·头衔流水账】「XX 部部长、XX 社副社长」铺满版面却零量化成果,行为面试一问「做出了什么 impact」就空;【反模式·单故事赌徒】只准备一个故事就上场,面试官换一个维度(进取心 / 失败复盘)追问立刻没素材;【反模式·热闹打杂】社团经历看着丰富但全是成员级执行活,撑不起任何一个能讲 15 分钟的非职权影响力故事。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度必须给出 why,三段式且分数与 why 严格一致:① 引用简历中具体命中或缺失的事实写进 evidenceFound / gap——假设驱动维度要点出有没有「可证伪假设 → issue tree → 数据证伪 → 金字塔结论」的完整链路与个人 own 的模块、实习要点明层级(MBB / Tier2 / 四大战略 / 普通企业)与是否用咨询语言转译且建议是否被采纳、院校要点出是否在白名单 18 所内及 GPA 是否显著高于 3.5+ 并以排名百分位呈现、量化维度要数 bullet 数字密度并核验关键数字是否说得清口径与基线、PEI 要看经历能否撑起 3-4 个可深挖 15 分钟的独立故事;② 说明在校招管理咨询语境下为何重要(假设驱动结构化是 MBB 终面唯一无可替代的核心交付、白名单院校+GPA 在中国是 ATS 入场券级筛选器、实习筛的是咨询语言而非品牌、PEI 是麦肯锡每位面试官深挖一个故事 15 分钟的核心考察、数字严谨度要经得起连追三层);③ 命中反模式时直接点名(框架贴皮匠 / 先有答案后补框架 / 跑数工具人 / 镀金叙事 / 大厂光环依赖 / 头衔通胀 / 藏分自残 / 水课刷绩 / 形容词冲量 / 假数字 / 头衔流水账 / 单故事赌徒 等),不得软化为「有待加强 / 建议提升」;④ 分数必须与 why 一致,给高分但 why 全是缺口属评分自相矛盾应拒绝输出。严禁出现「满分的 X% / 扣 X 分 / 给分不超过 / 得分率」等内部计算口径,只陈述事实、反模式与缺口。

## 改写指引（禁编造铁律）
管理咨询(压力版)改写铁律——只精修简历「已有」的实习 / case 竞赛 / 课程项目句,绝不编造:把做的是哪类商业问题、设了什么可证伪假设、用什么框架或工具拆解、识别出哪几块、影响多大量级讲精准,用咨询精准动词(拆解 / 测算 / 搭建框架 / 设假设并证伪 / 识别优先级 / 推动落地)与可量化指标(市场空间数字 / 降本增收 % / 访谈轮数 / 模型假设 / 活动规模)增强可信度;只在缺数字处用 [具体数字] 占位,绝不代填想象数字。严禁替候选人添加原句没有的分析框架、战略结论、被采纳记录或定量产出,严禁把「协助 / 参与」夸大为「独立 / 主导」,严禁把跟项目某一环写成全周期主导。凡简历没有体现的能力(没设过假设、没搭过模型、没有对口实习、没有可深挖的 PEI 故事)一律走 gap_advice 给「建议补充」,而非在改写里替候选人编出来。

## 本土惯例与硬规则
中国校招管理咨询惯例核查(压力版从严):① 出局级硬规则——非白名单约 18 所院校冷申 MBB 会被 ATS 自动降权几乎无效,唯一解是内推(绕过 ATS 路由直达人工),非白名单院校须显著体现内推路径;MBB 秋招截止即止不接受迟交;麦肯锡硬性要求中英文双版简历 + 成绩单 + 英语测试分数,缺一项直接拒;GPA 达标(3.5+)却不写按刻意隐瞒处理。② 英语硬门槛——MBB 中国区要求全英文会议、贝恩杯复赛英文展示,简历英文 bullet 的语言精度本身即信号;CET-6 人人都有不构成加分,真正能展示的是雅思 7+ / 托福 100+ 或全英授课项目。③ 竞赛优先级——S 级(贝恩杯全国决赛名次 / 麦肯锡 Young Leaders / 奥纬 / Peak Time)、A 级(数模国赛一等 / Kaggle 银牌以上 / 顶级商学院大型案例赛)、B 级(互联网+省金 / 校级商赛),不同段位混放并列反显认知不足;贝恩杯全国冠军近乎直通贝恩面试。④ 格式——严格一页 A4、中英文双版(MBB 要求),Calibri / Garamond / Times New Roman 10–11pt,深蓝+深灰不用花哨图标色块,教育背景置顶且 GPA + 排名百分位 + 奖学金三连第一行,两页及以上视为无法对信息优先级排序即时减分;无照片、无年龄 / 政治面貌 / 婚姻状况栏。⑤ 加分项——内推极其关键(被内推简历直接路由人工、跳过 ATS 降权),理工+经管双学位(清华计算机+经双匹配数字化咨询为顶配),LSE / MIT / 港大港科等海外顶校交换或联合学位。⑥ 反信号——GPA 低于 3.3 且无顶级竞赛 / 内推 / 顶尖实习补偿则 MBB 基本出局;实习全为国企 / 政府且无量化产出;出现「稳定 / 有编制」等与 MBB 文化错位的词汇;所有实习均一个月以内且数量很多(信号为广撒网而非深度参与)。
