# 品牌/公关(PR)（品牌/公关(PR) · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`brand-pr-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 文字输出能力（硬通货筛选线）（满分 28）
- **好的样子**：简历里有真实可查证的文字成品：写过被采用的新闻稿/通稿/深度稿、运营过有阅读量数据的公众号、给校园官媒/院报/广播站供稿、或拿过广告文案类竞赛。最好直接附作品集链接（公众号、个人博客、稿件原文），让HR五秒内点开看见文笔与角度。不靠形容词，靠点得开的成品说话。
- **应届证据**：公众号/小红书账号链接（带阅读量、涨粉、爆款数据）；校媒/院报/校广播站供稿署名；媒体实习产出的可署名稿件；广告/文案类竞赛获奖作品（写明主办方名次）；个人作品集附件或在线链接。
- **常见缺失 / 反模式**：技能栏写「文笔好/表达能力强/热爱写作」却连一条可点击的作品链接都没有，等于自己宣布出局。【反模式·万金油文案员：嘴上说会写，简历里翻遍找不到一篇能点开看的稿子。】

### 2. 传播策划与Campaign执行（区分度最高）（满分 26）
- **好的样子**：有从0到1主导过一个完整传播项目的经历——哪怕只是校园品牌节/科创赛/公益项目的传播端：自己出创意方案、排预热-引爆-收尾的传播节奏、最后带覆盖人数/曝光量/转化数据收尾。动词是「主导/统筹/操盘」而非「参与/协助」，且每条都落到结果。能讲清楚「背景是什么、面临什么挑战、为什么这么打」，而不是流水账。
- **应届证据**：校内活动/品牌节/赛事的传播负责人经历（带覆盖X人、曝光量、转化数据）；完整传播方案文档或策划案附件；实习中独立推过的小型传播项目；广告/公关大赛的策划案作品（如大广赛、学院奖）。
- **常见缺失 / 反模式**：所有bullet都是「参与XX」「协助XX」「配合XX」，没有一个词体现主导性，也分不清自己是负责人还是打杂的。【反模式·全程打杂人：通篇被动动词，看不出哪件事是你独立推成的。】

### 3. 媒介认知与新媒体平台感（满分 18）
- **好的样子**：对微信/微博/小红书/抖音各平台内容生态有真实手感：运营过账号且有涨粉率、互动率、阅读量这类数据支撑；理解KOL/KOC投放逻辑，接洽过媒介资源。大厂PR岗还需对央媒/财经媒体等传统媒体生态有基本认知。出海岗能体现TikTok/Instagram等英文社媒操作经验是强加分。
- **应届证据**：个人/校园自媒体账号的真实粉丝与数据截图或链接；社媒运营实习（带互动率、涨粉量）；媒介接洽/KOL沟通经历；英文社媒（TikTok/Instagram）运营经验；媒体或公关公司实习接触的投放/媒介排期工作。
- **常见缺失 / 反模式**：没做过投放却堆「KOL矩阵/私域流量/AARRR/用户分层」一串术语，被问具体项目就答不上来。【反模式·黑话复读机：术语背得溜，一问哪个campaign用过就卡壳。】

### 4. 舆情敏感度与危机公关意识（满分 16）
- **好的样子**：校招少有实操，但能体现思维：做过危机公关课程项目、模拟舆情处置的竞赛/课堂案例，或实习里碰过舆情监测日报；对热点事件有自己的复盘分析（可链到个人文章）。懂5S原则（承担责任/真诚沟通/速度第一/系统运行/权威证实），面对「某品牌负面曝光的72小时应对」这类题能给出有逻辑的方案而非套话。
- **应届证据**：危机公关/舆情管理相关课程的项目作业或论文；公关大赛的危机处置赛题作品；实习中参与舆情监测/日报的经历；个人对真实热点事件的复盘文章链接；笔试常考的5S原则相关训练。
- **常见缺失 / 反模式**：把品牌/公关岗当成新媒体运营来投，开篇就堆粉丝增长和排版技能，对舆情、媒体关系、危机管理只字不提。【反模式·运营岗错投：拿涨粉简历投策略岗，话术体系完全不在一个频道。】

### 5. 跨部门协调与效果复盘（满分 12）
- **好的样子**：PR本质是资源整合，能体现统筹拉通的经历：学生组织里协调过多部门（量化带几人、协调几个部门、落地了什么），或实习中对接过外部媒体/供应商/KOL。互联网大厂PR岗越来越看数据意识——活动后能产出传播效果报告（媒体覆盖量/曝光量/舆情正负比），会用识微/慧科讯业/清博指数等监测工具，能做竞品传播分析。
- **应届证据**：学生组织/活动中的统筹协调经历（带人数、部门数、落地结果）；实习中对接外部媒体/供应商/KOL的记录；活动后的传播效果复盘报告；舆情监测工具使用经历（识微/慧科讯业/清博指数）；竞品传播分析作业。
- **常见缺失 / 反模式**：写了二十条经历却条条只有任务描述没有结果，没人看得出哪件事产生了实际效果。【反模式·素材堆砌机：经历列满整页，全是「负责XX日常」，零数据零成果。】

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度的评分说明必须采用三段式 why，且分数与 why 严格一致：

① 事实层（evidenceFound / gap）：先点出简历里命中或缺失的具体事实。命中示例写法——「evidenceFound：运营校园公众号至3.2万粉、单篇推文阅读量10w+，并附了可点开的链接」；缺失示例写法——「gap：自称文笔好但全篇无任何可查证的稿件/账号/作品链接」。禁止泛泛说「表现不错」或「有待提升」。

② 语境层：说明该事实在品牌/公关校招里为何关键。例如文字输出维度——「文字是PR岗的硬通货筛选线，HR五秒内点不开作品就过滤」；Campaign维度——「大厂最看重有没有从0到1独立推过一个传播项目，这是和其他应届生拉开差距的区分点」；媒介感维度——「互联网PR岗JD直写自媒体运营经验优先，要的是平台手感不是理论」。

③ 反模式层：命中反模式直接点名扣分，不得空泛。例如——「命中『全程打杂人』：四条经历全是参与/协助，无一主导，传播岗要的是能独立推进的人，扣分」「命中『黑话复读机』：堆了KOL矩阵/私域流量却无对应项目支撑，比不写更减分」「命中『运营岗错投』：用涨粉数据投品牌策略岗，画像错位」。

分数对齐规则：三段 why 指向强命中（有可查证作品+独立主导+量化结果）才给该维度高分；若 gap 是核心缺失（如零作品、全程打杂、岗位画像错投），分数必须落到低档，不允许「why 说缺失却给高分」的矛盾。各维度得分按 weight 加权汇总，主交付维度（文字输出、Campaign策划）缺失的扣分权重最重。

## 改写指引（禁编造铁律）
改写严格遵循「禁编造」原则：只把简历里已经存在的传播经历讲精准、讲可信，绝不替候选人添加原句没有体现的能力、平台、数据或项目。

把已有的模糊句讲精准：将「负责公众号运营」这类任务描述，按简历真实信息改写为「主导校园公众号内容策划与撰写，覆盖 [具体粉丝数] 读者，单篇最高阅读量 [具体数字]，产出爆款推文 [具体篇数] 篇」——动词用「主导/策划/操盘/统筹」等精准词替换空泛的「负责」，并在效果处补量化。

只在「缺数字」处用 [具体数字] / [覆盖人数] / [曝光量] 占位，提示候选人回填真实数据；不得凭空编造一个数字填进去。

严禁夸大：原句是「参与活动策划」就只能讲精准为「参与XX活动的传播端执行，承担 [具体环节]」，绝不能擅自改成「独立主导/全程操盘」——参与就是参与，主导就是主导，混淆即造假。

凡简历里根本没有的能力，一律走「建议补充（gap_advice）」而非写进改写句。例如简历无任何作品链接，gap_advice 写：「建议补充可点击的作品集链接（公众号/已发表稿件/策划案），PR岗HR需要五秒内点开看到你的文字成品」；简历无危机公关经历，gap_advice 写：「建议补充危机公关相关课程项目或对真实热点事件的复盘分析链接，体现舆情敏感度」。改写句里绝不出现这些原本不存在的能力。

## 本土惯例与硬规则
出局级硬规则：
1. 零作品基本直接过滤——品牌/文案类PR岗，没有任何可展示的文字或策划作品，HR第一轮就刷掉；强烈建议作品集单独附件或链接（腾讯官网明确要求附件提交作品集+新闻稿/策划案）。
2. 专业卡梯队——新闻传播/广告/中文/公共关系为第一梯队；非传播背景可投但必须有实操经历弥补。
3. 学历门槛——多数互联网大厂PR管培要求本科，部分品牌传播岗要求在校/应届硕士（如深圳品牌传播岗）。
4. 学科成绩——部分JD（如拼多多）明写「学科成绩优秀」，不是摆设。

证书优先级（从高到低）：
1. 本岗非CFA/CPA型，无强制行业证书。
2. 英语：CET-6是国内岗基线；涉外/海外PR岗要求英语可作工作语言，日/韩/德/意等小语种为部分岗位加分项。
3. 国际公关师（IABC/APR）：高级岗加分，校招几乎无人持有，不是筛选项。
4. Adobe系（PS/PR/AE）：加分项，会基础操作即可，不要求专业级。
5. 计算机二级/普通话证书：基本无加分，人人都有，写了等于没写。

格式偏好：
1. 本科一页A4；研究生经历多可两页，但内容必须撑得住，超两页（应届）是反信号。
2. PDF投递，确保ATS可解析文字——避免图片嵌字、复杂表格、彩色花哨模板；PR岗简历本身要「专业」而非「creative」。
3. 时间倒序，最新经历在前；经历时间线不得重叠混乱，否则被疑造假。

反信号（看到即扣分）：
1. 技能栏写「熟练使用Office」——默认人人会。
2. 自我评价写「责任心强/学习能力好/积极主动」等通用话——HR完全免疫。
3. 全篇「参与」没有一个「主导/独立/负责」。
4. 一份简历海投所有岗位（腾讯HR原话：要成为偏才，在某一领域扎根很深）。

加分项：主流媒体/知名公关公司/4A广告公司实习（多个JD明写「有媒体实习经验者优先」）；有真实粉丝数据的自媒体账号；海外交流/英语工作能力（涉外岗强加分）；省级以上广告/公关/新媒体竞赛获奖（写明主办方与名次）；参与过真实品牌项目而非课堂假设案例。
