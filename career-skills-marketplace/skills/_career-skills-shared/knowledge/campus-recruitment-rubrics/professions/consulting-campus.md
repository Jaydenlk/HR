# 管理咨询（管理咨询 · 校招(融合版)）

> 校招职业标尺 · 难度档：`standard` · 预设ID：`consulting-campus`

## 五维评分标尺（权重之和 = 100；score 封顶各维满分，total_score = 各维之和）

### 1. 结构化拆解与假设驱动（满分 32）
- **好的样子**：面对信息不完整的问题仍能 MECE 拆解、先给假设再用数据验证,而不是上来就堆现象。简历经历能看出一条完整链路:把一个模糊商业问题(为什么增长停滞 / 该不该进某市场)切成相互独立、完全穷尽的几块,识别出盈利优先级或关键驱动因子,最后落到一句可执行的结论。叙述遵循结论先行的金字塔结构,case 竞赛 / 战略实习中担任的是搭框架、定优先级的角色,而非跑数据的执行位。能说清这个框架是为这个具体问题量身搭的,而不是硬套现成模型。
- **应届证据**：S 级 case 竞赛实绩(贝恩杯全国决赛名次 / 奥纬 / Peak Time / 麦肯锡 Young Leaders),且写明自己负责的拆解模块与最终建议;战略 / 咨询实习中独立搭建的分析框架(如市场细分框架识别 3 个盈利优先级、用 issue tree 拆解客户降本课题);主导的定量课程项目(产业经济学 / 计量 / 公司金融中以商业结论收尾的研究);能复述某个 case 从问题定义到最终 recommendation 的完整逻辑链。
- **常见缺失 / 反模式**：满屏参与 / 协助 / 负责开头,看不到任何结构化产出,六秒扫过去脑子里留不下一个框架或结论【反模式·动词堆砌仔:全是动作没有结论,做了一堆活却讲不出自己拆解了什么、得出了什么判断】;或者反过来,硬把 SWOT / 4P / 波特五力套到每段经历上充门面,套了框架却答不出各项对该问题的具体影响——咨询恰恰在筛定制化思维,套模板是减分项。

### 2. 咨询实习含金量与语言转译（满分 24）
- **好的样子**：实习层级清晰且用咨询语言描述:S 级(MBB 暑期 / PTA、顶级投行战略部、PE 尽调)本身即强信号;A 级(四大咨询 DC / FAS、Tier2 咨询如罗兰贝格 / 奥纬)写清所在项目类型与个人独立承担的子模块。普通企业实习不靠公司 logo 撑场,而是被诚实重构成问题拆解—数据分析—建议落地的咨询叙事:做了什么分析、解决什么商业问题、影响多大量级。无对口实习者,用 S 级 case 竞赛或重量级课程项目实打实顶上,而非空挂头衔。
- **应届证据**：MBB / Tier2 / 四大咨询实习写明项目方向(如消费品增长战略 / 制造业降本 / 数字化转型)+ 个人负责的具体分析模块 + 可量化产出(搭了几个模型、跑通几轮访谈、识别出几条建议);大厂战略 / 商分实习用咨询语言转译的工作产出;PE / 投行尽调中承担的行业或财务子课题;无实习时以贝恩杯决赛级竞赛或主导的定量课程项目替代。
- **常见缺失 / 反模式**：实际做的是 cold call、整理会议纪要、订会议室,简历却写成制定战略方案 / 主导转型规划,一被追问就穿帮、信任度直接归零【反模式·镀金描述仔:执行打杂活硬包装成战略决策,面试一深挖就露馅】;或仗着腾讯 / 阿里运营实习的大厂光环,沿用通用运营描述就以为够了——MBB 筛的是能不能把经历讲成咨询语言(问题结构化 + 量化建议),品牌替代不了内容重构。

### 3. 院校与 GPA 学术信号（满分 18）
- **好的样子**：院校落在 MBB 大陆白名单约 18 所(北清复交 / 人大 / 浙大 / 同济 / 南大 / 外经贸 / 中财 / 上财 / 北外 / 北航 / 北理 / 中山 / 厦大 / 武大 / 华科 等)或海外 Target;GPA 达到非正式门槛 3.5+(4.0 制),且用 Top 5%(8/235)这类排名百分位呈现而非裸分,专业 GPA 高于总 GPA 时单列。教育背景置顶,GPA + 排名 + 奖学金三连放第一行。加分信号(国家奖学金即专业 Top 1%、理工 + 经管双学位)显著前置。非白名单院校则坦诚通过内推路径 + 顶级竞赛 / 实习这类黑船级经历来对冲降权。
- **应届证据**：教育栏的院校全称 + 专业 + GPA / 排名百分位 + 奖学金;国家奖学金、校级一等奖学金等可量化荣誉;理工 + 经管双学位(清华计算机 + 经双匹配数字化咨询方向为顶配);港大 / 港科 / LSE / MIT 等海外顶校交换或联合学位;相关核心课程(高级计量 / 公司金融 / 机器学习)的具体高分。
- **常见缺失 / 反模式**：GPA 明明到了 3.5+ 却不写,或只写一句成绩优秀、专业前列而没有任何数字,机器和筛选官都会按刻意隐瞒处理,等于主动扔掉正向信号【反模式·藏分仔:达标的分死活不肯写,把入场券亲手撕了】;或非白名单院校冷申却没有内推、把版面浪费在堆水课拉高的总绩点上,而非用专业 GPA、核心难课高分和顶级竞赛去补院校短板。

### 4. 量化分析与数字密度（满分 14）
- **好的样子**：对数字敏感这件事贯穿全篇:每条 bullet 至少含一个金额 / 比例 / 规模 / 时间的数字,目标 70% 以上 bullet 带量化结果,而不是有效提升了 / 取得良好成果这类空话。工具能力落到实处——Excel 高级建模(financial modeling)是底盘,Python / R / SQL 数据分析是加分;熟悉 MECE、bottom-up、scenario analysis、EBITDA 等咨询语汇并真的用在过经历里。能列出有信号的核心课程(高级计量 / 随机过程 / 机器学习 / 公司金融)而非通识水课。
- **应届证据**：实习 / 竞赛中用 Excel 自下而上测算市场空间 / 做敏感性分析的具体项目;Python / R / SQL 清洗或分析数据的产出物(数据量级 + 解决的商业问题);CFA / ACCA 进度或数据分析工具能力;Relevant Coursework 列出的高难度定量课程及成绩;每段经历里嵌入的可验证数字(增收 % / 降本额 / 覆盖规模)。
- **常见缺失 / 反模式**：通篇找不出一个数字,全是有效提升、显著改善、圆满完成这类自我表扬,筛选官无法判断你到底做出了多大影响【反模式·定性描述仔:满纸形容词零个数据,商业 impact 全靠想象】;或技能栏堆 Office / 沟通能力 / 团队合作占满一行——咨询默认人人都会,写了等于噪音,真正稀缺的 CFA / 建模 / 数据工具反而没突出。

### 5. 领导力与非职权影响力(PEI)（满分 12）
- **好的样子**：用 1 到 2 段最能体现领导力与主动性的经历,而非罗列十几个社团头衔。看的是规模(全国性 > 院系级)、角色(负责人 > 执委 > 成员)与可量化成果——学生会主席四个字毫无意义,主导 2000 人校庆、赞助额提升 40% 才有信号。展现的是非职权影响力:在没有正式权力时如何说服他人、推动跨团队拿到结果。经历足以撑起麦肯锡 PEI 所需的 3 到 4 个故事库(领导力 / 影响力 / 进取心各一),每个都经得起 5 到 6 轮追问,而不是只准备一个故事就上场。
- **应届证据**：全国性 / 大型学生组织或咨询俱乐部中的核心角色 + 量化成果(扩大赞助额 / 活动规模 / 招募人数);担任 case 辅导导师、组织校园大使招募等主动发起型经历;跨团队协作中靠说服而非职权推动落地的故事;能围绕同一段经历讲清背景—我的动作—说服 / 推动过程—结果的 PEI 素材。
- **常见缺失 / 反模式**：把 XX 部部长、XX 社副社长一连串头衔铺满版面,却没有一个量化结果,行为面试一问做出了什么 impact 就答不上来、白占版面【反模式·头衔罗列仔:职位列一打,成果数字一个没有,PEI 一追问就空】;或社团经历看着热闹但全是成员级打杂,撑不起任何一个能讲 15 分钟的非职权影响力故事。

## 打分解释规则（每维 why 必须落到简历事实；命中反模式直接点名；严禁泄漏"满分的X%/扣X分"等内部计算）
每个维度必须给出 why,三段式且分数与 why 一致:① 引用简历中具体命中或缺失的事实,写进 evidenceFound / gap——结构化拆解要点出有没有完整的问题定义到 recommendation 链路与负责的拆解模块、实习要点明层级(MBB / Tier2 / 四大 / 普通企业)与是否用咨询语言转译、院校要点出是否在白名单 18 所内及 GPA / 排名是否达 3.5+ 并量化呈现、量化维度要数 bullet 的数字密度与工具实操产出、PEI 要看经历能否撑起可深挖 15 分钟的故事,不得笼统;② 说明在校招管理咨询语境下该维度为何重要(结构化拆解是唯一无可替代的核心交付、院校 + GPA 在中国是 ATS 入场券级筛选器、实习筛的是咨询语言而非品牌、PEI 是麦肯锡每位面试官深挖一个故事 15 分钟的核心考察、数字敏感度贯穿全文);③ 命中反模式时直接点名(动词堆砌仔 / 镀金描述仔 / 藏分仔 / 定性描述仔 / 头衔罗列仔),不得以有待加强、建议提升等软化表述替代;④ 分数必须与 why 一致——给高分但 why 全是缺口属评分自相矛盾,应拒绝输出。

## 改写指引（禁编造铁律）
管理咨询改写侧重:把简历已有的实习 / case 竞赛 / 课程项目句讲精准——做的是哪类商业问题、用了什么分析框架或工具、拆解出哪几块、影响多大量级,用咨询精准动词(拆解 / 测算 / 搭建框架 / 识别优先级 / 推动落地)与可量化指标(市场空间数字 / 降本增收 % / 访谈轮数 / 模型假设 / 活动规模)增强可信度;只在缺数字处用 [具体数字] 占位;严格遵守禁编造:严禁替候选人添加原句没有体现的分析框架、战略结论、被采纳记录或定量产出,严禁把协助 / 参与夸大为独立 / 主导。凡简历没有体现的能力(没搭过模型、没做过框架、没有对口实习)一律走 gap_advice 给出补充建议,而不是在改写里替候选人编出来。

## 本土惯例与硬规则
中国校招管理咨询惯例核查:① 出局级硬规则——非目标院校(非白名单约 18 所)冷申 MBB 会被 ATS 自动降权 30% 到 50% 几乎无效,唯一解法是内推(可绕过 ATS 路由直达人工筛选),非白名单院校须显著体现内推路径;MBB 秋招截止即止不接受迟交,春招名额极少;麦肯锡硬性要求中英文双版简历 + 成绩单 + 英语测试分数,缺一项直接拒;GPA 达标(3.5+)却不写会被机器和人工当作刻意隐瞒处理。② 英语硬门槛——MBB 中国区要求能参与全英文会议,贝恩杯复赛英文展示;简历英文 bullet 的语言精度本身就是信号;CET-6 人人都有不构成加分,真正能展示的是雅思 7+ / 托福 100+ 或全英授课项目,只写四六级在咨询简历里毫无区分度。③ 竞赛优先级——S 级(贝恩杯全国决赛名次 / 麦肯锡 Young Leaders / 奥纬 / Peak Time)、A 级(数模国赛一等 / Kaggle 银牌以上 / 顶级商学院大型案例赛)、B 级(互联网+省金 / 校级商赛),不同段位竞赛混放并列反显认知不足;贝恩杯全国冠军近乎直通贝恩面试,含金量最高。④ 格式——严格一页 A4、中英文双版(MBB 要求),字体 Calibri / Garamond / Times New Roman 10 到 11pt,深蓝 + 深灰不用花哨图标色块,教育背景置顶且 GPA + 排名百分位 + 奖学金三连放第一行,两页及以上简历视为无法对信息优先级排序、即时减分;无照片、无年龄 / 政治面貌 / 婚姻状况等个人信息栏(放了反显不专业);四大咨询 DC 可接受行业通用格式,对证书偏好高于 MBB。⑤ 加分项——内推极其关键(被内推简历直接路由人工、跳过 ATS 降权),理工 + 经管双学位(清华计算机 + 经双匹配数字化咨询为顶配),港大 / 港科 / LSE / MIT 等海外顶校交换或联合学位。⑥ 反信号——GPA 低于 3.3 且无顶级竞赛 / 内推 / 顶尖实习补偿则 MBB 基本出局;实习全为国企 / 政府且无量化产出(缺市场化问题解决语言);出现稳定 / 有编制等词汇与 MBB 文化严重错位;所有实习均一个月以内且数量很多(信号为广撒网而非深度参与)。
