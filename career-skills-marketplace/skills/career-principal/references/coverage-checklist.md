# 主动盘点清单(Coverage Checklist)— 15 维校招谋略

> 这是代表"主动全面"的弹药库。用户常只问眼前一件事(改简历、看 JD),但真正决定成败的维度往往没被问到。
> 代表的职责不是把 15 维一次性全做完(那是长问卷,反人性),而是**按用户当前目标动态点出 3-5 个最相关、最高价值的盲区**,告诉用户"你还没提但建议一起看 X/Y,因为…",再把选择权交还用户。

## 主动度规则

**核心:动态选维,不全量做。**

1. **按用户当前目标,动态选 3-5 个最相关维度主动点出**。措辞模板:
   > "你还没提但建议一起看 **X**、**Y**,因为 ⟨损失/收益理由⟩。要不要顺手一起看?"
   把选择权交还用户——用户说"看"才展开对应 skill,说"先不"就不做。**绝不一次性把 15 维全铺开**(那退化成长问卷,违背"连贯聊天"体验)。

2. **高损失维度一旦情境相关必点**:
   - **⑨ 城市 / 落户红利** —— 只要涉及一线城市岗位 / 户口 / 应届身份,必点。落户名额价值可能远超薪资差,错过即永久关闭。
   - **⑩ 三方协议与违约** —— 只要进入"拿 offer / 签约 / 比 offer"情境,必点。三方锁应届身份、违约金与备注栏一旦签错损失巨大。
   这两维"错过的损失"远大于"多说一句的打扰",所以情境相关时不走"3-5 个里挑"的概率,直接点。

3. **高优先 ①-⑩ 默认进入盘点候选池**(按相关性排序后取 3-5);**中优先 ⑪-⑮ 按情境提议**(命中触发条件才进候选池)。

4. **挂实时联网的维度**(标 `[实时]`):时效信息当场 WebSearch/WebFetch、附 URL、标 `[实时·未核实·URL·日期]`;无网才降级为训练知识并说明可能过时。不挂实时的维度用知识库 / 行业惯例 / JD/CV 即可。

5. **每点一维都要带理由(为什么现在看)**,不堆术语。理由优先讲"不看会损失什么"而非"看了有什么好处"——损失厌恶更能驱动用户配合。

## 高优先维度(默认覆盖)

### ① 招聘时间窗口 / 批次

- **简述**:校招按批次滚动,踩准窗口=多一轮机会、错过=等下一年。提前批(6-7 月,部分 1 月)→ 秋招主力(7-10 月,全年 70-80% 岗位)→ 春招(次年 2-5 月)→ 补录捡漏(11-12 月 / 4-5 月毁约释放)。提前批常免笔试 / 不影响正式批,是低成本试错窗口。`[实时]`
- **中国校招特调点**:`[据知识库]` "金八银九"节奏已被打破——字节 1 月底就开提前批,部分头部把窗口大幅前移;别再用旧日历规划,当季节点必须实时核。
- **是否挂实时联网**:**是**。具体批次开放 / 截止日期是时效信息,需当场 WebSearch 目标公司 + 当届校招公告,标 `[实时·未核实·URL·日期]`。
- **对应可调度 skill**:`market-radar`
- **来源**:`[行业惯例]` 新东方秋招节奏说明;知乎 26 届春招讨论。

### ② 同岗竞争强度 / 供需比

- **简述**:先量化"这条赛道多挤",再决定投入强度与冲稳保配比。`[据知识库]` 2026 届 1270 万+ 往届 + 海归共超 1500 万求职者,有效岗约 567 万,整体供需比 ≈ 2.7:1;1 岗约 17.2 份简历、应届平均投 150-200 份拿 1 面、offer 率 < 8%。结构极不均:央企总部 > 1000:1、大厂算法 60:1、文科 7:1;而 AI 大模型核心岗供需比 0.39、高性能计算 0.15(供不应求)。`[实时]`
- **中国校招特调点**:`[行业惯例]` 总量是"虚假繁荣",真正可投有效岗远少于公告数;且冷热极化——别用平均供需比 2.7 估自己赛道,要落到细分岗位。
- **是否挂实时联网**:**是**。当届最新供需 / 投录比是时效数据,目标赛道需实时核,标 `[实时·未核实·URL·日期]`。
- **对应可调度 skill**:`market-radar`、`salary-radar`
- **来源**:`[据知识库]` 阿波罗就业数据 / 网易 / 钛媒体 / 脉脉口径(注意多源口径差异,见多源并列规则)。

### ③ 内推 / 隐藏渠道

- **简述**:`[行业惯例]` 内推平均 +30-50% 通过率;60-80% 岗位不公开走内推 / 熟人。投递优先级:内推 > 官网 > 第三方平台。`[据知识库]` 辨真伪内推——能查进度 / 直通业务线 = 真内推;只给一个码、查不到进度 = 伪内推(只为刷 KPI)。
- **中国校招特调点**:`[行业惯例]` 国内大厂内推码满天飞但含金量天差地别;牛客等社区有大量"内推避坑"经验,要教用户识别真伪、别浪费宝贵简历额度。
- **是否挂实时联网**:否(策略与识别方法为相对稳定经验;具体某公司内推开放情况若需要可顺带实时核)。
- **对应可调度 skill**:`referral-strategy`、`networking-message-writer`
- **来源**:`[据知识库]` 牛客内推避坑帖;2026 校招 Playbook。

### ④ 谈薪空间与筹码

- **简述**:`[行业惯例]` 应届无历史薪资锚点,但有"可塑性溢价"筹码;多 offer = 议价权。谈薪原则:别先报数 / 报区间而非单点 / 用硬证据(竞品 offer)/ 懂白菜价-SP-SSP 分层 / 首轮报价非底线。`[据知识库]` 反制"综合包"模糊套路(把不确定的浮动 / 期权混进总包做大数字)。
- **中国校招特调点**:`[行业惯例]` 国内大厂有明确白菜 / SP / SSP 评级体系,SSP 可比白菜高 50%+;应届敢谈、有竞品 offer 就能撬档位,多数人因不敢谈而损失。
- **是否挂实时联网**:否(谈判方法稳定;具体岗位薪资基准走 ⑤/② 的实时数据)。
- **对应可调度 skill**:`salary-radar`、`offer-comparator`
- **来源**:`[据知识库]` 掘金谈薪经验;牛客 offer 谈判帖。

### ⑤ 总包结构拆解

- **简述**:`[行业惯例]` 把口头"总包 XX 万"拆成三类钱看清虚实:①固定(base × 12/13/14 薪)②浮动(绩效 / 年终,问清是否保底)③有条件(签字费 / 安家费 / RSU,可能绑服务年限)。隐形项:公积金基数比例(12% vs 5% 一年差上万)/ 试用期是否打折 / 加班费。核心动作:把口头总包翻译成"白纸黑字写进 Offer 的固定部分"。
- **中国校招特调点**:`[行业惯例]` HR 惯用"综合年包"话术把浮动 + 期权 + 补贴堆成大数字,实际到手可能差一截;公积金 12% vs 5% 是国内特有的隐形大头。
- **是否挂实时联网**:否(拆解框架稳定;具体公司公积金比例 / 调薪惯例若需要可实时核)。
- **对应可调度 skill**:`offer-comparator`、`salary-radar`
- **来源**:`[据知识库]` 博客园 offer 拆解;掘金总包结构帖。

### ⑥ 业务线 / 团队 / 部门选择

- **简述**:`[行业惯例]` 同公司同岗,落到核心业务线 vs 边缘业务线,成长曲线天差地别;有无 mentor、技术栈新旧、是否二次分配都决定前 1-2 年成长,而前 1-2 年成长又决定后续涨幅。签约前必问:具体部门 / 是否二次分配 / 技术栈 / 是否配导师。
- **中国校招特调点**:`[行业惯例]` 国内大厂常"先发 offer 再二次分配",入职才知去哪个组——这是最大暗坑,必须签前锁定或问清分配机制。
- **是否挂实时联网**:否(选择框架稳定;具体业务线近况若需要走 ⑦/⑫ 实时核)。
- **对应可调度 skill**:`opportunity-intelligence`
- **来源**:`[据知识库]` 博客园选 offer 帖;牛客部门选择讨论。

### ⑦ 公司 / 行业风险信号

- **简述**:看清行业是上升还是收缩、岗位是否被 AI 替代。`[据知识库]` 2026 校招:互联网 / 房产 / 教培岗位分别约 -35% / -40% / -50%;文职 / 客服 / 初级会计 / 简单设计被 AI 腰斩(替代率 85-95%)。求稳升温:国企成首选(45.7%)、国考 98:1。`[实时]`
- **中国校招特调点**:`[行业惯例]` 把口头承诺(调薪 / 房补 / 不裁应届)写进三方协议备注栏才有保障;收缩行业的"画饼"风险尤其高。
- **是否挂实时联网**:**是**。公司近况 / 裁员 / 财报 / 行业景气是高度时效信息,需当场 WebSearch + WebFetch,标 `[实时·未核实·URL·日期]`。
- **对应可调度 skill**:`company-risk-auditor`、`industry-trend-analyst`
- **来源**:`[据知识库]` 阿波罗就业报告 / 新浪财经 / 网易行业数据。

### ⑧ 长期职业路径联动

- **简述**:`[行业惯例]` 第一份工作影响下一份的薪资基准 + 大厂背书价值(校招红利仅毕业 1 年内有效,之后社招要 2-3 年经验)+ 应届生身份红利只能用一次。决策倾向:先进大厂攒背书再转岗 > 在小公司熬 3 年。建议按 3-5 年轨迹评估这份 offer 的"跳板价值"而非只看起薪。
- **中国校招特调点**:`[据知识库]` 国内"应届生身份"是一次性稀缺资源(过期不补、考公考编 / 大厂校招通道随之关闭),第一份的选择权重远高于起薪几千块差异。
- **是否挂实时联网**:否(路径规律稳定;目标赛道趋势走 ⑦ 实时)。
- **对应可调度 skill**:`career-path-planner`、`role-transition-advisor`
- **来源**:`[据知识库]` 超级简历职业路径;CSDN 应届身份红利帖。

### ⑨ 城市 / 落户红利(中国特调·必点)

- **简述**:`[据知识库]` 北上深户口多数政策只对应届开放——毕业 > 2 年或在外地交了社保即关闭通道。落户补贴可观:杭州本科生活补贴 1 万+、租房补贴 1 万 × 3 年;深圳本科 1.5 万 / 硕士 2.5 万。落户名额的长期价值(买房 / 子女教育 / 摇号)可能远超几千块薪资差。`[实时]`
- **中国校招特调点**:这是**纯中国特调维度**,海外职业框架完全没有;落户是应届身份绑定的一次性窗口,**情境相关(涉一线城市 / 户口 / 应届身份)即必点**。
- **是否挂实时联网**:**是**。各城市当年落户政策 / 补贴金额 / 名额常调整,需当场实时核,标 `[实时·未核实·URL·日期]`。
- **对应可调度 skill**:`city-industry-fit-advisor`
- **来源**:`[据知识库]` 超级简历落户政策;CSDN 各城市补贴汇总。

### ⑩ 三方协议与违约风险(中国特调·必点)

- **简述**:`[据知识库]` 三方协议(就业意向)受法律保护,签下即锁定应届身份。签前四看:①违约金(正常 3000-1 万,过高需警惕)②备注栏(13 薪 / 房补 / 调薪等口头承诺必须写进备注才有效)③落户资格是否随三方走 ④公司信息(全称 / 统一信用代码核对)。红线:不能同时签两份三方。
- **中国校招特调点**:这是**纯中国特调维度**,三方协议是中国校招独有制度;**情境相关(拿 offer / 签约 / 比 offer)即必点**——签错损失大且法律层面有约束力。
- **是否挂实时联网**:否(三方制度与审查清单稳定;不需联网)。
- **对应可调度 skill**:`application-tracker`
- **来源**:`[据知识库]` 网易三方科普 / 博客园签约避坑 / CSDN 三方违约金帖。

## 中优先维度(按情境提议)

### ⑪ 冲稳保梯度自评

- **简述**:`[行业惯例]` 拉 5-10 份目标 JD 自评匹配度——≥ 70% 为强匹配(冲)/ 50-70% 可投(稳)/ < 50% 需补能力(保 or 暂缓)。投递策略:冲稳保三梯度配比,精投 60% + 海投 40%,避免全冲落空或全保浪费。
- **中国校招特调点**:`[行业惯例]` 国内简历额度宝贵(内推码有限、HR 看脸熟),精投比例要比海外更高;别无脑海投稀释信号。
- **是否挂实时联网**:否(自评框架稳定,基于用户 JD/CV)。
- **对应可调度 skill**:`application-strategist`、`match-diagnosis`
- **来源**:`[据知识库]` CareerBuilder 冲稳保模型;人人文库投递策略。
- **触发情境**:用户手握多个目标岗位 / 问"该投哪些 / 投递怎么排布"。

### ⑫ 公司 / 行业研究深度

- **简述**:`[行业惯例]` 面试前必须能答上来:公司做什么 / 主要竞品 / 未来 12 个月目标 / 这个岗位解决什么问题 / 公司近期公告。建议面试前花 15-20 分钟深挖,在面试中展现商业意识(而非只背简历)。`[实时]`
- **中国校招特调点**:`[行业惯例]` 国内面试官尤其看重"你了不了解我们"——能说出近期业务动态 / 财报亮点会显著加分,泛泛而谈"贵公司很优秀"反而扣分。
- **是否挂实时联网**:**是**。公司近期公告 / 业务动态 / 竞品格局是时效信息,面试前当场实时核,标 `[实时·未核实·URL·日期]`。
- **对应可调度 skill**:`interview-intelligence`、`company-interview-playbook`
- **来源**:`[据知识库]` Vivid 面试准备指南;JobSprout 公司研究法。
- **触发情境**:用户已拿到面试邀请 / 进入面试准备阶段。

### ⑬ 申请时机微操

- **简述**:`[行业惯例]` 同一岗位发布后 24-48 小时内投递,竞争最小、被看到概率最高;HR 回复率周二三四上午最高。提前批随投随筛(早投早面),正式批公告后 3-10 天是投递黄金期。
