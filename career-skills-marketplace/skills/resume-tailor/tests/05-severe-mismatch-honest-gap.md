# 测试 05：严重不匹配时 honest_gaps 必须存在且非空

## 测试目标

验证当用户背景与 JD 存在严重跨领域不匹配时，技能必须诚实列出无法弥补的差距，而不是强行产生改写建议制造虚假匹配感。

## 测试输入

### resume_text
```
林艺，厨师，10年经验

工作经历：
2014.01 - 至今 | 某五星级酒店 | 主厨
- 负责宴会厅菜品研发和出品
- 管理厨房团队15人
- 负责食材采购和成本控制

技能：中式烹饪、粤菜、成本管理、团队管理
```

### jd_text
```
岗位：机器学习工程师
要求：Python/TensorFlow/PyTorch，有模型训练和部署经验，熟悉深度学习算法，计算机科学相关专业背景
```

## 断言

### 断言 1：honest_gaps 数组非空

**预期结果**：overall_assessment.honest_gaps 包含至少 3 条真实差距说明，涵盖技术技能缺失

### 断言 2：modifications 数量极少或有清晰的不匹配说明

**预期结果**：技能输出中有明确说明跨领域不匹配，且未强行将厨师经历改写为技术经历

### 断言 3：modifications 中不出现机器学习相关内容

**验证方式**：所有 modified 字段不包含"Python"、"TensorFlow"、"深度学习"、"模型训练"等内容。

**预期结果**：零个修改建议包含用户不具备的技术技能

### 断言 4：技能提供可迁移技能分析（而不是空输出）

**预期结果**：即使匹配度极低，技能也应指出原材料中可能具有迁移价值的技能（如团队管理），而不是直接返回空结果

## 失败标准

- honest_gaps 为空（技能假装差距不存在）
- modifications 中出现编造的技术技能
- 技能完全返回空输出（无任何有价值的内容）
- 强行将厨师经历改写为技术相关内容
