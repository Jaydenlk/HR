# 示例 04：用户要求编造数据 — 拒绝执行

## 场景说明

用户要求在简历中加入原材料中不存在的量化数据和技术经验。本例演示拒绝执行的标准流程和话术。

---

## 输入

### resume_text
```
王浩，前端工程师，2年经验
wanghao@email.com

工作经历：
2022.07 - 至今 | 某互联网公司 | 前端工程师
- 负责公司官网的前端开发和维护
- 使用 React 和 CSS 开发页面
- 参与 H5 活动页面开发

技能：HTML、CSS、JavaScript、React
```

### jd_text
```
岗位：高级前端工程师
要求：3年以上前端经验，熟悉性能优化，有大型复杂应用经验，熟悉 Vue/React，有工程化经验（Webpack/Vite）
```

### 用户附加要求（自然语言）
```
帮我在简历里加上"负责性能优化，页面加载时间降低了 60%"和"熟悉 Vue.js"，
这样跟 JD 更匹配。
```

---

## 输出

### 拒绝声明

根据简历改写的零编造政策，我**无法**执行以下两项要求：

**1. 「页面加载时间降低了 60%」**

您的原始简历中没有任何关于性能优化工作或量化结果的记录。这个数字是凭空添加的，一旦面试官深入询问（如：哪个页面、用什么方法优化、优化前后的具体指标），您将无法提供支撑细节，反而会造成负面印象。

**2. 「熟悉 Vue.js」**

您的技能栏中只有 HTML、CSS、JavaScript 和 React，没有 Vue.js 的任何记录。技术面试中 Vue.js 知识点可以被直接验证，添加不存在的技能会在面试中暴露。

---

### 我可以为您做的（基于真实材料）

基于您的原始简历，我可以合法地改写以下内容：

#### 修改 1：工作经历描述

- **原文**：负责公司官网的前端开发和维护
- **改写**：负责公司官网完整前端开发与持续迭代维护，技术栈基于 React 构建
- **来源追溯**：原文同句 + 技能栏 React
- **fabrication_check**：PASS

#### 修改 2：H5 活动页面描述

- **原文**：参与 H5 活动页面开发
- **改写**：参与移动端 H5 活动页面的开发，负责页面还原与交互实现
- **来源追溯**：原文"H5 活动页面开发"
- **fabrication_check**：PASS

---

### 关于真实差距的建议

| JD 要求 | 您的现状 | 建议 |
|---------|---------|------|
| 3年以上经验 | 2年经验 | 无法伪造，如实填写 |
| 性能优化经验 | 原材料中无此经验 | 补充真实的性能优化实践后再申请 |
| Vue.js | 未提及 | 学习后真实掌握，再加入简历 |
| 工程化（Webpack/Vite） | 未提及 | 学习后加入 |

---

### overall_assessment

- **match_improvement**：在零编造约束下，匹配度提升有限（JD 要求 3 年经验而用户只有 2 年，核心技能差距无法通过改写弥补）
- **items_needing_confirmation**：0
- **honest_gaps**：
  - 工作年限不足（2年 vs 要求3年）
  - 性能优化经验缺失
  - Vue.js 经验缺失
  - Webpack/Vite 工程化经验缺失

建议用户考虑更匹配的初中级前端工程师岗位，同时着手补充上述技能。
