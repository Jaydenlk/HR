# follow-up-message-writer — 面试后跟进消息

## 概述

根据跟进场景生成时机得当、语气得体的跟进消息，涵盖面试感谢信、投递进度询问、拒信礼貌回复、offer催促和录用确认五种场景。

## 跟进类型

| 类型 | 时机 | 说明 |
|---|---|---|
| `thank_you` | 面试后24-48小时 | 感谢信，提及具体话题 |
| `status_inquiry` | 投递后14天+ | 进度询问，简短礼貌 |
| `rejection_reply` | 收到拒信后1-2天 | 礼貌回复，维持关系 |
| `offer_followup` | offer期限前3-5天 | 温和催促，不施压 |
| `acceptance` | 决定接受时 | 正式确认，表达期待 |

## 必须输入

- `followup_type`：跟进类型
- `company`：公司名称
- `position`：职位名称

## 可选但重要

- `interview_details`：面试话题（感谢信个性化的关键）
- `contact_name`：收件人称谓
- `days_since_event`：距事件天数（用于时机评估）

## 重要原则

- 感谢信只有24小时内效果最好，超过72小时效果大幅下降
- 进度询问只跟进一次，无回音则继续其他选择
- 拒信一定要回复：维持行业关系，可询问反馈
- 催促用词温和：「以您时间为准」而非「请尽快」

## 限制

- 不虚构面试细节（无 interview_details 时使用占位符）
- 不生成催促语气（「急」「马上」等词）
- 每个场景只生成一版消息，不让用户从多版中选择

## 依赖

无（独立技能，不依赖其他技能）
