# referral-strategy — 内推路径分析

## 概述

分析用户人脉网络，识别最佳内推路径（直接内推/间接内推/冷接触），找出目标公司的人脉空缺，给出填补空缺的策略。

## 适用场景

- 制定内推计划前的人脉梳理
- 想知道现有人脉中谁最适合开口请求内推
- 需要了解冷接触策略（目标公司无直接人脉）
- 规划人脉网络的长期建设

## 内推路径类型

| 类型 | 估计转化率 |
|---|---|
| 直接内推（好友在目标公司） | 30-50% |
| 间接内推（通过共同认识人转介绍） | 15-30% |
| 冷接触（脉脉/LinkedIn联系陌生人） | 5-15% |

## 输入数据

| 字段 | 必须 | 说明 |
|---|---|---|
| `target_companies` | 必须 | 目标公司列表（至少一个） |
| `user_profile` | 必须 | profile-builder 输出 |
| `network_contacts` | 推荐 | 已知人脉列表（含关系类型） |
| `target_positions` | 可选 | 目标职位（评估联系人匹配度） |

## 重要限制

- 无人脉数据时不编造联系人
- 转化率基于行业经验估算，不保证结果
- 只分析用户实际提供的人脉，不推测未提供的关系

## 依赖

- `profile-builder` — 用户画像（必须）
