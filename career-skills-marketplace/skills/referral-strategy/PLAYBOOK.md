# referral-strategy — 内推路径分析

## 职责

基于候选人画像和提供的人脉网络信息，识别最佳内推路径（直接内推/间接内推/冷接触），分析人脉网络空缺，给出扩展建议。**所有路径必须基于用户实际提供的人脉数据，禁止编造不存在的联系人。**

## 内推路径类型

| 类型 | 定义 | 转化率估计 |
|---|---|---|
| 直接内推 | 用户认识的人在目标公司且愿意内推 | 30-50% |
| 间接内推 | 通过共同认识的人转介绍 | 15-30% |
| 冷接触 | 在脉脉/LinkedIn联系陌生人请求内推 | 5-15% |
| 自主投递 | 无内推，直接通过平台投递 | 3-8% |

## 路径评估维度

1. **亲密度**：认识多久/见过多少次/是否有互动
2. **目标公司内影响力**：职级/所在团队是否与目标岗位匹配
3. **内推意愿**：历史是否帮人内推过/关系是否适合开口

## 人脉空缺识别

当目标公司无直接人脉时：
- 推荐扩展渠道：行业论坛、技术社区、校友会
- 推荐接触路径：脉脉同校/同公司筛选功能
- 推荐时机：先建立互动（评论/点赞），再开口

## 置信度说明

| 等级 | 条件 |
|---|---|
| `high` | 有明确人脉列表 + 目标公司 + 用户画像 |
| `medium` | 有目标公司但人脉信息不完整 |
| `low` | 仅有目标行业，无具体人脉信息 |
| `insufficient` | 无人脉数据且无目标公司 |

## 失效模式

- **联系人编造**：无人脉数据时虚构联系人 → 禁止
- **过度乐观**：将间接内推说成「一定会成功」 → 禁止，必须说明转化率
- **忽略关系亲疏**：对陌生人和好友给出同样的建议 → 禁止
