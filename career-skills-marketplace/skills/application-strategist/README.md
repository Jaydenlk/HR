# application-strategist — 求职策略制定

## 概述

基于候选人画像和中国求职市场规律（秋招/春招/金三银四），制定个性化求职策略：目标公司分层、投递顺序节奏、每日行动计划。

## 适用场景

- 秋招/春招开始前的整体策略规划
- 金三银四在职跳槽路径规划
- 多个目标行业/岗位的优先级排序
- 求职方向迷茫，需要结构化指引

## 输入数据

| 字段 | 必须 | 说明 |
|---|---|---|
| `user_profile` | 必须 | profile-builder 输出（技能、经验、目标等） |
| `application_timeline` | 推荐 | 当前日期、期望入职时间、紧迫程度 |
| `source_quality_report` | 可选 | 渠道质量报告（用于推荐最优投递渠道） |
| `current_applications` | 可选 | 已有投递记录（避免重复建议） |

## 核心输出

- **目标公司分层**：stretch（冲刺）/ target（核心）/ safety（保底）
- **投递序列**：按周分配投递重心和数量
- **每日行动计划**：具体任务+时间估算+优先级
- **风险评估**：主要风险和应对策略

## 中国市场时间窗口

| 窗口 | 时间 | 建议 |
|---|---|---|
| 秋招 | 9月-11月 | 应届生首选，提前2-3个月准备 |
| 春招 | 3月-5月 | 秋招未到岗者的补录机会 |
| 金三银四 | 3月-4月 | 社招黄金期，在职跳槽最佳窗口 |
| 金九银十 | 9月-10月 | 社招第二黄金期 |

## 重要限制

- **缺少 user_profile 时不输出具体策略**：画像是策略的基础
- **不编造具体公司名称**：只描述公司类型/规模/行业特征
- **时间窗口过期时明确告知**：不按过期的窗口给建议

## 依赖

- `profile-builder` — 用户画像构建
- `source-quality-auditor` — 招聘渠道质量评审
