# 小红书内容质量信号

## 推广内容识别规则

以下特征出现时，`is_promotional: true`：

| 特征 | 说明 |
|------|------|
| 含「课程报名」「添加微信」「私聊领取」 | 典型引流推广 |
| 含「保offer」「上岸必看」等绝对化表述 | 营销话术 |
| 帖子内容结构过于完整（标题/正文/FAQ 一体） | 专业推广格式 |
| 笔记末尾有课程价格或联系方式 | 明确商业目的 |
| 评论区清一色好评且内容雷同 | 刷评嫌疑 |

## 可信度等级标准（小红书专用）

| 等级 | 判断标准 |
|------|----------|
| C | 有面试时间、轮次，无推广特征，用户描述较自然 |
| D | 疑似推广、内容空洞、无具体细节 |

**注意：小红书来源的最高等级为 C，即使内容非常详细也不超过 C。**

## 时效性规则

| 帖子日期 | 时效判断 |
|----------|----------|
| 90 天内 | fresh（仍有参考价值） |
| 90-180 天 | stale（面试流程可能已变化） |
| 180 天以上 | 显著降级，可信度进一步打折 |
