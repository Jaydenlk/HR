# 牛客网内容分类体系

## 内容类型

| 类型 | 说明 | 可信度参考 |
|------|------|-----------|
| interview_experience | 完整面试经历（含轮次/题目/结果） | B 级 |
| online_test | 笔试题目和题解 | B 级 |
| offer_report | Offer 报告（薪资/福利/入职体验） | B 级（薪资部分需验证） |

## 技术题分类

| 类别 | 典型内容 |
|------|----------|
| algorithm | 数据结构、算法题 |
| system_design | 系统设计、架构设计 |
| language_specific | Java/Go/C++ 语言特性 |
| database | SQL、NoSQL、Redis、MySQL |
| network | TCP/HTTP/网络编程 |
| project_related | 项目深挖、STAR 法则 |
| other | 其他 |

## 可信度评级（牛客网专用）

| 等级 | 判断标准 |
|------|----------|
| B | 有完整面试经历描述，含具体技术问题，时间在 6 个月内 |
| C | 描述较简单或时间超过 6 个月 |
| D | 内容空洞、无具体细节 |

**注意：牛客网来源的最高等级为 B，不达到 A 级。**

## 高频题识别

- 同一题目在 3+ 篇独立面经中出现 → `frequency >= 3`，重点标注
- 同一面试轮次被多人提及 → 说明面试结构相对固定
