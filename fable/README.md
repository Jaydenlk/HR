# fable — AI 长任务工程化交付文档包

任何模型(尤其 Opus 级)接手任何项目的长周期开发前,按此顺序读:

1. **`00-第一性原理-AI长任务工程化交付.md`** ← 核心件,先读这个。五条公理 → 八条铁律 → 体系四件套 → 质量闸 → 异常决策树 → 移植清单。
2. `01-作业法-FABLE-PLAYBOOK.md` — 做事风格与编队设计(隐性经验显性化)。
3. `02-防降智保险方法论.md` — 模型降档时体系如何兜底。
4. `03-经济高保障验收方法论.md` — 验收强度与成本的平衡。

三份样例(照抄改名即可用):
- `样例-执行手册(HRBP实例).md` — 00 文件里"文档层 02-执行手册"的真实完整实例(判据/预检/中断处置/agent team 模式)。
- `样例-turnkey脚本(t6-bocha).js` — 三段式派工脚本代表作(侦察先行/红线清单/假绿陷阱/审计核点)。
- `样例-中断收口脚本(closeout).js` — 配额中断后"缺口审计→只补剩余"的恢复流程实例。
